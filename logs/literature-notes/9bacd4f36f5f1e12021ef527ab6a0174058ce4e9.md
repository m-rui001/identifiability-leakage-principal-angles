- 原题：Physics-informed neural networks (PINNs) for fluid mechanics: A review
- 作者：Shengze Cai, Zhiping Mao, Zhicheng Wang, Minglang Yin, George Em Karniadakis（Brown 大学、厦门大学、大连理工大学）；Acta Mechanica Sinica（2021，DOI: 10.1007/s10409-021-01148-1；arXiv:2105.09506）
- 通道：TeX 源，无页码，定位用章节/公式标签；抽文中引用编号与 \ref 丢失（见疑点）。
- 性质：短综述 + 三组新数值案例（作者自述"review recent advances ... We then present new results"），结构为"PINN 基础与进展回顾 → 3D 不可压尾流反演 → 2D 可压弓形激波反演 → 血栓流材料参数反演 → 总结与展望"。

## 综述部分的论证线索

**动机四条**（引言）：CFD 五十年进展后仍无法无缝融入（多保真度）数据；工业复杂度问题的网格生成耗时且近乎手艺；反问题（未知边界条件/系数等）在 CFD 中代价高昂且需要另写代码；OpenFOAM 式代码超 10 万行难以维护。作者的定位声明（原文明说，且常被误读）：**PINN 不是要取代 CFD**——当前 PINN 在标准正问题上的精度与效率都不如高阶 CFD（根源是高维非凸损失的最小化，这是所有 NN 的共同挑战）；**PINN 的优势在有散乱部分时空数据时**（反问题），且正逆问题表述完全相同、无需数据同化流程。

**基础框架**：参数化 PDE 系统 $f(\mathbf{x},t,\hat{u},\partial_{\mathbf{x}}\hat{u},\partial_{t}\hat{u},\dots, \bm{\lambda} ) = 0$ + 初边值；全连接网 $\mathbf{z}^{k} = \sigma(\mathbf{W}^{k}\mathbf{z}^{k-1} + \mathbf{b}^{k})$；损失 $L = \omega_{1}L_{PDE} + \omega_{2}L_{data} + \omega_{3}L_{IC} + \omega_{4}L_{BC}$（MSE、Adam）。两个 Remark 值得记录：(1) 损失组成随问题而定——正问题不需要 $L_{data}$，反问题必须加入测量；(2) PINN 可解"超定"系统（经典适定问题再加域内测量）。AD 计算偏导数避免数值近似的截断误差。

**进展回顾的分类**：方程类型扩展（积分微分、分数阶、曲面 PDE、随机 PDE）；变分/域分解（hp-VPINN、cPINN、XPINN、并行实现、NVIDIA SimNet）；UQ（贝叶斯框架）；架构与训练改进（多保真度、自适应激活函数、动态损失权重、硬约束、CNN 结构）；理论（收敛性保证）。流体应用谱系：从原始 PINN 推断圆柱绕流的对流系数起步，到可压流、生物医学流、湍流对流、自由边界/Stefan 问题；一个有前景的方向是流动可视化（从浓度场/图像反演流场）。

## 案例一：3D 不可压尾流反演（从 2D2C 平面观测重建 3D 场）

问题设定：$Re=200$ 圆柱绕流（谱元法 Nektar 生成参考解），域 $[-7.5,28.5]\times[-20,20]\times[0,12.5]$（以直径无量纲化），入口 $u=1$、侧向周期、出口零压、柱面无滑移；关注尾流子域 $\Omega_s$: $[1.5,7.5]\times[-3,3]\times[4,9]$，50 个快照（$\Delta t=0.2$，约两个涡脱周期）。数据设定模拟平面 PIV：三类观测布置（Case 1：两个 x 平面 + 一个 y 平面 + 两个 z 平面；Case 2：去掉一个 z 平面；Case 3：只剩一个 x 平面 + y 平面 + z 平面）；**横截面上只测投影两分量**（z 平面测 $(u,v)$、x 平面测 $(v,w)$、y 平面测 $(u,w)$，Table 1 给各平面分辨率 $61\times26$ 或 $61\times61$）。

PINN 实现：输入 $(x,y,z,t)$、输出 $(u,v,w,p)$；损失 $L = L_{data} + L_{PDE}$（**无初边值项、无压力数据**——作者强调这与经典设定不同）；$f_{1,2,3} = \partial_t\mathbf{u} + (\mathbf{u}\cdot \nabla)\mathbf{u} + \nabla p - \frac{1}{Re}\nabla^2\mathbf{u}$、$f_{4} = \nabla \cdot \mathbf{u}$；残差点 $N_f=3\times10^6$、权重全为 1；网络 8 隐层 ×200 神经元、**$\sin(\cdot)$ 激活**；Adam + mini-batch（$10^4$），150 epochs 分三段学习率 $10^{-3}, 5\times10^{-4}, 10^{-4}$。

结果（Fig. 4–5，相对 $L_2$ 误差 $\epsilon_{V} = \frac{\| V_{CFD}-\hat{V}\|^{2} }{\| V_{CFD}\|^{2}}$）：Case 1 与 Case 2 精确（5 平面略优于 4 平面）；Case 3（3 平面）误差显著增大但可用（主流向速度误差大部分低于 2%）；$w$ 分量误差最大（其幅值本身小）；**初始与末端时刻误差偏大**——归因于 $t<0$、$t>10$ 无训练数据导致导数计算缺支撑（原文明确把无初条件的非稳态问题的这一现象一般化）。Case 2 的涡量/压力等值面与点时序 $(u,v)(x=3,y=0,z=6.4)$ 显示 PINN 准确捕捉涡脱非定常性。

## 案例二：2D 可压弓形激波反演

方程：定常可压 Euler $\nabla\cdot \boldsymbol{f}(U) = 0$，$U = [\rho, \rho u, \rho v, \rho E]^T$，$G_1(U) =[\rho u, p+ \rho u^2, \rho u v, p u + \rho u E]$、$G_2(U) = [ \rho v, \rho uv , p+ \rho v^2, p v+ \rho v E]$，多方气体状态方程 $p = (\gamma-1)\left(\rho E - \frac{1}{2}\rho \|\boldsymbol{u}\|^2\right)$ 封闭。问题设定的关键转折（原文明说的动机）：高速流的真实实验中边界条件通常未知、只能近似估计——因此**不用传统 CFD 所需的边界条件**，改用三类替代信息：(1) 子域 $D\subset\Omega$ 内的密度梯度数据 $\nabla\rho$（受纹影摄影 Schlieren 启发）；(2) 物面压力传感器数据；(3) 全局守恒约束（质量/动量/能量）。损失：

$$Loss = \omega_{1}Loss_{F} + \omega_{2}Loss_{\nabla \rho|_{D}} + \omega_{3}Loss_{inflow} + \omega_{4}Loss_{p^*} + \omega_{5}\left(Loss_{Mass} + Loss_{Momentum} + Loss_{Energy}\right) + \omega_{6}Loss_{n\cdot \boldsymbol{u}},$$

末项为物面法向速度条件。算例：$M_\infty = 4$，$p_\infty = 101253.6\,\mathrm{Pa}$，$\rho_\infty = 1.225\,\mathrm{kg/m^3}$，$u_\infty = 1360.6963\,\mathrm{m/s}$，$v_\infty = 0$，$T_\infty = 288\,\mathrm{K}$。网络 $6\times 60$（6 隐层 ×60），逐层自适应 tanh 激活，Adam 学习率 $6\times 10^{-4}$、$3\times 10^{5}$ epochs，动态权重技术。结果（Fig. 7）：PINN 的压力与 $u$ 场和 CFD 吻合——作者结论：**用与传统 CFD 不同的可用知识（密度梯度 + 物面压力 + 全局守恒）即可重建高速流场**。

## 案例三：血栓流材料参数反演（FSI + Cahn–Hilliard）

模型：Navier–Stokes + Cahn–Hilliard 的流固耦合描述——$\rho(\partial_t\mathbf{u} + \mathbf{u}\cdot\nabla\mathbf{u}) +\nabla p = \nabla \cdot (\boldsymbol{\sigma_{vis}} + \boldsymbol{\sigma_{coh}}) - \mu\frac{(1-\phi)\mathbf{u}}{2\kappa(\phi)}$（$\kappa(\phi)$ 为相依赖渗透率）、$\nabla\cdot \mathbf{u} = 0$、辅助向量输运 $\partial_t\boldsymbol{\psi} + \mathbf{u}\cdot \nabla\boldsymbol{\psi} = 0$（梯度构成变形梯度张量 $\mathbf{F}$）、$\partial_t\phi + \mathbf{u}\cdot \nabla \phi = \tau \Delta \omega$、$\omega = \Delta \phi + \gamma g(\phi)$（$g$ 为双井势导数）；$\boldsymbol{\sigma_{vis}} = \mu \nabla u$、$\boldsymbol{\sigma_{coh}} = \lambda\nabla\cdot(\nabla\phi \otimes \phi)$。参数：$\rho = 1$、$\mu = 0.1$、$\lambda = 4.2428\times10^{-5}$、$\tau = 10^{-6}$、$h= 0.05$；渗透率归一化 $\kappa = k_f/a_f^{2}$。

反演设定：半圆形血栓（不可渗核心 $\phi=-1$、可渗外壳 $\phi=0$）在抛物型入流通道中； permeability 的空间变化用参数化 $\kappa(\phi) = e^{a\phi} + b$（作者注明形式不唯一，只要在 $\phi=0,-1$ 处取值正确），真值 $a = 6.9$、$b = 0$（对应核心 $\kappa=0.001$、外壳 $\kappa=1$）。待推断量：$a,b$（即渗透率）与隐藏速度场；可观测数据只有**相场 $\phi$**。训练点构成（Fig. 8(b) 四类）：初始快照 1000 点、内部 PDE 残差点 10000 个（30 个快照、$t\in[0.03, 0.93]$、共 10000 个带相场值的点测量）、边界 1000 点。网络：两个全连接网（Net U 输出 $u,v,p,\phi$；Net W 输出 $\omega,\psi_1,\psi_2$），各 9 隐层 ×20 神经元；总损失 $L = \omega_{1}L_{PDE} + \omega_{2}L_{IC} + \omega_{3}L_{BC} + \omega_{4}L_{data}$，联同 PDE 参数 $\lambda=[\kappa]$（即 $a,b$）一起优化。

结果（Fig. 9）：300,000 epochs，PDE 损失为最大分量、其余低于 $O(10^{-3})$；**推断 $a = 7.1$、$b = 0.0003$ 对真值 6.9、0.0**，即核心渗透率 $\kappa(\phi=-1)=0.0011$、外壳 $\kappa(\phi=0)=1.0003$ 与参考吻合；相场与 $v$ 场预测在 $t=0.78$ 与真值一致——**隐藏速度场仅凭相场数据即可准确推断**；误差分布有结构：相场误差集中在血栓出口层附近、速度误差限于外壳层（原样记录，未解释成因）。

## 总结与展望（原文明说）

PINN 定位为处理"有多模态数据、初边条件未知"的病态流问题的**补充方法**（现有 CFD 无法处理此类不适定问题）。四个展望方向：主动流动控制（替代昂贵实验与大规模仿真）；迁移学习预测新雷诺数（由低 $Re$ 解外推）；用 PINN 的自动数据同化为高 $Re$ 未解析动力学发展封闭模型；多 GPU 数据并行/混合并行以达成工业规模（已获得的并行加速比很好）。

## 适用条件与边界（综合原文）

- 正问题精度/效率不如高阶 CFD（作者明确承认），PINN 的价值区间是有数据注入的反问题与不适定问题。
- 3D 尾流案例依赖足够多的观测平面：平面数从 5 降到 3 误差显著上升；$w$ 分量因幅值小相对误差大；无初/终时刻数据导致端点误差。
- 可压案例用子域密度梯度而非全域（与既有 1D 工作的差异），全局守恒约束为软约束；激波间断下未报告逐点误差数值（只有定性"good agreement"）。
- 血栓案例的 $\kappa(\phi)$ 参数形式是先验假设（作者自认非唯一）；推断值 7.10 对 6.90 有约 3% 偏差。
