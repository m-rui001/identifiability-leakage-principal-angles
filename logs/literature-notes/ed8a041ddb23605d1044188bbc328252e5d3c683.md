# CPC v2：把"可预测表示"做成数据高效识别的引擎

原题：Data-Efficient Image Recognition with Contrastive Predictive Coding（Hénaff, Srinivas, De Fauw, Razavi, Doersch, Eslami, van den Oord，arXiv:1905.09272，ICML 2020）。LaTeX 源通道，定位用章节号。

## 论证主线：从"可预测性假设"到三层数据效率证据

论文的假设（Introduction 明说）：数据高效识别源于**使自然信号的变化更可预测**的表示；人工视觉缺乏这种性质，而人类感知表示已被证明能"拉直"（linearize/straighten）自然视频的时间变换。CPC（在图像上是"从上方 patch 的表示预测下方 patch 的表示"）是该假设的现成载体，故论文的任务是：把 CPC v1 改造到足以检验假设的水平（§5.1 的 v1→v2 消融），然后在三个递进的协议上检验——线性分类（表示质量的绝对度量，§5.2）、少标注高效分类（核心问题，§5.3）、跨任务迁移 PASCAL VOC 检测（通用性，§5.4）。评估协议（§2.2）形式化为两阶段：$\theta^* = \arg\min_\theta \frac{1}{N}\sum_n \mathcal{L}_{\mathrm{CPC}}[f_\theta(x_n)]$（在全量 ImageNet 无标注集上预训练编码器），随后 $\psi^* = \arg\min_\psi \frac{1}{M}\sum_m \mathcal{L}_{\mathrm{Sup}}[h_\psi \circ f_{\theta^*}(x_m), y_m]$，并丢弃上下文网络 $g_\phi$，仅保留编码器 $f_\theta$——下游可直接作用于整图而非 patch。

## CPC 目标（§2.1）

图像切为重叠 patch 网格 $\vx_{i,j}$，逐 patch 编码 $\vz_{i,j}=f_\theta(\vx_{i,j})$；掩码卷积网络 $g_\phi$ 聚合上方特征得上下文 $c_{i,j}=g_\phi(\{\vz_{u,v}\}_{u\le i,v})$；线性预测 $\hat{\vz}_{i+k,j}=\mW_k\vc_{i,j}$；InfoNCE 损失（对位置与预测偏移求和）：

$$\mathcal{L}_\mathrm{CPC} = - \sum_{i,j,k} \log \frac{\exp(\hat{\vz}_{i+k,j}^T \vz_{i+k,j})}{\exp(\hat{\vz}_{i+k,j}^T \vz_{i+k,j})+\sum_l \exp(\hat{\vz}_{i+k,j}^T \vz_{l})},$$

负样本取自同图其他位置与 mini-batch 内其他图像。作者指出该对比损失避免了 MSE 类损失的平凡解（所有 patch 坍缩到常向量）。

## v1→v2：四轴增量消融（§5.1，Fig. 3）

设计原则（原文自述）：增大编码器规模与训练效率、最大化每张图的监督信号、同时通过 patch 独立增广**切断低层线索**以防退化解。增量数字（自定义验证集，与官方验证集结果不可直接比较）：

- **模型容量（MC）**：v1 只用 ResNet-101 前 3 个残差堆；把第 3 堆（23 块、1024 维特征图、256 维瓶颈）换成 46 块、4096 维、512 维瓶颈，称 ResNet-161——**+5%** Top-1。patch 从 $64\times64$ 加大到 $80\times80$（扩大感受野）——**+2%**。
- **层归一化（LN）**：一个重要的负面发现——batch normalization 在 CPC 中**损害**大模型下游性能。作者的假设（明说为 hypothesize）：BN 通过 batch 统计量在 patch 之间引入依赖，可被用来绕过感受野约束、找到 CPC 的平凡解。换 layer normalization 拿回训练效率——**+2%**。
- **预测长度与方向（BU/HP）**：只用上方上下文预测改为上、下、左、右四个方向各配独立上下文网络，预测任务增至 4 倍，防过拟合——自下而上 **+2%**、全四方向再 **+2.5%**。
- **patch 级增广（RC/PA/LP）**：理由是若网络能用低层模式（patch 间直线延续、色差）解 CPC，就不必学语义内容。采用"color dropping"（每 patch 随机丢弃 3 通道中的 2 个）——**+3%**；再加固定通用增广（shearing、旋转、随机弹性形变、颜色变换）——合计 **+4.5%**。作者如实承认这些增广引入了"内容保持变换"的归纳偏置，但未针对下游性能调优（区别于后续工作的做法）。

累计：线性分类 Top-1 从 v1 的 48.7% 到 **71.5%**（+23% 绝对），当时 SOTA。同架构公平对比：CPC v2 配 ResNet-50 达 63.8%（Top-5 85.3%），超过同参数量的 Instance Discr.（54.0）、Local Aggr.（58.8）、MoCo（60.6）、PIRL（63.6）；ResNet-161 版超过架构更大的 AMDIM（68.1）、CMC（68.4）、MoCo×4（68.6）。作者明说各方法架构差异巨大（BigBiGAN 用 RevNet-50×4、AMDIM 定制 ResNet 等），"apples-to-apples 比较困难"，故补同架构对照。

## 高效分类：核心结果（§5.3，Table 2）

监督基线先做到位：对比 ResNet-50/-101/-152/-200，ResNet-200 在所有数据量下最好；针对低数据量调优（深度、正则、优化、大量增广）后，1% 标注下最优 Top-5 为 44.1%（100% 时 95.2%）。CPC 侧在 $14\times14$ 的 CPC 潜变量网格上接 11 块 ResNet 分类器（4096 维隐层、1024 维瓶颈），先固定特征训练至收敛、再整体微调（编码器用更小学习率与早停以防偏离 CPC 解）。核心数字（Top-1 / Top-5）：

| 标注量 | 1% | 5% | 50% | 100% |
|---|---|---|---|---|
| ResNet-200 on pixels | 23.1 / 44.1 | 50.6 / 75.2 | 75.9 / 93.1 | 80.2 / 95.2 |
| ResNet-33 on CPC 特征 | 52.7 / 78.3 | 68.1 / 88.8 | 81.2 / 95.6 | 83.4 / 96.5 |
| 数据效率增益 | 5× / 5× | 2× / 2× | 2× / 2× | — |

要点：1% 标注下 78.3% Top-5，对纯监督 +34% 绝对（+77% 相对），超过此前所有半监督方法逾 +20% Top-5；**50% 标注即超过全量监督基线**（2× 增益）；1% 标注超过 5% 标注的监督基线（5× 增益）。

**模型类的公平性问题（原文主动处理）**：作者强调比较的是两个模型**类**（监督 ResNet vs CPC 预训练 + 分类器）的最佳代表，二者容量悬殊（ResNet-200 约 60M 参数 vs 组合模型超 500M）。为排除"容量论"解释，他们把 ResNet-161 + ResNet-33 堆叠（含 BN）纯监督训练，结果 80.3%/95.2%——与 ResNet-200 相当而非更好。解释（原文给出）：ResNet 系列的容量是按 ImageNet 标签的训练信号量校准的，更大只增过拟合风险；而 CPC 目标信号更丰富、需要大架构才能吃满——ResNet-50 与 ResNet-161 的 CPC 线性分类差（63.8% vs 71.5%）即为证据。

**与其他无监督表示对比（Table 3）**：1% 标注 Top-5——旋转预测 57.5、BigBiGAN（固定）55.2、AMDIM（固定）67.4、CPC v2 固定 77.1、微调 78.3（固定与微调仅差 1.2%，说明表示本身已接近饱和）。对 BigBiGAN/AMDIM 原文未报高效分类，作者用同一范式自行评估（固定特征 + 同一 ResNet 分类器），方法透明。与 label-propagation 类方法（伪标签、VAT+熵最小化、Unsup. Data Aug、Rot+VAT+Ent）对比时作者明说比较"不完美"：这类方法假设所有未标注图都属于测试类别（有优势），但除一项外均用更小网络。结论：CPC 追平或超过最强的 label-propagation 组合（Rot+VAT+Ent 91.2 vs CPC v2 微调 91.2，1% 时 51.6 vs 78.3）。

## 迁移：PASCAL VOC 2007 检测（§5.4，Table 4）

标准协议（监督 ImageNet 预训练 → Faster-RCNN 特征提取）下 ResNet-152 达 74.7% mAP；换成 CPC 编码器作特征提取器达 **76.6%**（+2% 绝对），超过同期 Momentum Contrast 的 74.9% 与 PIRL 的 73.4%，是"无监督预训练在迁移学习上超过监督预训练的首批结果之一"（原文用 "one of the first"，留有余地）。同时该数据集只有 5011 张标注图，本身就是数据效率的检验。作者仍强调比较的是模型类、各选最佳架构。

## 可复现细节（附录）

预训练：$260\times260$ 输入（$300\times300$ 随机裁剪）切 $6\times6$ 网格、$80\times80$ patch（步距 $36\times36$），ResNet-161 末端 mean-pooling 得 $[6,6,4096]$ 张量；pixelCNN 式上下文网络。每 patch 的增广流程（4 步，概率各异：弹性形变/剪切 0.2、颜色直方图自动增广 0.2、颜色增广 0.8、灰度投影 0.25）。优化：Adam 200 epochs，lr 0.0004、$\beta_1=0.8$、$\beta_2=0.999$、$\epsilon=10^{-8}$，Polyak 平均衰减 0.9999，梯度范数裁剪 0.01，batch 512（32 workers）。线性分类：特征 BN 归一（去 scale 参数）+ $1\times1$ 卷积到 1000 logits + 空间均值池化；Adam lr 0.0005。监督基线的超参（lr $\in\{0.05,0.1,0.2\}$、权重衰减 $10^{-5}$ 到 $10^{-2}$ 对数搜索、DropOut 0–1 线性）按每个标注子集分别搜索，用约 1 万张图的独立验证集选择、在 ILSVRC-2012 公开验证集评估。

## 讨论中的推广主张与限定

- 结论外推（作者明说 "open the door"）：数据天然受限的领域如医学影像与机器人；并主张对比预测方法"任务无关"，可作为整合多模态（视觉、音频、触觉、本体感觉、动作）自监督任务的统一框架——这是展望，非本文实验支持的范围。
- 限定一：所有预训练都在全量 ImageNet（128 万张）上进行——结论是"少标注"而非"少数据"；无标注数据本身仍是巨量的。
- 限定二：patch 增广引入内容保持变换的归纳偏置（作者自认），v2 的提升有多少来自增广偏置 vs 预测任务本身，未做隔离（消融是按增量累加的）。
- 限定三：与其他方法比较时架构不可控（作者反复申明），同架构对照只对 ResNet-50 一档做了。
- 疑点：抽文中引用键丢失（Table caption 中的 [1]–[11] 占位），部分被引方法（如 color dropping 的出处、Zhang 式增广）无法落到具体文献；Fig. 3 的纵轴数值未在文本中出现，增量数字均取自正文行文。
