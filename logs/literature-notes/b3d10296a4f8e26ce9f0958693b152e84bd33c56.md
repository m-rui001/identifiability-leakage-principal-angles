# 基于信息瓶颈的不确定性量化：IB-UQ（函数回归与算子学习）

*IB-UQ: Information bottleneck based uncertainty quantification for neural function regression and neural operator learning · 2024 · DOI 10.1016/j.jcp.2024.113089（arXiv 2302.03271；郭玲、Hao Wu、Wenwen Zhou、Yan Wang、Tao Zhou）*

## 这篇论文要解决什么、主张什么

科学机器学习（DNN 回归、DeepONet 算子学习）的预测需要可信的不确定性量化（UQ），现有方法的痛点是：贝叶斯框架（BNN+HMC）是"金标准"但对大规模数据代价高，Deep Ensemble 在外推（OOD）区域往往给不出增大的不确定性，而算子学习方向的 UQ 工作尤其少。论文主张：把信息瓶颈（IB）原则改造成一个可训练的 UQ 框架 IB-UQ，同时给出预测均值、方差，并且**在训练分布之外仍给出放大的、可信的不确定性**。这是作者自称的"首次将信息瓶颈用于科学机器学习的 UQ"（Conclusions §）。

核心主张有三层：其一，IB-UQ 能在含噪数据上训练并在未见含噪数据上给出稳健预测与可靠不确定性（摘要、Results 各实验）；其二，与 BNN+HMC 相比"易于实现、对大规模数据高效"（贡献条目 2）——注意正文中没有给出墙钟时间的对照表，这一效率主张在文本内只有定性支撑；其三，模型能对 OOD 数据给出"confident uncertainty evaluation"，其理论根据是补充材料中的一个刻画性结论（见下）。

## 方法机制：三处改造拼成一个可训练目标

**1. 把 IB 目标里的压缩项换成"宽分布"版本。** 标准 IB 目标是 $\mathcal{L}_{\mathrm{IB}} = I(Z;Y) - \beta I(Z;X)$（Methods §IB-UQ for DNN function regression）。作者指出用它训练时互信息都在训练集联合分布上估计，天然只"认识"训练分布，OOD 处理不好。于是改用 General Incompressible-Flow Network（GIN）生成宽分布样本 $\tilde X \sim \tilde p(x) \propto p(x)^{1/\tau}$（$\tau>1$，GIN 的温度缩放性质 $V'=f_I(\sqrt{\tau}W)$ 使密度按 $1/\tau$ 次幂变宽，Supp §GIN and Mixup），压缩项换成 $I(\tilde Z;\tilde X)$：

$$\mathcal{L}_{\mathrm{IB}} = I(Z;Y) - \beta\, I(\tilde Z;\tilde X).$$

这一步是全文最关键的论证转折，且有定理支撑（Supp §Analysis of data augmentation with GIN）：若存在 $C>1$ 使 $p(y)^{-1}p(y|x)\le C$ 对所有 $x,y$ 成立，则对满足 $p(x)\le\epsilon\tilde p(x)$ 的任意 $x$，最优编码器满足 $\mathrm{KL}(q_E^*(\cdot|x)\,\|\,e^*(\cdot)) \le \epsilon\beta^{-1}\log C$。由于 $L_{XZ}(x;\mathcal M)=\mathrm{KL}(q_E(\cdot|x)\|e(\cdot))$ 而最优解在每点上最大化 $L(x;\mathcal M)=L_{YZ}-\beta L_{XZ}$，$\epsilon$ 小意味着**该输入的潜变量近似与输入无关**——即编码器对 OOD 输入输出的是无信息的 $z$，解码器随后只能给出宽的预测分布。这就是"IB 目标自动产生 OOD 不确定性"的推理链，原文明说这是分析推导（补充材料），不是实验观察。

**2. 置信度感知编码器 + 高斯解码器。** 潜变量取 $z=\operatorname{diag}(m(x))\bar z(x)+\operatorname{diag}(\mathbf 1-m(x))z_0$，其中 $\bar z(x)$ 是确定性特征网络，$m(x)\in[0,1]$ 逐维给出"该特征可信"的权重，$z_0\sim\mathcal N(0,I)$ 是无信息噪声（Methods §）。理想训练后 $m(x)=\mathbf 1$ 意味着 $x$ 接近训练数据、$z$ 完全确定；$m(x)=\mathbf 0$ 则 $x$ 是 OOD、$z$ 退化为 $z_0$。实现上还对 $m(x)$ 做了基于 GIN 密度分位数的修正（$\tilde p(x)\le\tilde p'$ 时强制 $m\lessapprox 10^{-6}$，Supp §algorithm），使两个分布都覆盖不到的极低密度输入也被压向无信息端——这一处理在正文编码器描述里没有展开，属于实现层面的关键细节。解码器是高斯 $q_D(y|z)=\mathcal N(\mu_D(z),\Sigma_D(z))$，对角协方差。

**3. 变分下界使目标可训。** 直接优化 $\mathcal L_{\mathrm{IB}}$ 不可行，作者沿用 Alemi 等的变分技巧并配上 RealNVP 归一化流做边际密度 $e(\tilde z)$（Supp §Normalizing Flow），得到

$$\mathcal{L}_{\mathrm{VIB}} \triangleq \mathbb{E}_{(x,y,z)}[\log q_D(y|z)] - \beta\,\mathbb{E}_{(\tilde x,\tilde z)}\left[\log\frac{q_E(\tilde z|\tilde x)}{e(\tilde z)}\right] \;\le\; \mathcal{L}_{\mathrm{IB}} - \mathcal H(Y),$$

等号当且仅当 $q_D(y|z)=p(y|z)$、$e(\tilde z)=\tilde p(\tilde z)$（Supp §Variational approximation，KL 非负性两步推出，属教科书式推理，作者明说推导同前人）。训练时小批量为：Mixup（可选，$\lambda\sim\mathrm{Beta}(\alpha,\alpha)$）平滑 $I(Z;Y)$ 的经验估计防过拟合；GIN 采 $\tilde x_b$；编码、估计 $\widehat{\mathcal L}_{\mathrm{VIB}}$、SGD 上升（Algorithm 1）。

**算子学习版**：瓶颈只放在 DeepONet 的 branch 网络上（假设输出函数域 $\mathcal K_2$ 低维且充分采样），目标是 $\mathcal L_{\mathrm{IBONet}} = I((Y,Z);s(Y)) - \beta I(\tilde Z;\tilde O)$，其中 $\tilde O$ 是 GIN 生成的合成传感器读数；解码器用确定性 DeepONet 同时输出均值和对数标准差 $(\mu_D(y,z),\log\sigma_D(y,z))^\top=\sum_{i=1}^n b_i(z)t_i(y)$（Methods §IB-UQ for neural operator learning，Algorithm 2）。作者明确说明：只做单点 $y$ 处的 UQ，多点联合预测"超出本文范围"；trunk 网络也可以加瓶颈但本文不做（两个 remark）。

## 证据如何支撑主张

- **不连续函数回归**（$u(x)=\frac12[\sin^3(2\pi x)-1]$ 于 $[-1,0)$、$\frac12[\sin^3(3\pi x)+1]$ 于 $[0,1]$，$N=32$，$\sigma_u=0.1$，$\beta=0.3$）：与 GP、HMC、Deep Ensemble 对比，四种方法均值都好，但 OOD 区间（$x\in[-1,-0.8]\cup[-0.2,0.2]\cup[0.8,1]$）上只有 GP、HMC、IB-UQ 的标准差明显增大，Deep Ensemble 不增大（Results §，Fig. four_method）。这是"IB-UQ 达到贝叶斯金标准的 OOD 敏感性"这一主张的直接证据。
- **算子学习两个 PDE**（扩散反应方程 $\partial_t s=D\partial_x^2 s+ks^2+u(x)$，$D=0.01,k=0.5$；对流方程 $\partial_t u+v(x)\partial_x u=0$；各 $N=10000$，噪声 0.01，测试用相关长度 $l$ 不同的 GP 输入制造 OOD）：ID（$l=0.5$）误差小；$l<0.5$ 的 OOD 误差显著增大，且 2 倍标准差带覆盖绝对误差；$l>0.5$ 的 OOD 误差仍然小（Fig. dr1–dr3、adv1–adv3）。注意原文对后一现象给了**可能解释**——"更平滑的核使 DeepONet 更容易预测"，并注明与已有观察一致——这是谨慎措辞的推断，不是结论。推理链的关键点是：主张从来不是"OOD 一定误差大"，而是"误差大的地方不确定性大"。
- **真实数据**（California housing，20640 样本，用 LOF 分数 −1.2/−1.5/−2 切出 ID 与三档 OOD）：绝对误差随 LOF 递减显著增大，不确定性带覆盖 ID 与 OOD 的绝对误差（Fig. housing_outlier_structure/abs_change/std_change）。
- **大规模气候模型**（地表温度场 → 气压场，$N=1825$，$144\times72$ 网格，trunk 输入加谐波特征展开 $\zeta(y)=[y,\sin(2\pi y),\cos(2\pi y),\dots]$，$H=5$）：删去第二季度（$N=1375$）、删去二、三季度（$N=925$）训练后，被删季节上的误差与不确定性同步增大，ID 处误差小且不确定带覆盖误差；对照组 vanilla DeepONet"无任何不确定性估计"（Fig. climate_* 与 deeponet_climate_*）。
- **消融**：信息平面上扫 $\beta$，$\widehat{I(Z;Y)}$ 与 $\widehat{I(\tilde Z;\tilde X)}$ 的权衡显示最优 $\beta\in[0.2,0.3]$，故取 0.3（Supp §Additional results）；$\sigma_u$ 从 0.1 增到 0.2、$N$ 从 32 降到 16，不确定性相应增大（Fig. four_situation）——UQ 行为对噪声和数据量方向正确。

## 训练稳定性的隐含承认

超参数部分披露了两处经验性补救：训练初期设 $\beta=0$ 预训练（函数回归 1000 epochs / 算子学习 100 epochs），"显著增强稳定性"；Mixup 的 $\alpha$ 用 0.005（数据量 16 时用 0.01），远小于原 Mixup 文献常用的 $0.1\sim0.4$——作者解释是训练集极小时 $q_D(y|z)$ 的条件密度估计会过拟合。GIN 温度按问题取 $\tau=16$（玩具函数）、4（housing）、1.4（算子），并无统一取法。这些细节说明目标函数的训练并非开箱即稳，属于论文自己承认的工程边界。

## 适用条件与失败模式

- OOD 结论的成立依赖两个前提：宽分布 $\tilde p$ 必须真正覆盖 OOD 区域（$p(x)\le\epsilon\tilde p(x)$ 中的 $\epsilon$ 要小），以及似然比有界 $p(y)^{-1}p(y|x)\le C$。原文定理是条件性的；GIN 本身对 $\tilde p$ 的近似质量没有误差界。
- 归一化流会在多模态分布的模式之间高估密度（原文引述已知缺陷）；作者论证这在 IB-UQ 里反而无害甚至有利（多产生 OOD 增广样本）——这是一个"缺点变优点"的论证，未做定量验证。
- 效率主张（对比 HMC）无运行时间数据支撑；补充材料只列了 HMC 的参数配置（$\epsilon=0.1$、burn-in 2000、1000 样本）。
- 高维推广、物理信息（部分物理+稀疏观测）场景、极端事件主动学习均列为未来工作，本文未做。

## 术语与抽取疑点

- GIN 在本文指 General Incompressible-Flow Network（体积保持的流模型），与强化学习领域的 GIN（Graph Isomorphism Network）同名异义；"confidence" $m(x)$ 实为逐维门控概率，不是统计学置信度。
- 源文本为 LaTeX 源，正文中引用编号在抽取时被剥除（如"Tishby et al. in their work ."处缺编号），引用归属按正文作者名保留；文中有大段 `\iffalse` 包裹的旧稿（早期版本目标用 $I(Z;X)$、完整 HMC 推导等），非正文内容，未作为证据使用；$\mathcal{LOSS}_{IB}$ 等旧稿记号与正式记号 $\mathcal L_{\mathrm{VIB}}$ 并存于源文件，注意区分。
