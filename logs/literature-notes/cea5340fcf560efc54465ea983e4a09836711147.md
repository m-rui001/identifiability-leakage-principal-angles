# PAC-Bayes 信息瓶颈（PAC-Bayes Information Bottleneck）

Wang, Zhou, He 等，AISTATS 2022（arXiv:2109.14509）。LaTeX 源通道，定位用章节/公式号。

## 动机：把 IB 的压缩项从表示搬到权重，绕开 $I(T;X)$ 的已知缺陷

论文从 IB 理论的争议清单出发：Saxe 等指出表示压缩相变只在 double-sided saturating 非线性（tanh/sigmoid）下出现，ReLU 下两相边界消失；压缩与泛化的因果性被质疑（有网络不压缩仍泛化好）；确定性网络中互信息退化为平凡值；binning/加噪等随机化近似"要么违反 IB 原则、要么与 NN 高性能矛盾"（Introduction 节）。作者的对策是把分析对象从表示 $T$ 换成权重 $\mathbf{w}$：IIW 定义为 $I(\mathbf{w};S)$（$S=\{X_i,Y_i\}_{i=1}^n$ 为有限数据集）。选它的理由有三（§3 开头）：其一，Xu 等（AISTATS 2020）已基于 PAC-Bayes 定理证明 $\mathbb{E}_{p(S)}[L(\mathbf{w}) - L_S(\mathbf{w})] \leq \sqrt{\frac{2\sigma^2}{n} I(\mathbf{w};S)}$（损失 $\sigma$-sub-Gaussian 时成立，脚注给出满足条件的方法是裁剪损失到 $[0,a]$ 使其为 $\frac{a}{2}$-sub-Gaussian），即 IIW 自带泛化界——这是 $I(T;X)$ 不具备的；其二，该量基于 Fisher 信息矩阵，对损失景观 Riemannian 流形的重参数化不变，而 Hessian 特征值可被重参数化任意放大；其三，权重不受输入 $X$ 与激活函数直接影响，故对激活函数选择不变。

新瓶颈（§2）在 PAC-Bayes 泛化界上加精度项：

$$\min_{p(\mathbf{w}|S)} \mathcal{L}_{\text{PIB}} = L_S(\mathbf{w}) + \beta I(\mathbf{w};S).$$

分类情形下作者声称其等价于 $\max_{p(\mathbf{w}|S)} I(\mathbf{w};Y|X,S) - \beta I(\mathbf{w};S)$——sufficiency/maximization 项变为权重中关于标签的信息。与表示 IB 的关键差别（作者明说）：PIB 建在不受输入与激活函数直接影响的权重上，其压缩项与泛化有显式关联而非类推。需要注意（作者脚注）：这里的"后验"$p(\mathbf{w}|S)$ 并非贝叶斯定理给出的后验，PAC-Bayes 界对任意先验（可以错）与任意后验都成立。

## IIW 的可计算化：高斯 KL → bootstrap 先验协方差 → 影响函数 → Fisher 信息

估计链条是本文的技术核心，分四步递进。

第一步，高斯假设下的闭式解（§3.1）：设 $p(\mathbf{w})=\mathcal{N}(\mathbf{w}|\btheta_0,\bSigma_0)$、$p(\mathbf{w}|S)=\mathcal{N}(\mathbf{w}|\btheta_S,\bSigma_S)$，则

$$\text{KL}(p(\mathbf{w}|S)\parallel p(\mathbf{w})) =\frac12 \left[ \log \frac{\det \bSigma_S}{\det \bSigma_0} - D + (\btheta_S - \btheta_0)^{\top}\bSigma_0^{-1}(\btheta_S - \btheta_0) + \text{tr}\left(\bSigma_0^{-1}\bSigma_S\right) \right].$$

先验/后验协方差成比例时（作者脚注：这是 PAC-Bayes 界构造的常见简化），对数与迹项均为常数，故 $I(\mathbf{w};S) \propto \mathbb{E}_{p(S)}\left[(\btheta_S - \btheta_0)^{\top}\bSigma_0^{-1}(\btheta_S - \btheta_0)\right] = \mathbb{E}_{p(S)}\left[\btheta_S^{\top} \bSigma_0^{-1} \btheta_S\right] - \btheta_0^{\top}\bSigma_0^{-1}\btheta_0$。剩下的问题是定 $\bSigma_0$。

第二步，bootstrap 先验（§3.2）：$\bSigma_0$ 称 oracle prior 协方差，因为 $\bSigma_0=\mathbb{E}_{p(S)}\left[(\btheta_S - \btheta_0)(\btheta_S - \btheta_0)^{\top}\right]$ 恰在 $p(\mathbf{w})=\mathbb{E}_{p(S)}[p(\mathbf{w}|S)]$ 时最小化 $I(\mathbf{w};S)$；作者用 bootstrap 重采样近似 $\bSigma_0 \simeq \frac1K \sum_{k} (\btheta_{S_k} - \btheta_S)(\btheta_{S_k} - \btheta_S)^{\top}$，但在 $K$ 个重采样数据集上各训一次 SGD 不可行。

第三步，影响函数（Lemma 1）：由稳健统计，丢弃样本 $j$ 重训的参数差为 $\hat{\btheta}_{S_{\setminus j}} - \hat{\btheta}_S \simeq -\frac1n \bpsi_j$，其中 $\bpsi_j = - \bH_{\hat{\btheta}_S}^{-1} \nabla_\btheta \ell_j(\hat{\btheta}_S)$；推广到 loss 扰动向量 $\bxi$ 有 $\hat{\btheta}_{S,\bxi} - \hat{\btheta}_S \simeq \frac1n \bPsi^{\top} (\bxi - \1)$。这是"重训 $K$ 次"到"一次解析计算"的关键替代。

第四步，闭环（Lemma 2，附录 A 给完整证明）：结合 Poisson bootstrapping（$\lim_{n\to\infty}\text{Binomial}(n,\frac1n)=\text{Poisson}(1)$，$n\geq100$ 时近似精确，$\mathbb{E}[\xi_i]=1$、$\text{Var}[\xi_i]=1$）与 Hessian-Fisher 关系（$\bH_{\hat{\btheta}} = \bF_{\hat{\btheta}} + \frac1n \sum_{i,c} [\nabla_{\hat{\by}}\ell_i(\hat{\btheta})]_{c} \bH_{[f]_c}$，训练良好时 $\nabla_{\hat{\by}}\ell_i\simeq0$ 故 $\bH\simeq\bF$），推得

$$\bSigma_0 \simeq \frac1n \bH_{\hat{\btheta}}^{-1} \bF_{\hat{\btheta}} \bH_{\hat{\btheta}}^{-1} \simeq \frac1n \bF_{\hat{\btheta}}^{-1}.$$

证明的关键代数步骤：$\bSigma_0 \simeq \frac1{n^2}\bPsi^{\top}\mathbb{E}_{p(S)}[\bxi\bxi^{\top}]\bPsi$，由 $\mathbb{E}_{p(S)}[\bxi\bxi^{\top}] = \1\1^{\top} + \mathbf{I}_n$ 与影响函数性质 $\bPsi^{\top}\1=\1^{\top}\bPsi=0$（二次型中 $\1\1^\top$ 项消失）化为 $\frac1{n^2}\sum_i\bpsi_i\bpsi_i^{\top} = \frac1{n^2} n\bH^{-1}\bF\bH^{-1}$。

最终估计量（§3.3）：$I(\mathbf{w};S) \propto n(\Bar{\btheta}_S - \btheta_0)^{\top} \bF_{\hat{\btheta}} (\Bar{\btheta}_S - \btheta_0)$，其中 $\Bar{\btheta}_S = \sqrt{\frac1K \sum_{k=1}^K \hat{\theta}_{k}^2}$（逐坐标二次平均；作者脚注解释因期望内是二次项，二次均值比算术均值更接近真值）。为避免 $D\times D$ 矩阵乘法的显存爆炸，用 FIM 定义 $\bF_{\hat{\btheta}} = \frac{1}{T} \sum_{t=1}^T \nabla_{\btheta} \ell_t(\hat{\btheta}) \nabla_{\btheta} \ell^{\top}_t(\hat{\btheta})$ 把矩阵-向量积缩为内积：

$$\widetilde{I}(\bw;S) = \frac{n}{T}\sum_{t=1}^T \left[\increment{\btheta}^{\top} \nabla_{\btheta} \ell_t(\hat{\btheta}) \right]^2,$$

即 Algorithm 1（预训练得 $\btheta_0$，SGD 过程中存梯度并用移动平均累积 $\Delta\bF_t \gets \Delta\bF_{t-1} + (\Delta\btheta^{\top}\nabla L_t)^2$，最后乘 $n/T_1$）。

## 从 PIB 最优后验到 SGLD 推断

Lemma 3（附录 B 用变分法证明）给出 PIB 的最优后验形式：对约束 $\int p(\mathbf{w}|S) d\mathbf{w} = 1$ 建 Lagrangian，对 $p(\mathbf{w}|S^*)$ 求导置零得

$$p(\bw|S^*) = \frac1{Z(S)} p(\bw) \exp \left\{-\frac{1}{\beta} \hat{L}_{S^*}(\bw) \right\} = \frac1{Z(S)} \exp \left\{-\frac{1}{\beta} U_{S^*}(\bw) \right\}, \quad U_{S^*}(\bw) = \hat{L}_{S^*}(\bw) - \beta \log p(\bw).$$

这是以 $\beta$ 为温度、$U$ 为能量的 Gibbs/Boltzmann 分布，因此可用 SGLD 采样：$\bw_{k+1} = \bw_{k} - \eta_k \mathbf{g}_k + \sqrt{2\eta_k \beta} \varepsilon_k$。作者给出其理论依据：SGLD 是 Langevin 扩散 $d \bw(t) = - \nabla U(\bw(t)) dt + \sqrt{2 \beta}dB(t)$ 的离散化，Gibbs 分布是该扩散的唯一不变分布；在 $\sum_t \eta_t \to \infty$、$\sum_t \eta_t^2 \to 0$ 且退火 $\beta$ 下，$\{\bw_k\}_{k\geq\hat{k}}$ 收敛到目标 Gibbs 分布。实现上只需在 SGD 更新中注入各向同性高斯噪声（Algorithm 2），先验项 $-\log p(\bw) \propto (\bw - \btheta_0)^{\top} \bSigma_0^{-1}(\bw - \btheta_0) + \log(\det\bSigma_0)$ 中 $\log\det$ 用特征分解 $\sum_{i=1}^D \log \lambda_i$ 计算（附录 C）。作者强调该推断不需要知道 $S$ 的真分布、理论上可避开局部极小。

## 实验证据链：从两相涌现到泛化关联再到训练收益

可解释性实验全部使用"plain cross entropy loss + SGD"训练并监测 $\widetilde{I}(\mathbf{w};S)$ 轨迹（作者刻意与 VIB 类显式信息正则训练区分开）。激活函数普适性：784-512-10 的 2 层 MLP（MNIST，Adam，学习率 1e-4）在 linear/tanh/ReLU/sigmoid 下都出现清晰的两相边界（Fig. 1）——IIW 先骤升（fitting）后缓慢下降（compression），训练损失在信息下降段继续以更缓斜率下降；压缩末期 IIW 在零附近波动并回升，作者将其与过拟合（memorization 复发）对应。这直接回应了 Saxe 等的 ReLU 反例：换成权重信息测度后两相行为在 ReLU 下仍然可见。层级实验（Fig. 2）：1 到 4 层 MLP 都有两相，1 层（softmax 回归）拟合与压缩都极慢，层越深拟合相越短，4 层末端观察到 IIW 回升的过拟合信号。宽度实验（Fig. 3）：32 个隐单元已（近乎）能插训练集，但更多单元仍改善泛化；$\ell_2$-范数随宽度持续上升，而 IIW 随宽度下降并与测试-训练精度差（泛化 gap 的经验代理）同步——作者以此论证 IIW 比 $\ell_2$ 范数更真实地反映过参数化下的复杂度。标签噪声实验（Fig. 4）：CIFAR-10 上噪声率升高时 IIW 随泛化 gap 扩大而上升；随机标签 CIFAR-10 中模型仍能近乎插值训练集（train acc 下降、test acc 保持 10%），IIW 同样捕捉到 gap 扩大。batch size 实验（Fig. 5 左）：相同迭代数与学习率下，batch size 16 达到最小 IIW 与最小泛化 gap，作者推测最优 batch size 存在于 $(4,16)$ 或 $(16,64)$ 区间并明确这是猜想（相应凸性假设的"Hypothesis 1"论证在正式文本中被注释掉，只留在附录注释里）。训练收益（Table 1）：VGG（削减两 block 以省显存）在 CIFAR10/100、STL10、SVHN 上比较 vanilla/$\ell_2$/dropout/PIB，PIB 全面最优——CIFAR10 为 $80.19(0.42)$ vs vanilla $77.03(0.57)$，CIFAR100 $56.47(0.62)$ vs $52.07(0.44)$，STL10 $58.83(0.75)$ vs $54.31(0.65)$，SVHN 差距最小（$93.88$ vs $93.57$）；Fig. 6 显示 PIB 训练的 VGG 的 IIW 全程最低。

## 边界与疑点

- IIW 泛化界 $\sqrt{2\sigma^2 I(\mathbf{w};S)/n}$ 依赖 $\sigma$-sub-Gaussian 损失假设；高斯后验/等协方差假设、$\bH\simeq\bF$（要求 $\nabla_{\hat{\by}}\ell_i\simeq0$，即接近收敛的网络）、影响函数一阶近似、Poisson bootstrap 的 $n\geq100$ 都是层层叠加的近似，作者在文中承认 IIW 计算的是近似量 $\widetilde{I}$ 而非真 $I(\mathbf{w};S)$。
- 优化 batch size 结论（16 最优）基于网格 $\{8,16,32,64,128,256,512\}$ 的有限观测，作者自己写的是猜想而非定理；对应的凸性论证（附录 Hypothesis 1）在源文本中整段被注释掉，未进入正式版本。
- 疑点：附录"C"节标题重复出现两次（"Computation for PIB object"），且其中被注释掉的内容声称 $I(\mathbf{w};Y|X,S) = L_S(\mathbf{w})$——正文 Eq. (5) 与 (6) 的"等价"依赖于这一未在正文证明的恒等式，属推断性重建而非已展示的推导。Table 1 中 CIFAR100 的 $\ell_2$ 正则（50.84）低于 vanilla（52.07），说明正则项在该数据集上未普适有效，PIB 相对 vanilla 的 $+4.4$ 点提升幅度在 SVHN 上仅 $+0.3$ 点——作者未解释这种数据集依赖性。
