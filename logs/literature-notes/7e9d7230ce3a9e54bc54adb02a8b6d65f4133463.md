# 可扩展向量高斯信息瓶颈（Scalable Vector Gaussian Information Bottleneck）

Mahvari, Kobayashi, Zaidi，arXiv:2102.07525，2021（IEEE 格式）。LaTeX 源通道，定位用章节/公式号。

## 问题设定：把 IB 表述为对数损失下的远端源编码，再加"逐级精化 + 退化边信息"结构

论文的框架定位（Introduction）：IB 本质上是对数保真度度量下的远端源编码问题——目标（标签）变量 $X$、观测变量 $Y$，编码器把 $Y$ 编为描述 $U$，在 $I(U;X)$（相关性/精度）与对 $Y$ 的描述长度（复杂度）之间权衡。本文的扩展是在此之上叠加两个通信理论结构：其一，可扩展性（scalable）——编码器输出 $T\geq2$ 个信息量递增的描述 $(U_1,\dots,U_T)$，第 $t$ 级解码器用 $(U_1,\dots,U_t)$ 加本级边信息 $Y_t$ 重构 $X$，动机是"不同复杂度预算下需要不同精度"（作者举路上移动物体为例：粗信息只识别类型 car/bicycle/bus，精化信息再给出颜色、速度等）；其二，退化边信息——满足 Markov 链

$$(X, Y) \leftrightarrow Y_T \leftrightarrow \dots \leftrightarrow Y_1,$$

即第 1 级（$Y_1$）的边信息质量最差、第 $T$ 级最好。作者说明该模型与源编码文献中带退化边信息的逐级精化问题平行，区别在于这里取远端源设定与对数损失（服务分类问题）。

可达性定义（Definition 2）：$(\Delta_1,\dots,\Delta_T,R_1,\dots,R_T)$ 可达若存在编码/解码函数使 $\Delta_t \leq \frac{1}{n} I(X^n; \psi_t(\phi_1(Y^n),\dots,\phi_t(Y^n), Y_t^n))$、$R_t \geq \frac{1}{n}\log M_t^{(t)}$；相关性-复杂度区域为全部可达元组的并。主区域（§2，由既有结果"straightforward adaptation"到远端源 + 对数损失）为

$$\sum_{l=1}^{t}R_l \geq I(Y; U_1, \dots , U_t |Y_t), \qquad \Delta_t \leq I(X;U_1, \dots, U_t, Y_t), \quad \forall t,$$

并给出替代形式（Remark 1）：在更强 Markov 链 $(X, Y_1, \dots, Y_T) \leftrightarrow Y \leftrightarrow U_T \leftrightarrow \dots \leftrightarrow U_1$ 下 $\Delta_t \leq I(X;U_t, Y_t)$——作者证明两区域在更强链下右边重合，前者用于高斯情形的逆证明，后者用于未知分布的变分情形。这里体现出推导的分工设计。

## 第一个结果：向量高斯情形的相关性-复杂度区域完全刻画

模型（§3）：$\mathbf{Y} = \mathbf{X} + \mathbf{W}_0$，$\mathbf{Y}_t = \mathbf{X} + \mathbf{W}_t$，$(\mathbf{W}_0,\mathbf{W}_t)$ 联合复高斯、协方差分块 $\begin{pmatrix}\Sigma_0 & \Sigma_{0t}\\ \Sigma_{t0} & \Sigma_t\end{pmatrix}$，约束 $\Sigma_T \preceq \dots \preceq \Sigma_1$（边信息质量递增）且 $t\neq s$ 时 $\mathbf{Y}_t,\mathbf{Y}_s$ 在给定 $\mathbf{Y}$ 下独立。定义条件协方差 $\Sigma_{0|t} \triangleq \Sigma_0 - \Sigma_{0t} \Sigma_t^{-1} \Sigma_{t0}$（无/不相关边信息时退化为 $\Sigma_0$）。Theorem 1 给出区域：存在 $0 \preceq \Omega_1 \preceq \dots \preceq \Omega_T \preceq \Sigma_{0|T}^{-1}$ 使

$$\Delta_t \leq \log \left|\Id + \left[ \Sigma_t^{-1} + (\Id - \Sigma_t^{-1}\Sigma_{t0}) \Omega_t (\Id - \Sigma_t^{-1}\Sigma_{t0}) \right] \Sigma_x \right|,$$

$$\Delta_t \leq \sum_{l=1}^{t}R_l + \log |\Id- \Omega_t \Sigma_{0|t} | + \log|\Id + \Sigma_x \Sigma_t^{-1} |.$$

证明结构（附录 A）值得展开。可达性取 $\mathbf{U}_t=\mathbf{Y}+ \mathbf{Z}_t$（$\mathbf{Z}_t \sim \mathcal{N}_{\mathbb{C}}(0, \Omega_{z_t})$ 独立于其他变量）与退化结构 $\Omega_{z_T}\preceq \dots \preceq \Omega_{z_1}$；相关性项按 $I(\mathbf{X}; \mathbf{U}_t, \mathbf{Y}_t)=\log\frac{|\cov(\mathbf{U}_t, \mathbf{Y}_t)|}{|\cov(\mathbf{W}_0+\mathbf{Z}_t,\mathbf{W}_t)|} = \log|\Id_{2m} +A^{-1}B|$ 计算（$A,B$ 为 $2m\times2m$ 分块矩阵），"直接代数"化为区域第一式；复杂度项用链式展开与 (a) 相关性约束、(b) $h(\mathbf{U}_t | \mathbf{Y}_t, \mathbf{X})=h(\mathbf{Z}_t + \mathbf{W}_0| \mathbf{W}_t)$、(c) $|A|^{-1}=|A^{-1}|$ 三步得到 $\Delta_t - \sum_l R_l$ 的下界，最后取 $\Omega_{z_t}= \Omega_t^{-1} - \Sigma_{0|t}$ 收尾。逆证明用两条引理——Fisher 信息/MMSE 夹逼（$\log |(\pi e)J^{-1}(\mathbf{X}|\mathbf{Y})| \leq h(\mathbf{X}|\mathbf{Y}) \leq \log |(\pi e)\mathrm{mmse}(\mathbf{X}|\mathbf{Y})|$）与连接引理 $\mathrm{mmse}(\mathbf{V}_2|\mathbf{V}_1,\mathbf{V}_2+\mathbf{Z})=\Sigma_z - \Sigma_z J (\mathbf{V}_2+\mathbf{Z}|\mathbf{V}_1)\Sigma_z$——把 $\Delta_t$ 的上界归到 $\mathrm{mmse}(\mathbf{Y}|\mathbf{U}^t, \mathbf{Y}_t,\mathbf{X})$，再由 $\mathrm{mmse}(\mathbf{Y}|\mathbf{U}^t, \mathbf{Y}_t, \mathbf{X}) \preceq \mathrm{mmse}(\mathbf{Y}|\mathbf{Y}_t, \mathbf{X}) =\Sigma_{0|t}$ 引入参数化 $\mathrm{mmse}(\mathbf{Y}|\mathbf{U}^t, \mathbf{Y}_t, \mathbf{X})=\Sigma_{0|t}-\Sigma_{0|t}\Omega_t\Sigma_{0|t}$。逆证明中最技巧性的一步是借助 MMSE 分解 $\mathbf{X} = \hat{\mathbf{X}}_t +\tilde{\mathbf{X}}_t$（$\Sigma_{\tilde{x}_t}^{-1} = \Sigma_x^{-1} + \Id_{m \times 2m} \Sigma_{w_0, w_t}^{-1}\Id_{m \times 2m}^\mathsf{H}$）与 Fisher 信息对估计量分解的响应把 $J(\mathbf{X}|\mathbf{U}^t, \mathbf{Y}_t)$ 写成 $\Sigma_{\tilde{x}_t}^{-1} - (P_1+P_3)(\Sigma_{0|t} - \Sigma_{0|t}\Omega_t\Sigma_{0|t})(P_1+P_3)^\mathsf{H}$。

特例校验（Remark 2）构成理论与既有结果的对接链：$T=1$ 时区域退化为带边信息单级 IB（与其文献 Theorem 3/1 一致）；标量情形显式给出 $R \geq \log \left[ \frac{\Sigma_x}{2^{-\Delta} \Sigma_x C_2 - (\Sigma_x + \Sigma_1 ) C_1 } \right]$（$C_1 = \frac{\Sigma_0 \Sigma_1 - \Sigma_{01}^2}{(\Sigma_1 - \Sigma_{01})^2}$，$C_2 = \frac{(\Sigma_x+\Sigma_1)^2}{\Sigma_x \Sigma_1} C_1 + \frac{\Sigma_x}{\Sigma_1}+1$）；再取 $\mathbf{Y}_1=\emptyset$ 得到经典高斯 IB 的相关性-复杂度权衡 $R \geq \log\left( \frac{\Sigma_x}{(\Sigma_x+\Sigma_0)2^{-\Delta}-\Sigma_0} \right)$。这一串退化关系表明新定理严格推广而非孤立结果。

数值示例（Fig. 3）给出具体数字：标量情形对称复杂度 $R=R_1=R_2$，取 $\Sigma_{0t}=\gamma\Sigma_t$（$\gamma=0.25$）、$\Sigma_x=3$、$\Sigma_0=1$、$\Delta_1=1.5$，对称边信息 $\Sigma_1=\Sigma_2=\Sigma_{\rm si}$；由 $0\leq\Omega_1\leq\Omega_2\leq\Sigma_{0|2}^{-1}$ 推出可行域 $1.64\leq\Sigma_{\rm si}\leq4$。在 $\Sigma_{\rm si}=2$（红色曲线）时第二级达到 $\Delta_2=2$ 所需最小 $R=1.42$，该复杂度下第一级最大相关性 $\Delta_1=1.78$；$\Sigma_{\rm si}=4$ 时最小 $R=1.63$ 对应 $\Delta_2=1.82$。结论：边信息噪声越小权衡越优。

## 第二个结果：未知分布下的变分上界与 DNN 参数化

当 $(X,Y,\{Y_t\})$ 联合分布未知时（§4），作者对目标 $\mathcal{L}_{\boldsymbol{\beta}}(P) = I(U_T;Y) + \sum_{t=1}^T \beta_t H(X|U_t)$（复杂度约束取总和形式、忽略边信息以简化）建立变分上界：引入任意解码分布 $\{Q_{X|U_t}\}$ 与先验 $\{Q_{U_t}\}$ 后

$$\mathcal{L}^{\rm VB}_{\boldsymbol{\beta}}(P, Q) \triangleq D_{KL}(P_{U_T|Y} || Q_{U_T}) - \sum_{t=1}^T \beta_t \mathbb{E}[ \log Q_{X|U_t}],$$

Lemma 2 证明对固定 $P$ 有 $\mathcal{L}_{\boldsymbol{\beta}}(P)\leq \mathcal{L}^{\rm VB}_{\boldsymbol{\beta}}(P, Q)$ 且唯一最优 $Q^*_{X|U_t}=P_{X|U_t}$、$Q^*_{U_t}=P_{U_t}$（附录 B：由 $\mathbb{E}[-\log Q_{X|U_t}] = D_{KL}(P_{X|U_t}||Q_{X|U_t}) + H(X|U_t)$ 与 $I(U_T;Y) = D_{KL}(P_{U_T|Y}||Q_{U_T})-D_{KL}(P_{U_T}||Q_{U_T})$ 两式直接拼合）。DNN 参数化：编码器 $P_{\boldsymbol{\theta}}(u_t|y)$、解码器 $Q_{\boldsymbol{\rho}}(x|u_t)$、先验 $Q_{\boldsymbol{\eta}}(u_t)$，经验目标 $\mathcal{L}^{\rm DNN}$ 用重参数化技巧与 $M$ 个 Monte Carlo 样本 $\{u_{t,i,j}\}_{j=1}^M$ 估计（Algorithm 1 给出 minibatch 训练流程）。

MNIST 实验（§4.2）设置具体：70000 张图像，训练 50000 张，其中比例 $\alpha$ 的图像加零均值标准差 $0.3$ 的高斯噪声（截断到 $[0,1]$）；两个测试集（无噪/带噪各 10000 张）；$T=2$ 与 $T=1$ 基线用同一 CNN（Table 1：conv[5,5,32]-maxpool-conv[5,5,64]-maxpool-dense[1024]-dropout 0.4-dense[2×latent]，解码 dense[100]-dense[10] softmax），latent 维度 $T=1$ 时 20、$T=2$ 时每级 10 以保证总复杂度对等。无噪测试中 $T=1,\alpha=0$ 最高达 $99.8\%$。关键观察：$\alpha=1/2$ 时两级方案在两个测试集上都更高；$\alpha=0$ 时 $T=1$ 模型在带噪测试集上精度随 epoch 下降至约 $40\%$（DNN 越来越拟合干净训练数据而无法预测带噪测试数据），而 $T=2$ 方案以更高复杂度为代价泛化到未见过的带噪数据。作者的解读是多级描述的粗-精结构本身具有正则化效应。

## 边界与疑点

- 解析刻画严格限定于联合高斯且分布已知、边信息满足退化 Markov 链与"给定 $Y$ 条件独立"两条结构假设；变分算法则放松分布假设但只处理总和复杂度约束并丢掉边信息（作者自述"for simplicity"），两半部分的设定并不完全衔接。
- 实验只有 MNIST 单一数据集、单一噪声水平（std $0.3$）与单一 $\beta$ 设置（正文未报告 $\beta_t$ 取值），泛化性结论的外推有限；作者在结论（被注释掉的草稿中）也承认"alternative converse proof as well as alternative encoding schemes are left as future works"。
- 疑点：附录 A 逆证明中 $P_2 = - \Sigma_{0|t} \Sigma_{0t} \Sigma_{t}^{-1}$、$P_3 = - \Sigma_{t}^{-1} \Sigma_{t0} \Sigma_{0|t}^{-1}$ 的量纲/对称性与 $P_1=\Sigma_{0|t}^{-1}$ 不匹配（推断应为 $P_2 = -\Sigma_{0|t}^{-1}\Sigma_{0t}\Sigma_t^{-1}$、$P_3 = -\Sigma_t^{-1}\Sigma_{t0}\Sigma_{0|t}^{-1}$ 之类的笔误），照录并标记；不影响定理主结论（其证明只用到 $P_1+P_3$ 的组合形式）。
- 结论章节在源文本中整段被注释掉，正式结论文字缺失；正文交叉引用宏（REF(...)）未解析，公式编号按内容定位。
