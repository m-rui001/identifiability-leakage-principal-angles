# EDMD-DL：字典可训练的扩展动态模态分解

*Extended dynamic mode decomposition with dictionary learning: a data-driven adaptive spectral decomposition of the Koopman operator · 2017 · DOI 10.1063/1.4993854（arXiv 1707.00225；Q. Li, F. Dietrich, E.M. Bollt, I.G. Kevrekidis）*

## 问题与主张

EDMD 用固定字典张成子空间近似 Koopman 算子，$N,M$ 均有限时其全部精度押在"字典张成空间近似 Koopman 不变"上；对高维强非线性系统，先验选字典既难又贵。本文把字典本身变成优化变量：求解

$$(K,\Psi)=\arg\min_{\tilde K,\tilde\Psi}\ \sum_{n=1}^N\|\tilde\Psi(y(n))-\tilde K\tilde\Psi(x(n))\|^2+\lambda(\tilde K,\tilde\Psi),$$

即**残差范数最优的字典**——与稀疏编码、Karhunen–Loève 分解"自适应基最优截断"同一精神，但这里字典函数非线性、必须数值求解。主张：自适应字典用更少的元素达到固定字典的精度。

## 算法链与两个关键设计

**参数化与交替迭代**（§A practical algorithm）：$\Psi(x)=\Psi(x;\theta)$ 用 3 层 $\tanh$ 全连接网络表示；迭代 (a) 固定 $\theta$ 解 $K=(G(\theta)+\lambda I)^+A(\theta)$（Tikhonov 正则闭式解），(b) 固定 $K$ 对 $\theta$ 做（随机）梯度下降。交替格式的收敛性"经验上稳定"但无证明——作者明说留作未来工作。

**防平凡解**是全文最容易被忽视却最要紧的一步：若存在 $\theta$ 使 $\Psi\equiv0$，损失恒为零、优化瞬间坍缩。作者的解法是字典里**必须保留固定的非可训练函数**——常数函数与坐标投影。后者还有第二个不可省的理由：算 Koopman 模态需要全状态观测量 $O(x)=x$ 落在 $U(\Psi)$ 张成空间里，投影映射不在就重构不出轨迹。这个设计决定了"网络可学的是什么"：网络学的是**增广**在恒等结构之上的不变子空间补全。

## 证据

两个指标贯穿全文：轨迹重构误差（用 Koopman 模态分解重构 $O(x)=x$）与特征函数误差 $E_j=\|\phi_j\circ f-\mu_j\phi_j\|_{L^2}$（Monte Carlo 估计）。

- **Duffing 振子**（$\alpha=1,\beta=-1,\delta=0.5$，$\tau=0.25$，$10^5$ 数据点）：EDMD-DL 用 22 个可训练 + 3 个固定元素（共 25），对比 25 个二维 Hermite 多项式与 100 个薄板样条 RBF（k-means 选心、针对此问题精心调过）。结果：25 元素的 EDMD-DL 重构精度超过同规模 Hermite EDMD，与 4 倍规模的 RBF EDMD 相当；特征函数误差 $E_j$ 同样排序。作者对低维系统的边界很清醒：Duffing 上"标准 EDMD 仍然合理"——字典学习的优势场景是字典难选的高维系统。
- **Kuramoto–Sivashinsky PDE**（$u_t+4u_{zzzz}+\alpha(u_{zz}+uu_z)=0$，$\alpha=16$，周期域；初值两参数族 $a\sin(2\pi z)+b\exp(\cos(2\pi z))$，$a\in[0.8,1],b\in[0.5,1]$）：这是字典难选的典型场景。两个手工字典——状态+四个空间导数（250 元素）、状态+Fourier 系数（150 元素）——都无法重构精细结构，且大量算出的特征值聚在 0 附近（伪谱）；EDMD-DL 用 50 可训练 + 51 固定（共 101）得到更丰富的有效谱与更好的特征函数误差。一个有洞察力的失败分析：Fourier 字典加模态**不再变好**，作者归因于 KSE 存在惯性流形——高阶 Fourier 振幅被低阶决定，纯谱基天然冗余。这解释了"为什么这个问题上手工字典结构性失败"。

## 适用条件与边界

- 交替迭代收敛无理论保证；正则项取 $\lambda\|K\|_F^2$ 为稳定性选择，未做替代项比较。
- 防平凡解依赖固定函数注入，"哪些函数必须固定"与下游任务（模态重构需要投影映射）耦合，不是纯粹的数据驱动。
- 与后续文献的关系：本文是"可学习字典 EDMD"谱系的开端之一，与 KRONIC（稀疏回归直接找特征函数）、Deep EDMD（自编码器）同属把 EDMD 的字典选择问题交给机器学习的路线；本文的定位差异在**目标函数直接是 EDMD 残差**，而非重构或多步预测误差。
- 展望部分的两条线索后来都成了独立方向：CNN 字典（平移不变特征函数，适合空间齐次 PDE、多尺度）；随机对应的 Kolmogorov 回退算子谱分解（即后来 gEDMD 处理的问题）。源文 \cite 键被剥除，公式完整可读。
