# 互信息神经估计（MINE）

原题：MINE: Mutual Information Neural Estimation（Belghazi, Baratin, Rajeswar, Ozair, Bengio, Courville, Hjelm；ICML 2018；arXiv:1801.04062）。源文本为 arXiv LaTeX 源（主文件 icml2018.tex；定位用章节/公式号）。

## 论证起点：互信息"枢纽却难算"，只有两类可解情形

论文把互信息定位为数据科学的基础量（信息瓶颈、特征选择、因果、盲源分离等），定义为联合分布对边缘乘积的 KL 散度：

$$I(X; Z) = \int_{\mathcal{X}\times\mathcal{Z}} \log\frac{d\PJ{X}{Z}}{d\PI{X}{Z}}\, d\PJ{X}{Z} = \KL{\PJ{X}{Z}}{\PI{X}{Z}},$$

并强调它不同于相关系数、能捕捉非线性依赖。计算障碍被明确限定：精确可算的只有离散变量（求和可算尽）与分布已知（如联合高斯）的有限情形；非参数或高斯近似的估计器"通常不随样本量与维度扩展"，因此不是通用估计器。论文的策略是把 GAN 社区用于 $\FDG$-散度的**对偶表示/对抗优化**思想抽出来——作者明说其主张超越 minimax：对偶优化估计散度"可以不涉及对抗博弈"，只需一个可通过反向传播训练的神经函数逼近密度比。

## 技术核心：Donsker–Varadhan 表示及其对 $f$-散度表示的优势

方法建立在 KL 的对偶表示上：

$$\KL{\PP}{\QQ} = \sup_{\FGen:\,\Omega\to\mathbb{R}} \EE_{\PP}[\FGen] - \log(\EE_{\QQ}[e^{\FGen}]).$$

对任一满足可积性约束的函数类 $\mathcal{F}$ 得到下界（作者脚注指出即 PAC-Bayes 文献中的 compression lemma），且界在最优 $T^*$ 处取紧，$T^*$ 与 Gibbs 密度相联系：$d\PP = \frac{1}{Z}e^{\FGen^*}d\QQ$，$Z=\EE_{\QQ}[e^{\FGen^*}]$。正文用注释块给出了一份被移去附录的完整证明（Gibbs 分布构造，间隙 $\Delta$ 恰为 $\KL{\PP}{\mathbb{G}}\geq 0$，因此最优统计量形如 $T^*=\log\frac{d\PP}{d\QQ}+C$）——此证明在源中处于注释状态，标注为疑点，但其结论与定理陈述一致。

与 $f$-散度表示 $\KL{\PP}{\QQ} \geq \sup_{\FGen\in\mathcal{F}} \EE_{\PP}[\FGen] - \EE_{\QQ}[e^{\FGen-1}]$（Nguyen–Wainwright–Jordan 型）相比，作者给出一个一步论证：对任意固定 $T$，把恒等式 $x \geq e\log x$ 用在 $x=\EE_\QQ[e^T]$ 上，即知 DV 界的右端**严格更大**——这直接决定了后文所有实验里 MINE 比 MINE-$\FDG$ 更紧。

## 方法：统计网络 + 一个 minibatch 偏差的工程修复

取 $\mathcal{F}=\{\FGen_\theta\}$ 为深度神经网络（"statistics network"），定义神经信息测度 $I_{\Theta}(X,Z)=\sup_{\theta} \EE_{\PJ{X}{Z}}[\FGen_\theta] - \log(\EE_{\PI{X}{Z}}[e^{\FGen_\theta}])$，则 $I(X;Z)\geq I_\Theta(X,Z)$。MINE 即其对经验分布的版本：

$$\widehat{I(X;Z)}_n = \sup_{\theta\in\Theta} \EE_{\PP^{(n)}_{XZ}}[\FGen_\theta] - \log(\EE_{\PP^{(n)}_{X}\otimes\hat\PP^{(n)}_{Z}}[e^{\FGen_\theta}]).$$

实现细节有两处对后续应用至关重要：边缘样本**直接由联合样本沿 batch 轴打乱（shuffling）得到**；DV 形式的 $\log$ 项使 minibatch 随机梯度有偏——朴素估计

$$\widehat{G}_B = \EE_{B}[\nabla_\theta T_\theta] - \frac{\EE_{B}[\nabla_\theta T_\theta\, e^{T_\theta}]}{\EE_B[e^{T_\theta}]}$$

的第二项是全 batch 梯度的有偏估计（$f$-散度形式的优点恰是 SGD 梯度天然无偏，但其估计更松）。修复方法是把分母换成指数滑动平均；作者主张学习率足够小时偏差可任意小，并报告实验中全面改善性能。

**理论性质**分两层：逼近层（Lemma approximation）由神经网络的万能逼近定理保证存在参数域 $\Theta\subset\mathbb{R}^k$ 使 $|I(X,Z)-I_\Theta(X,Z)|\leq\epsilon$；估计层（Lemma estimation）由极值估计器的经典一致性定理保证 $n\geq N$ 时 $|\widehat{I}_n - I_\Theta|\leq\epsilon$ 几乎必然成立。三角不等式合并得**强一致性定理**。样本复杂度定理在 $T_\theta$ 对参数 $L$-Lipschitz、$T_\theta$ 与 $e^{T_\theta}$ 均 $M$-有界、$\|\theta\|\leq K$ 的假设下给出 $n \geq \frac{2M^2(d\log(16KL\sqrt{d}/\epsilon)+2dM+\log(2/\delta))}{\epsilon^2}$，即 $\widetilde{O}(d\log d/\epsilon^2)$。作者另把构造平移到一般 $\FDG$-散度（经 Fenchel–Legendre 对偶），但正文明说"研究留给未来工作"（该小节在源中整体位于注释块内，正文只保留一句话的扩展说明，标注为疑点）。

## 验证实验：与 Kraskov 对打，以及 equitability

高斯实验用分量相关 $\mathrm{corr}(X_a^i,X_b^j)=\delta_{ij}\rho$ 的多元高斯（利用 MI 对连续双射变换不变，只需标准化边缘）。结果：二维时 MINE 与 Kraskov $k$-NN 估计器都"与真值几乎不可区分"；**二十维时 MINE 明显优于 Kraskov**——这正对应引言中"非参数估计器不随维度扩展"的论断。MINE 比 MINE-$\FDG$ 更紧的经验结果也与前述 $x\geq e\log x$ 论证一致。非线性实验验证 equitability：对 $Y=f(X)+\sigma\odot\epsilon$（$f\in\{x, x^3, \sin(x)\}$，$X\sim\mathcal{U}(-1,1)$），MI 只应由噪声水平 $\sigma$ 决定、与确定性非线性变换无关，MINE 的热图符合该不变性。

## 应用一（最大化 MI）：对抗模式坍缩

推理链是：模式坍缩源于生成分布缺乏多样性；理想正则是样本的 neg-entropy，但熵不可算；于是用互信息作代理——把先验写成 $Z=[\epsilon, c]$（噪声拼接码），最大化 $I(G([\epsilon,c]); c)$。生成器目标变为

$$\argmax_G \EE[\log(D(G([\epsilon, c])))] + \beta\, I(G([\epsilon, c]); c).$$

工程要点：MI 理论无上界，需自适应梯度裁剪使判别器与统计网络给生成器的学习信号量级相当（细节在附录，含 adaptive clipping 小节）。结果：spiral 与 25-Gaussians 上 GAN+MINE 的模式覆盖显著优于 $\beta=0$ 的正统 GAN（5000 迭代时基线坍缩）。定量基准 Stacked MNIST（三张 MNIST 数字堆叠、1000 模式，26,000 样本用预训练分类器数模式并算 KL）：DCGAN 99.0 模式 / KL 3.40，ALI 16.0 / 5.40，Unrolled GAN 48.7 / 4.32，VEEGAN 150.0 / 2.95，PacGAN 1000.0±0.0 / 0.06±1.0e-2，**GAN+MINE 1000.0±0.0 / 0.05±6.9e-3**——与为该问题专门设计的 PacGAN 持平。相关工作段落逐一对比时点出一个区分：InfoMax-GAN 类方法最大化码-样本互信息时是**最小化条件熵的变分上界、忽略了样本熵**，而 MINE 直接估计完整互信息。

## 应用二（最大化 MI）：双向对抗模型的重建误差界

ALI/BiGAN 同时学正向 $q(x|z)$ 与反向 $F: x\to z$。论文给出（证明在补充材料）重建误差的上界：

$$\mathcal{R} \leq \KL{q(x,z)}{p(x,z)} - I_q(x, z) + H_q(z),$$

推理是：若联合分布匹配则 $H_q(z)\to H_p(z)$（由固定先验锁死），故**最大化 $I_q(x,z)$ 即最小化期望重建误差**——这一步是原作者省略后的显式桥接（"Subsequently, maximizing..."）。训练目标在 ALI 的两个极值项上给 $F,G$ 加 $\beta I_q(x,z)$。实验用三个无似然指标（欧氏重建误差、重建准确率——预训练分类器判标签保持、MS-SSIM）在 25-Gaussians、MNIST、CelebA 上对比：MNIST 上 MINE 9.73 / 96.10% / 0.99（ALI 为 14.24 / 45.95% / 0.97；ALICE-$l_2$ 为 3.20 / 99.03% / 0.97）；CelebA 上 **MINE 36.11 / 76.08% / 0.99 全面最优**（ALICE-$l_2$ 8.01 / 32.22% / 0.93，ALICE-Adv 92.56 / 48.95% / 0.51）。定性结论诚实对称：ALICE（显式重建损失）在重建误差上有时更好，但在样本空间有明显模式丢弃；MINE"在重建与捕获全部模式之间取得平衡"（fig:bi_directional）。

## 应用三（最小化 MI）：连续设定下的信息瓶颈

IB 的 Lagrangian 写作 $\mathcal{L}[q(Z|X)] = H(Y|Z) + \beta I(X,Z)$——交叉熵项照旧，正则项（表示最小性）用 MINE 估计。推理定位：离散情形有 Blahut–Arimoto（坐标上升），连续情形长期受制于 $I(X;Z)$ 不可算；已有的 DVIB 类方法依赖变分下界近似条件熵，**要求后验密度可解**，MINE 无此要求。实验沿用 DVIB 的置换不变 MNIST 设置与经验协议，测三种编码器：高斯编码器 $z=\mu(x)+\sigma\odot\epsilon$、加性噪声编码器 $z=enc(x+\sigma\odot\epsilon)$、传播噪声编码器 $z=enc([x,\epsilon])$。结果（10 次运行平均，非 MINE 数字引自 DVIB 论文）：Baseline 1.38%，Dropout 1.34%，Confidence penalty 1.36%，Label Smoothing 1.40%，DVB 1.13%，DVB+加性输入噪声 1.06%（该对照行是为排除"收益只来自加性高斯噪声"的混淆而设）；MINE(Gaussian) 1.11%，MINE(Propagated) 1.10%，**MINE(Additive) 1.01%**。注意推理细节：MINE(Gaussian) 并未超过 DVB 的 1.13%，优势出现在不需要可解密度的加性/传播噪声编码器上——"MINE 优于变分瓶颈"的主张严格说限于这些设定，正文以"this shows MINE as being superior in these settings"限定。

## 边界与未决

- MI 对确定性连续映射（如确定性生成器 $G$）理论上可为无穷；源中相应脚注处于注释状态（建议对 $G(Z)$ 的子集算 MI 或注入噪声，并称实验未遇到此问题）——作为疑点登记，正文未系统处理。
- DV 梯度的 minibatch 偏差只有"小学习率下可任意小"的论证与 EMA 修复，无收敛速率保证；样本复杂度界依赖 $L$-Lipschitz 与 $M$-有界假设，实际统计网络的这些常数未知。
- 强一致性是渐近结论；实验中 MI 估计值用于梯度训练（作为损失），其优化动力学偏差未被单独量化。
- Stacked MNIST 与 PacGAN 打平，但 PacGAN 需要多样本判别机制；结论限于该基准。
