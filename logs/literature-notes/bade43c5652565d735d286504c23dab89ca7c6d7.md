# 科学机器学习中的不确定性量化：方法、度量与比较（Psaros, Meng, Zou, Guo & Karniadakis）

原题：Uncertainty Quantification in Scientific Machine Learning: Methods, Metrics, and Comparisons。Brown 大学应用数学系 + 上海师范大学 + PNNL。arXiv:2201.07766，DOI: 10.1016/j.jcp.2022.111902（J. Comput. Phys. 2023）。通道：tex-rescue（TeX 源，含全部附录），定位用章节/公式号；抽文引用编号丢失，见疑点。这是综述 + 框架论文 + 大规模比较研究三合一。

## 论证框架：四类问题 × 统一不确定性模型 × 方法库 × 度量体系 × 比较研究

**问题分类（Table 1）**：统一方程 $\mathcal F_{\lambda,\xi}[u(x;\xi)]=f(x;\xi)$、$\mathcal B_{\lambda,\xi}[u]=b$，$\lambda$ 为问题参数、$\xi$ 为随机事件。四个场景：(1) 前向确定性 PDE（$\mathcal F,\mathcal B$ 已知，$f,b$ 含噪数据、$u$ 未知）；(2) 混合确定性 PDE（$u,\lambda$ 部分未知，数据 $\mathcal D=\{\mathcal D_f,\mathcal D_b,\mathcal D_u,\mathcal D_\lambda\}$）；(3) 混合随机 PDE（$N$ 组带噪随机实现，目标是 $u,\lambda$ 的统计量）；(4) 算子学习（$\mathcal F,\mathcal B$ 未知且随机；预训练 + 推理两阶段，推理数据带噪有限）。作者强调术语："noisy data" 指含偶然不确定性的随机位置采样，"neural PDE" 用 NN 解已知算子、"neural operator" 用 NN 学未知算子。

**总不确定性的分解（饼图）**：数据（噪声、缺口）、物理模型（misspecification、随机性）、神经网络（架构、超参、过参数化）、后验推断。偶然不确定性来自噪声数据不可约；认知不确定性来自数据有限/噪声与 NN 过参数化。作者明确声明：除物理模型 misspecification 造成的模型误差外，其余所有不确定性都被建模、处理或讨论（附录 A 补充后验 tempering 处理 misspecification）。

**不确定性建模（§3）**：概率预测 $p(u|x,\mathcal D,\mathcal H)$（$\mathcal H$ 是用户假设集合：架构、似然等）。数据生成模型 $u(x)=u_c(x)+\epsilon_u$，似然如因子化高斯
$$p(u|x,\theta)=\mathcal N(u|u_\theta(x),\mathrm{diag}(\Sigma_u^2)).$$
贝叶斯模型平均（BMA）$p(u|x,\mathcal D)=\int p(u|x,\theta)p(\theta|\mathcal D)d\theta$ 不可精确计算，所有方法归结为取后验样本 $\{\hat\theta_j\}_{j=1}^M$ 做 MC 估计 $\bar p(u|x)=\frac1M\sum_jp(u|x,\hat\theta_j)$（高斯似然下是高斯混合），均值 $\bar\mu(x)=\frac1M\sum_ju_{\hat\theta_j}(x)$，方差分解（论文的标志性公式）：
$$\bar\sigma^2(x)=\underbrace{\Sigma_u^2}_{\bar\sigma_a^2(x)}+\underbrace{\frac1M\sum_j(u_{\hat\theta_j}(x)-\bar\mu(x))^2}_{\bar\sigma_e^2(x)},$$
即总方差 = 偶然 + 认知（后者至差因子 $M/(M-1)$ 等于样本方差；另有基于全方差定律的推导）。异方差情形把方差并入 NN 输出 $\Sigma^2_{u,\theta}(x)$，偶然项变为 $\frac1M\sum_j\Sigma^2_{u,\hat\theta_j}(x)$。PINN/DeepONet 的接入方式：PINN 对 $f,b,u,\lambda$ 四类数据各配似然，总似然为乘积；点估计 + 高斯似然即退化为标准 MSE 损失（各数据类噪声尺度可未知、随 $\theta$ 学习）；DeepONet 的 $\lambda$ 是输入（预训练阶段不易带噪），仅 $u$ 数据配似然。PINN + 贝叶斯方法称 U-PINN，DeepONet + 贝叶斯称 U-DeepONet。

## 方法库（Table 2）与统一视图（§4）

**后验采样方法八种**：HMC（两步 MCMC 模拟哈密顿动力学）、LD（一步 MCMC，带噪声的 SGD）、MFVI（因子化高斯变分分布、最大化边际似然下界）、MCD（dropout 可解释为 VI 特例：训练 + 推理时按固定比例随机置零参数）、LA（标准训练后在众数 $\hat\theta$ 处按训练误差 Hessian 拟合高斯）、DEns（$M$ 次独立标准训练）、SEns（学习率周期重启的快照集成）、SWAG（SEns 快照上拟合高斯）。组合记号：h-X = X + 异方差噪声建模；X+BNN = X + 标准 BNN 先验（默认）；X+FP = X + GAN 函数先验替代 BNN。**学习层组合**：U-PINN/h-U-PINN（解 PDE）、PI-GAN-FP（物理信息 GAN 先验 + PINN）、GP+PI-GAN（GP + PINN + GAN，前向 PDE）、U-PI-GAN、U-NNPC(+)（多项式混沌 NN 架构 + X+BNN，解 SPDE）、U-DeepONet、PA-BNN-FP / PA-GAN-FP（预训练 DeepONet + 两种先验）。**函数先验（FP，§4.3）**的动机：用历史数据先学一个解空间的先验（GAN 生成器输入 $\theta$ 的维度远小于 NN 参数），减少所需数据量与物理知识；代价是需要预训练（作者给出约 1 小时 GPU 的量级）。**统一视图（§4.5）**：所有问题与方法都可写成"物理 + 新数据 + 可能各种噪声的历史数据"的联合推断，各具体方法为特例。附录 B 给出各方法细节（MCMC 的 hyperpriors 交替优化 = 在线学习；交叉验证/meta 学习 + 验证数据 = 离线学习）。

## 评估与校准（§5）

**精度**：RL2E（相对 $\ell_2$ 误差，均值预测）；**预测能力**：MPL（平均预测似然，测试点在预测高斯 $\mathcal N(\bar\mu,\bar\sigma^2)$ 下的 PDF 值）；**统计一致性**：概率校准条件 $P(U_X\le\bar P_X^{-1}(p))=p$，度量采用 RMSCE
$$\mathrm{RMSCE}=\sqrt{\frac{1}{N_p}\sum_j\Big[p_j-\frac{1}{N_{test}}\sum_i\mathbb 1\{u_i\le\hat u(x_i)_{p_j}\}\Big]^2}.$$
作者明确指出一个实践性困难：每个 $x$ 至多一个样本，校准图只能"对不同 $x$ 取平均"产生。次要指标 PIW（预测区间宽度，锐度）与 SDCV（跨 $x$ 离散度）；gold standard 指标 NIP-G/KL-G（预测方差与金标准方差的内积/分布距离）。**事后校准（三种）**：(i) 方差重加权——优化常数 $s$，校准后 $\mathcal N(\bar\mu,s^2\bar\sigma^2)$（只改方差）；(ii) CDF 修正——用校准数据逼近失配函数 $Q(p)=P(U_X\le\bar P_X^{-1}(p))$ 并作用到所有预测 CDF（改均值与方差）；(iii) CRUDE——对缩放残差 $\epsilon_u=(u-\bar\mu)/\bar\sigma$ 拟合经验分布。作者警示：三者都是"全域平均式"校准，对 ID 或 OOD 评估都可能反而变差；且校准可能用于应对噪声模型选错等 misspecification。

## 比较研究（§6）的结果摘要

**不连续函数逼近**（$u(x)=\frac12[\sin^3(2\pi x)-1]$ 左、$\frac12[\sin^3(3\pi x)+1]$ 右，四种噪声设定）：九种方法（已知同方差高斯）、三种先验学习方法（未知噪声尺度）、四种异方差高斯（含 GAN-FP）、Student-t 噪声 + 后验 tempering。**摘要**：计算便宜 + 先验可学的方法（MFVI、LA）可与昂贵方法（HMC、DEns）性能相当；用小的留出集做事后校准可显著降低校准误差；推断中学习 NN 参数先验减轻架构选择的负担（不同架构在学习先验后结果相似）；单一指标会误导（有情形 MCD 在所用指标上远好于 HMC 但对 OOD 过度自信）；异方差建模 + 在线/离线学习（含 FP）表现满意。

**混合确定性 PDE**（非线性时间依赖扩散反应方程 $\partial_tu=D\partial_x^2u-\lambda(x)u^3+f$，标准情形 $\sigma_u=\sigma_f=\sigma_\lambda=0.05$、异方差 $0.1|x|$、大噪声 0.1、外推与陡边界层附加案例）：五方法比较（HMC、MFVI、MCD、DEns、PI-GAN-FP）。**摘要**：用源项与参数的历史数据预训练的 PI-GAN-FP 精度高于 BNN 类方法；BNN 类中昂贵的 HMC 与 DEns 更好，HMC/MFVI/DEns 能满意估计未知噪声；大噪声、单侧数据需外推、大梯度函数等困难情形下不确定性多数情况下覆盖误差。

**混合随机椭圆方程**（$-\frac{1}{10}\frac{d}{dx}(\lambda(x;\xi)\frac{d}{dx}u)=f$）：U-PI-GAN、U-NNPC、新提出的 U-NNPC+（各配 3 个独立训练的 deep ensemble）。**摘要**：U-NNPC+ 在带噪随机实现情形可胜过现有方法；但 deep ensemble + 这些方法得到的认知不确定性**可能不覆盖**一阶/二阶统计预测的误差；U-NNPC+ 相对 U-NNPC 认知不确定性更小、导致过度自信（negative finding，原文明说）。

**前向确定性 PDE**（非线性静态扩散反应 $D\partial_x^2u-\lambda u^3=f$，15 或 6 个源项数据点）：U-PINN vs 新提出的 GP+PI-GAN（先拟合源项数据、再传播不确定性到解）。**摘要**：某些情形 GP+PI-GAN 可胜过 U-PINN；但因拟合源项时不使用 PDE，可能过度自信（6 数据点情形），需进一步研究。

**算子学习**（二维非均质多孔介质流动；两种推理设定）：带噪有限推理数据用 PA-GAN-FP vs PA-BNN-FP——PA-GAN-FP 更准（如预期）但 PA-BNN-FP 无额外计算成本且更校准；干净完整推理数据用 U-DeepONet（5 个 DeepONet 独立训练的 ensemble）——对 OOD 数据均值预测比标准 DeepONet 更准、认知不确定性覆盖 ID 与 OOD 误差且 OOD 时增大。**OOD 检测**：提出三个检测指标（Table：基于预测分布宽度的量），实验显示检测指标跟踪 OOD 推理误差，可作为新输入"未见过"的红旗。

**性能 vs 成本（§6.6）**：函数逼近问题的指示性耗时（CPU/GPU 秒）：HMC 131.5/322.7、LD 44.4/269.7、MFVI 19.5/31.2、MCD 41.7/55.4、LA 60.3/77.6、DEns 359.8/494.7（$M=10$ 串行）、SEns 31.9/56.1、SWAG 36.6/61.5。HMC 约 4-5 倍标准训练（50 leapfrog steps）；LD/MFVI/MCD/SEns 与标准训练相当；DEns 并行则同串行则 $M$ 倍。有趣的工程观察：此小数据问题上 GPU 反而更慢（tensorflow probability 的动量随机数生成与 HMC 的 if/else 拒绝采样在 CPU 更高效；小数据下 PCIe 3.0 8 GT/s 的传输延迟主导）。结论段：HMC 与 DEns 预期性能最高（先验学习/超参调优可进一步增强）；便宜方法中除 LA 外校准较差、认知不确定性不随噪声增大/数据减少而一致增大；**MFVI、LA、SEns 提供良好的性能-成本折中**。给用户的四条建议：(a) 对手头问题比较多种方法；(b) 使用多种评估指标；(c) 用验证数据学习/调优先验（超参）；(d) 训练后用小留出集校准。GAN-FP 用预训练成本换推断成本下降与性能提升。

## 结论：贡献、发现与展望

**贡献**按五类问题归纳（函数逼近：FP 学异方差噪声；前向 PDE：GP+PI-GAN；混合 PDE：PI-GAN-FP + 异方差；混合 SPDE：NNPC+ 架构 + 带噪实现；算子学习：带噪/不完整推理数据处理 + OOD 检测指标）。**发现**（§7.2，原文逐条）：便宜方法 + 先验学习可与昂贵方法相当；小数据校准显著降误差；先验学习降低架构选择负担；多指标必要性（MCD vs HMC 的反例）；GP+PI-GAN 可能过自信；U-NNPC+ 的 ensemble 认知不确定性可能不覆盖统计量预测误差；PA-BNN-FP 更校准；U-DeepONet 的不确定性随 OOD 增大可驱动检测。**展望**：UQ 可扩展性（高维 + 大数据、随机梯度 + 更便宜方法、成本-效益研究）；校准 vs 主动学习的比较（稀有/极端事件需输出加权准则）；多保真训练与数据增强的 UQ；DeepONet 预训练阶段带噪输入；替代框架——evidential 框架、变分信息瓶颈、conformal prediction；数字孪生中多物理多尺度系统的多方法协同/拮抗效应评估。

## 推理重建（标明为推断）

- "统一 UQ 框架"的实际地位：论文以建模记号 + 方法组合表 + 一个概念图呈现统一性，未给出单一形式的定理或算法；作者也用 "towards a unified view/formulation" 的措辞，即方向性框架而非完成的公理化体系。
- §6.2 的 PI-GAN-FP 优势依赖历史数据可获得性；$\lambda$ 与 $f$ 的历史数据在标准情形（Table 1 问题 2）并不天然存在，该优势的适用范围以历史数据可得为前提（原文在方法节明说"pre-trained with historical data"，适用条件由我提炼）。
- U-NNPC+ 认知不确定性更小反而过度自信的机理未解释；作者只作为实验发现报告（negative finding），可能与其多项式混沌结构把随机性显式建模、留下更小的残余认知分量有关——此为我的推测。

## 限定条件与边界（原文显式）

- 物理模型 misspecification 的模型误差不在建模范围内（饼图 caption 明说）；只能通过后验 tempering（附录）部分处理。
- 校准方法"全域平均式"：对 ID/OOD 都可能使性能变差；每个 $x$ 至多一个样本使校准图只能平均化。
- 表格耗时只针对小规模函数逼近问题，"not intended for performance comparison between CPU and GPU"；$M$ 个样本的使用成本在大 NN/多评估点下不可忽略。
- DeepONet 预训练阶段不能自然处理噪声输入数据（作者列为未来方向）。
- GP+PI-GAN 的结果作者自述需进一步研究确立（"Further study is required to establish these new results"）。
- U-NNPC+ 的 ensemble 认知不确定性覆盖性失败的发现被明示为该组合的一般性风险。
