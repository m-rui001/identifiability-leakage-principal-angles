- 作者：Akil Narayan（犹他大学）等（据页眉与致谢注释推断；arXiv:1708.01296）；SIAM J. Sci. Comput.（2018，DOI: 10.1137/17M1140960）

## 论文自身的推进顺序

引言先立"非侵入式最小二乘 gPC 系数计算"的稳定性问题：等距点（Newton–Cotes 型）在不过采样时对无穷光滑无噪函数也高度不稳定。既有改进分两支——随机（Monte Carlo：张量 Legendre 需 $M\sim N^2$、张量 Chebyshev 需 $M\sim N^{\ln 3/\ln 2}$；加权最小二乘 + 平衡测度采样渐近最优、非渐近精确采样）与确定性（Fekete/Leja 型网格、Weil 点）。本文方法 CFP（Christoffel-weighted Fekete points）是 AFP（近似 Fekete 点）的加权版：贪心最大化加权行列式 $\det|\boldsymbol{W}\boldsymbol{V}\boldsymbol{V}^T\boldsymbol{W}|$，$\boldsymbol{W}$ 的对角元为 $L^2$ Christoffel 函数。论证策略是"理论收拢 + 数值证实"：第 3 节先证明"加权行列式最优 = 加权条件数最优 = 贪心可达"三个问题在最优解存在时重合（Theorem 1），再在 1D 用正交多项式三项递推 + Christoffel–Darboux 关系完全刻画最优集（Lemma 2 + Theorem 3：几乎任何起点贪心产生 Gauss 求积节点）；第 4 节给实用算法（指数扩充、候选点集、列主元 QR）；第 5 节用条件数与逼近误差两类实验对比 MC/AFP/CFP。

## 第 2 节：记号与最小二乘设定

张量域 $\Gamma = \prod_{i=1}^d\Gamma_i$、张量密度 $\rho(y)= \prod_{i=1}^d \rho_i(y_i)$；单变量正交族 $\varphi^i_n$（$\int_{\Gamma_i} \varphi^i_k \varphi^i_l \rho_i = \delta_{k,l}$），张量化 $\psi_{\alpha}(y) = \prod_{j=1}^d \varphi^{j}_{\alpha_j}(y_j)$；指标集例：全阶 $\Lambda_k^{\mathrm{TD}} = \{ \alpha : |\alpha| \leq k \}$ 与双曲交叉 $\Lambda_k^{\mathrm{HC}} = \{ \alpha : \prod_{j=1}^d (\alpha_j+1) \leq k+1 \}$。定义 Christoffel 函数与加权多项式空间：

$$K_\Lambda(y) = \sum_{\alpha \in \Lambda} \psi_\alpha^2(y),\qquad Q = Q(\Lambda) = \mathrm{span} \left\{ \frac{\psi_\alpha}{\sqrt{K_\Lambda}} \;\big|\; \alpha \in \Lambda \right\},$$

以及两类 Vandermonde 型矩阵 $\boldsymbol{V}(A_m, P)$（元 $\psi_{\alpha(k)}(y_j)$）与 $\boldsymbol{V}(A_m, Q)$（元 $\psi_{\alpha(k)}(y_j)/\sqrt{K_\Lambda(y_j)}$）。加权最小二乘（引自既有工作的推荐做法）：

$$\boldsymbol{\widehat{f}}=\arg\min_{\boldsymbol{v}}\|\boldsymbol{V}(A_M,Q)\boldsymbol{v}-\boldsymbol{W}\boldsymbol{f}\|_2,\qquad (W)_{m,m} = 1/\sqrt{K_\Lambda(y_m)},$$

即以 $1/K_\Lambda$ 为权重把离散 $L^2$ 内积对齐到连续 $\rho$-加权内积。本文的全部任务是：如何确定性地选 $A_M$。

## 第 3 节：从 Fekete 点到加权贪心设计

**Fekete 点与稳定性**：$M=N$ 时插值问题 $p(y_i)=f(y_i)$ 的良态性由 Lebesgue 常数 $\| I_N \|_{C(\Gamma) \to C(\Gamma)} = \sup_{y}\sum_n |\ell_n(y)|$ 与条件数 $\kappa(\boldsymbol{V}) = \sigma_1/\sigma_N$ 度量。行列式最大化点集（Fekete 点）通过 Lagrange 基的行列式表示给出**至多线性**的 Lebesgue 常数界（$\leq N$，实践中观察到对数增长）。定义四种点集：行列式最优 $A_N^F$、条件数最优 $A_N^C$ 及其贪心版 $A_N^{F\ast}, A_N^{C\ast}$。两个困难（原文明说）：四类点集一般互不相同；且 $\Gamma$ 非紧时这些定义失效。

**加权版的收拢（Theorem 1，本文核心理论）**：把四个问题全部搬到 $Q$ 上（只需 $\Gamma$ 内部含正测度开集，不要求紧）。则

$$\left| \det \boldsymbol{V}( A_N, Q ) \right| = 1 \iff \kappa(\boldsymbol{V}( A_N, Q )) = 1,$$

且若这样的 $A_N$ 存在、贪心起点 $y_1^{F\ast}$（或 $y_1^{C\ast}$）落在 $A_N$ 内，则贪心迭代存在一个分支恰好产出 $A_N$。证明（附录 A）核心是 Hadamard 不等式 $\left| \det \boldsymbol{A} \right| \leq \prod_i \|\boldsymbol{a}_i\|_2$（等号 iff 列两两正交）：$Q$ 空间的行向量 $\boldsymbol{\psi}(y_j)$ **自动单位化**（$\|\boldsymbol{\psi}(y_j)\|_2 = 1$，因为 $K_\Lambda(y_j)=\sum_i \psi_i^2(y_j)$ 恰是行范数平方），故行列式 = 1 当且仅当行两两正交即 $\boldsymbol{V}$ 为正交阵（条件数 1）。贪心部分用 QR 分解的体积解释：每步新增点的增益是残差向量的长度 $r = \sqrt{1 - \|\boldsymbol{b}\|_2^2}$（$\boldsymbol{b}$ 为该点与已选点的内积向量，Bessel 不等式给 $\|\boldsymbol{b}\|_2 \leq 1$），选到 $A_N$ 中的下一点即得 $r=1$。作者强调："若最优条件数点集存在"这一前提在多维下难验证（但有非平凡例子），这是定理的 caveat。

**一维情形的完全刻画（Lemma 2 + Theorem 3）**：$\Gamma = \R$、任意密度 $\rho$、$\Lambda = \{0,\ldots,N-1\}$。定义亚纯函数

$$r_N(y) = \frac{\varphi_N(y)}{\varphi_{N-1}(y)},$$

则：(1) 对任意 $y \notin \varphi_{N-1}^{-1}(0)$（共 $N-1$ 个例外点），$A_N(y) = r_N^{-1}(r_N(y))$（集值逆）是行列式/条件数双最优集；(2) 该集随 $y$ 唯一；(3) $r_N'(z)>0$（除极点）且 $\lim_{z \to \pm\infty} r_N = \pm\infty$，故 $A_N(y)$ 恰含 $N$ 个互异实点；(4) $A_N(y)$ 是对次数 $\leq 2N-2$ 多项式精确的正求积节点，$\int_\Gamma p\rho = \sum_{z\in A_N(y)} \frac{1}{K_\Lambda(z)} p(z)$；(5) 若 $y\in\varphi_N^{-1}(0)$ 则 $A_N(y)$ 是 $N$ 点 **Gauss 求积节点**。证明要点：Christoffel–Darboux 关系 $\sum_{j=0}^{n-1}\varphi_j(x)\varphi_j(z) = \frac{\sqrt{b_N}}{\varphi_{N-1}(x)\varphi_{N-1}(z)}\frac{r_n(x) - r_n(z)}{x - z}$，于是当 $r_N(y_j)=r_N(y_k)$、$y_j\neq y_k$ 时行向量正交——**同一个 $r_N$ 水平面的 $N$ 个原像自动构成正交行**。求积精确性由 $\boldsymbol{V}^T\boldsymbol{V}=\boldsymbol{I}$ 的逐分量读出 + 欧几里得除法 $p = \varphi_{N-1} q + r$ 归约。推论：1D 贪心几乎总产出最优网格/Gauss 节点——"determinant 最优、condition number 最优、贪心、Gauss 求积"四位一体。

## 第 4 节：CFP 算法

最小二乘需要 $M > N$，而贪心设计产出维数大小的点集——本文的实用处理是**先扩充指标集再算 CFP 点**（作者自认 ad hoc，不声称最优）：
1. **扩充**：$\Delta N = \lfloor 0.05N \rfloor$（所有实验统一取 5% 过采样率）；把 $\Lambda$ 按全阶分级的反字典序（graded reverse lexicographic）补到 $\widetilde{\Lambda}$（$|\widetilde{\Lambda}| = N+\Delta N$），加权空间 $\widetilde{Q} = Q_{\widetilde{\Lambda}}$。
2. **候选集**：$\widetilde{A}$ 大小 $\widetilde{M} = 10^4$，取两路随机样本之并——$\widetilde{M}/2$ 个 iid $\rho$-样本（$R_j$）+ $\widetilde{M}/2$ 个"度渐近密度"样本（$S_j$）：均匀密度时用张量 Chebyshev 密度，Gaussian 时用半径 $\sqrt{2n}$ 球内密度 $C_d \left(1 - \frac{1}{2n} \sum_{k=1}^d s_k^2\right)^{d/2}$。作者说明 $d\le 5$ 时候选网格可信、$d\gtrsim 5$ 时无法保证覆盖（本文不做改进）；弱可容网格虽好但构造随维数增长过快故弃用。
3. **贪心**：对 $\boldsymbol{V}(\widetilde{A}, \widetilde{Q})^T$ 做列主元 QR，主元序即 CFP 点序——"只需 pivoted 线代例程"。
4. **求解**：用原指标集 $\Lambda$ 的 $Q$ 做加权最小二乘。

## 第 5 节数值实验

对照组：MC（iid $\rho$ 采样）、AFP（不加权近似 Fekete 点）、CFP。条件数实验 50 次取均值 + 20%/80% 分位；误差实验 50 次、离散 $\ell_2$ 误差用 1000 个 $\rho$-随机检验点。过采样率 $M = 1.05N$。

**有界域（Legendre，$[-1,1]^d$，均匀密度）**：$d=2, 6, 10$、TD 与 HC 指标集（Figs. 1–3）——CFP 的条件数显著低于 AFP 与 MC。
**无界域（Hermite，$\rho(y) \propto \exp(-\|y\|_2^2)$）**：$d=2, 6, 10, 25$（Figs. 4–7）——CFP 在所有情形都最稳，但**高维改进幅度有限**（原文如实陈述 "the improvement is modest in high dimensions"）。
**代数函数逼近**：$f(y) = \exp(-\sum_{j=1}^d y_j^2)$。Legendre（$d=2$）：CFP 与 AFP 相当；**Hermite（$d=2$）：CFP 明显优于 MC 与 AFP，尤其高阶**（Figs. 8–9）——与条件数实验的 Hermite 结果一致。
**参数化椭圆方程**：$-\frac{d}{dx}[\kappa(x,y)\frac{du}{dx}] = 2$，$x\in(0,1)$，零边界，$\kappa(x,y)=1+\sigma \sum_{k=1}^d \frac{1}{k^2 \pi^2} \cos(2\pi k x) y_{k}$（KL 型展开），QoI 为 $u(0.5,y)$，Legendre 基（$\rho$ 均匀 $[-1,1]^d$）。$d=2, 6, 10, 25$（Figs. 10–11）：**CFP 与 AFP 相当但不更差、明显优于 MC**。

## 结论与边界（原文明说）

- 理论优势：$\Gamma$ 不必紧（AFP 的本质限制）；最优解存在时贪心 = 全局优化；1D 对任意密度几乎必然产出最优（Gauss）节点。
- 实用优势：只需列主元 QR；数值上 CFP 在低维（$d=2$）与相对高维（$d=25$）都比随机与确定性对照更稳更准。
- 边界：多维最优性依赖"单位条件数点集存在且起点落入"的不可验证假设；$M/N$ 扩充策略（5%）与候选集构造是启发式的；高维候选点覆盖不足问题未解决（作者明确承认）。
