# EDMD 收敛到 Koopman 算子：强收敛、弱谱收敛与有限时域预测

*On Convergence of Extended Dynamic Mode Decomposition to the Koopman Operator · 2018 · SIAM J. Applied Dynamical Systems（arXiv 1708.05464 系列；M. Korda, I. Mezić，UCSB）*

## 问题与主张

Williams 等的 EDMD 收敛结果有一个强假设：观测量属于 Koopman 算子的**有限维不变子空间**（此时谱包含关系立即可得）。本文的目标是去掉这个假设——"全文不对观测量属于有限维不变子空间做任何假设"，仅要求基函数取自 $L_2(\mu)$ 的正交基、Koopman 算子有界（$\mu$ 不必是不变测度，动力学甚至不必保测度；状态空间可以是任意拓扑空间，覆盖 PDE 与带控制的系统）。四条主结果：EDMD 是经验测度下的 $L_2$ 正交投影；$M\to\infty$ 与 $N\to\infty$ 的两步收敛；谱的弱收敛（沿子序列）；有限时域预测收敛。

## 推理链：投影 → 两步收敛 → 谱与预测

**第一步：EDMD 的恒等刻画**（Theorem 1）：经验测度 $\hat\mu_M=\frac1M\sum\delta_{x_i}$ 下，Gram 矩阵可逆时

$$\mathcal K_{N,M}\phi=P_N^{\hat\mu_M}\mathcal K\phi=\arg\min_{f\in\mathcal F_N}\|f-\mathcal K\phi\|_{L_2(\hat\mu_M)},$$

即 EDMD 恰是"Koopman 作用在 $\mathcal F_N$ 上的限制"向 $\mathcal F_N$ 的 $L_2(\hat\mu_M)$ 正交投影。证明是最小二乘与投影极小化问题的逐项对照（严格凸保证唯一性；矩阵奇异时 EDMD 从 $\Argmin$ 集合中选一个，解释见 Remark）。这一刻画把数值算法翻译成泛函分析对象，是后续一切收敛论证的支点。

**第二步：$M\to\infty$**（Theorem 2）：iid 采样（或遍历采样——Birkhoff 定理替换大数定律，"以概率一"改为"对几乎处处的初值"）下 $\mathcal K_{N,M}\to\mathcal K_N=P_N^\mu\mathcal K|_{\mathcal F_N}$，任何算子范数收敛，谱以 Hausdorff 度量收敛。Assumption 1（$\mu$ 不支撑在基函数线性组合的零水平集上）保证 Gram 矩阵概率一可逆——多项式、无界支撑 RBF 等常用基自动满足。

**第三步：$N\to\infty$**（Theorem 3）：把 $\mathcal K_N$ 经 $P_N^\mu$ 延拓到全空间（$\mathcal K_NP_N^\mu=P_N^\mu\mathcal KP_N^\mu$），在"$\mathcal K$ 有界 + 正交基"两个假设下**强算子拓扑收敛**到 $\mathcal K$。证明结构简单干净：正交投影强收敛到恒等（Parseval）+ $\mathcal K$ 的连续性。注意强收敛不蕴含谱收敛——这正引出第四步。

**第四步：弱谱收敛**（Theorem 4）：特征对序列 $(\lambda_N,\phi_N)$（$\|\phi_N\|=1$）有子列 $\lambda_{N_i}\to\lambda$、$\phi_{N_i}\rightharpoonup\phi$，且 $(\lambda,\phi)$ 是 Koopman 特征对——**前提是弱极限非零**。证明用 Banach–Alaoglu/Eberlein–Šmulian 紧性 + 三项分解的内积极限论证。作者用一个精心构造的例子说明"弱极限非零"不可去：恒等算子（谱 $\{1\}$）上取 $\phi_N=\sqrt2\sin(2\pi Nx)$，$\|\phi_N\|=1$ 但 $\phi_N\rightharpoonup0$——若这类高振荡函数成了 $\mathcal K_N$ 的特征函数，谱序列可以收敛到**伪特征值**。实用推论：可用 Sobolev 型范数 $\int\|\nabla\phi_N\|^2d\mu$ 等"振荡度"指标检测伪特征值。

**第五步：有限时域预测**（Theorem 5，实践核心）：对任意 $\Omega$，$\sup_{i\le\Omega}\|(\mathcal K_N)^iP_N^\mu f-\mathcal K^if\|\to0$——归纳法直接从强收敛推出。作者点明其含义：预测在任意**有限**时域上渐近精确（$L_2(\mu)$ 范数意义），无限时域不可期待；线性提升预测器 $C_NA_N^i\boldsymbol\psi_N(x_0)$ 的"线性性"正是 MPC 与状态估计应用的基础。

**副产品与极端情形**：解析版 EDMD（$T$ 与相关积分有闭式时直接构造 $A_N$，消采样误差，适合控制应用与数值研究）；$M=N$ 情形（采样在同一轨迹上、$T$ 同胚）沿子列收敛到弱特征函数/特征分布，且与 Perron–Frobenius 算子的特征测度相关——这是对"数据不足时 EDMD 到底收敛到什么"的部分回答。

## 适用条件与边界

- 两个假设的实际地位：$\mathcal K$ 有界在 $T$ 可逆 + Lipschitz + $\mu$ 绝对连续时成立，但对一般非线性 PDE 难验证（被注释掉的附录甚至尝试过去掉有界性，正文未收）；正交基假设技术上宽松（任何稠密集 Gram–Schmidt 即可）但计算上未必可行。
- 谱收敛是**弱的**：只保证子序列 + 弱极限非零；伪特征值问题没有一般解药（振荡度指标是启发式）。
- 收敛都是渐近陈述（$M,N\to\infty$），无速率；与后来具体基族（多项式、RBF）的定量速率研究互补。
- 与同簇论文的关系：本文与切换系统控制论文（引用并使用本文 Theorem 2 作为其控制等价性的跳板）、Mezić 遍历 DMD 论文（Hankel 情形、companion 矩阵路线）构成 EDMD 收敛理论的三大支柱；本文的 $L_2$ 投影刻画是其中最一般的表述。源文含 \new 修订标记与被 \iffalse 注释的无界算子一节，未作为证据；全部定理证明完整可核。
