# InfoBot：经由信息瓶颈的迁移与探索

原题：InfoBot: Transfer and Exploration via the Information Bottleneck（Goyal, Islam, Strouse, Ahmed, Botvinick, Larochelle, Bengio, Levine；ICLR 2019；arXiv:1901.10902）。源文本为 arXiv LaTeX 源（主文件 iclr_rebuttal.tex，含完整正文；定位用章节/公式号）。

## 论证起点：多目标 RL 中"对目标的信息依赖"应当被压缩

论文的问题设定是稀疏奖励下的泛化：在 $T \sim p_\text{train}(T)$ 上训练的目标条件策略 $\pi_\theta(A|S,G)$，要在相关的 $T \sim p_\test(T)$ 上表现好。作者从监督学习中的 IB 直觉（"information dropout"促进泛化）迁移过来，提出在多目标设定下最小化策略对单个目标的依赖，量化为条件互信息 $I(A;G|S)$。训练目标为

$$J(\theta) \equiv \mathbb{E}_{\pi_\theta}[r] - \beta I(A;G|S) = \mathbb{E}_{\pi_\theta}\left[r - \beta D_\text{KL}[\pi_\theta(A|S,G)\,\|\,\pi_0(A|S)]\right],$$

其中 $\pi_0(A|S)=\sum_g p(g)\pi_\theta(A|S,g)$ 是把目标边缘化后的"默认策略"。这一改写是全文概念枢纽：正则项度量的是实际策略偏离目标无关默认行为的程度。作者由此定义**决策状态（decision states）**——需要偏离默认策略、做目标依赖"决策"的状态——并把探索问题转化为：在新环境中激励 agent 寻访这些决策状态，因为它们是"达成不同目标之间的边界"。与人类认知中默认行为/控制加工的类比（驾驶通勤 vs 绕路买牛奶的例子）被作者用作该归纳偏置的间接支持，明确以"encouraging support"的弱语气表述。

## 方法：两级下界把 $I(A;G|S)$ 变成可优化的 KL

推导分三步，每步都明确给出不等式依据：

1. **DPI 上界替换**：策略被参数化为编码器 $p_\text{enc}(Z|S,G)$ 与解码器 $p_\text{dec}(A|S,Z)$（实验中实践中对 $Z$ 的边缘化用单样本估计）。由数据处理不等式 $I(Z;G|S) \geq I(A;G|S)$，压编码器的信息即压策略的信息，得到第一层下界 $J(\theta) \geq \mathbb{E}_{\pi_\theta}[r - \beta D_\text{KL}[p_\text{enc}(Z|S,G)\,\|\,p(Z|S)]]$，其中 $p(Z|S)=\sum_g p(g)p_\text{enc}(Z|S,g)$。
2. **变分近似**：实际中对目标边缘化可能不可行（可能不知道 $p(G)$、或目标连续）。用 $q(Z|S)$ 代替 $p(Z|S)$，作者写出完整推导：因 $D_\text{KL}[p(Z|s)\|q(Z|s)] \geq 0 \Rightarrow \sum_z p(z|s)\log p(z|s) \geq \sum_z p(z|s)\log q(z|s)$，替换后得到的是 $I(Z;G|S)$ 的下界——注意方向：把真边缘换成变分近似使互信息项变大，因此 $-\beta I$ 变小，仍是 $J$ 的下界。最终实用目标
$$J(\theta) \geq \tilde{J}(\theta) \equiv \mathbb{E}_{\pi_\theta}\left[r - \beta D_\text{KL}[p_\text{enc}(Z|S,G)\,\|\,q(Z|S)]\right],$$
实验中 $q(Z|S)$ 固定为标准高斯（作者注明也可学习，此时其参数应入 $\theta$）。
3. **采样轨迹上的策略梯度**：与任意 RL 算法兼容，本文用 REINFORCE（score function 估计）。时刻 $t$ 的更新为
$$\nabla_\theta \tilde{J}(t) = \tilde{R}_t \log \pi_\theta(a_t|s_t,g_t) - \beta \nabla_\theta D_\text{KL}[p_\text{enc}(Z|s_t,g_t)\,\|\,q(Z|s_t)],$$
其中修改后的奖励与回报为 $\tilde{r}_t = r_t + \beta D_\text{KL}[p_\text{enc}(Z|s_t,g)\|q(Z|s_t)]$、$\tilde{R}_t = \sum_{u=t}^{T}\gamma^{u-t}\tilde{r}_u$。作者逐项给出语义：第一项鼓励 agent 去往"高外部奖励且无需编码目标信息"的未来状态；第二项直接压当前状态的目标编码。

**两阶段迁移方案**（Algorithm algo:training）是该方法的第二支柱：先在 $p_\text{train}(T)$ 上按上式训练；然后**冻结编码器与 $q(Z|S)$、丢弃解码器**，把 $D_\text{KL}[p_\text{enc}(Z|S,G)\|q(Z|S)]$ 作为状态与目标相关的探索奖励，从头训练新策略 $\pi_\phi(A|S,G)$。为防 agent 只追奖励不追目标，用计数衰减模拟"消退效应"：组合奖励为

$$r_t = r_e(t) + \frac{\beta}{\sqrt{c(s_t)}}\, D_\text{KL}[p_\text{enc}(Z|s_t,g_t)\,\|\,q(Z|s_t)],$$

$c(s_t)$ 为状态访问计数（初始化 1）。丢弃解码器这一设计细节有对照功能：新任务的策略完全从零学起，只有"哪里是决策点"的知识经编码器迁移——这使后续与探索基线的比较更公平。

## 与既有概念的界线：T 型迷宫论证

相关工作中最有力的一步推理是对"瓶颈状态（bottleneck states）"的批判性比较：既有定义（大量奖励轨迹经过、或图论意义上分隔状态空间）会导致子目标泛滥。作者给出反例：T 型迷宫中起点在底部、两个目标在顶部两端，则**通道里所有状态都是瓶颈状态，该概念退化为平凡**；而真正的决策状态只有底部与顶部交界处一个。理由是决策状态绑定于"agent 在此需要获取目标信息"，而非 MDP 连通结构——作者的推论"决策状态是更简约准确的子目标指标"被其后的实验结果（作者自述）作为支持。作者同时诚实标注术语界限：本文与 IB 的对应并不严格——IB 最大化关于预测目标的信息（监督学习），本文最大化奖励；若换成模仿学习、把 $\mathbb{E}[r]$ 换成 $I(A^*;A|S)$，则精确对应目标 $G$ 与正确动作 $A^*$（条件于 $S$）之间的变分信息瓶颈。

## 实验：两级主张分别对齐两类证据

实验部分开宗明义列出两个待证主张：(a) 目标瓶颈训练带来更好的直接策略迁移；(b) 决策状态探索奖励优于任务无关探索方法。

**(a) 直接策略迁移。** MiniGrid 的 MultiRoom/$N_XS_Y$（$X$ 个房间、尺寸至多 $Y$，3x3 自我中心观测）与 FindObj/$S_Y$（9 房网格，7x7 观测）。在 MultiRoomN2S6 上训练、随时在 N10S4/N10S10/N12S10 上评估（fig:generalization）：泛化到 10 小房间时瓶颈 agent 近乎完美，而 vanilla 目标条件 A2C 基线只解出 **<50%**。FindObj（Table tab:generalization，S5 训练）：A2C 为 56%/36%（S7/S10），关键对照 **$\beta=0$ 的同架构 InfoBot 只有 44%/24%**，完整 InfoBot 为 **81%/61%**——$\beta=0$ 消融排除了"收益来自架构而非信息项"的混淆解释，这是论文中最干净的因果对照。行为分析给出机理：MultiRoom 中 agent 学会沿墙走（部分可观测下的可泛化策略），FindObj 中穿行于房门之间的直线——即默认策略确为跨任务可复用的习惯。

**(b) 可迁移探索。** 编码器在 MultiRoomN2S6 上训练，对新环境 N3S4/N4S4/N5S4 从头训新策略，对照计数法（去掉 KL 项的 Eqn bonused_reward）、VIME、curiosity（ICM）与 A2C（Table tab:exploration）：N3S4 上计数法与 curiosity 各 95% 略胜 InfoBot 的 90%（TRPO+VIME 54%，A2C 0%）；但 N5S4 上计数法与 VIME 归零、curiosity 降到 54%，InfoBot 保持 **85%**。作者的解读：任务无关方法不随房间数扩展，而 InfoBot 的奖励"调谐于任务族"。MiniPacMan 导航（有死胡同、分支更难；6x6 训练、11x11 评估，3 seeds 平均，Table 3）强化结论：InfoBot **64%**，对比 Actor-Critic 5%、PPO 8%、AC+计数 7%、ICM 47%、UVFA（俯视目标图）7%、UVFA（相对距离）15%、Feudal RL 37%。目标表示用相对距离或俯视图两种版本均报告。

## 认知科学映射与边界

结论前的神经科学章节把双通路架构对上"自动 vs 受控"行为选择、KL 项对上"前额叶控制的主观成本"：人类倾向走习惯路径，InfoBot 的 KL 惩罚恰好形式化了这种成本，并反过来为"控制成本为何存在"给出一个功能性解释（促进有用习惯的涌现与高效探索）。作者以"interesting connections""indirect encouragement"的措辞保持相关而非因果的语气。

边界与疑点（含源文本层面）：
- 探索结论限于 MiniGrid/MiniPacMan 这类"决策点在门口/岔口"的任务族；正文承认方法"tuned to the family of tasks"，对结构不同的任务族是否成立未验证。 Atari 上的实验在本 arXiv 源中是**整段注释掉的草稿**（含 Pong/Qbert/Seaquest/Breakout 与 5M 帧样本效率的表述），不能作为论文已主张的证据，标注为源疑点。
- 附录"Failures of the proposed method"讨论的潜在失败模式（编码器 $Z$ 可能不学目标抽象特征、而是旁路传递动作信息）同样以注释形式存在；作者称实验中未观察到但承认可能性。
- "决策状态 vs 瓶颈状态是连续谱（some states are more decisioney）"的细化也只在注释草稿中出现。
- $q(Z|S)$ 固定为单位高斯；bound 的松紧、单样本估计 $\pi_\theta=\sum_z p_\text{enc}p_\text{dec}$ 的方差影响未量化。
- 探索对比中 VIME 用 TRPO、本文用 A2C，作者注释里自己承认优化器不同使曲线未并入同一张图（正文未强调此差异，标注为疑点）。
