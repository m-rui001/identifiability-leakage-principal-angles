## 综述的定位与检索方法

主题限定：collocation 类物理信息网络家族（vanilla PINN、physics-constrained NN (PCNN)、variational hp-VPINN、conservative PINN (cPINN)），以 PINN 为代表（单数写法代表一族）。检索方法（原文明说）：Scopus 检索式 `((physic* OR physical) W/2 (informed OR constrained) W/2 "neural network")`，并聚焦 Brown 大学 CRUNCH 组与 PhILMs 中心（Karniadakis、Perdikaris、Raissi）的产出。文献计量观察（Fig. 1）：2019–2020 年 PINN 论文数增长超过 5 倍，2021 年又是 2020 年的两倍；按时间线标注各年首次被 PINN 解决的代表性问题——2017 原始论文（Allen–Cahn、KdV、1D 非线性薛定谔）→ 2019 Euler 方程 → 2020 不可压 Navier–Stokes → 2021 NSE+热方程耦合。

历史叙事：物理先验 + 机器学习可追溯到高斯过程回归推断线性算子泛函的工作；更早的直系先例是 1990 年代用双层小网络（3/5/10 节点）以配点法近似 $L^2$ 误差损失的 constrained neural network（Lagaris 等），及边界用常数项 + 可调项分解的解法（只适用规则边界，后续推广到不规则边界）；2017 年 PINN 的两篇合并版（2019）借自动微分与 TensorFlow 生态把该范式"即插即用"化。

## 构建模块一：网络架构

数学框架：$\bm{u}_{\theta}(x) = f_L \circ f_{L-1} \ldots \circ f_1(x)$；MLP 情形 $f_i (x_i ; W_i, b_i) = \alpha_i (W_i x_i + b_i)$，或写作 $\bm{u}_{\theta}(x) = C_K \circ\alpha \circ C_{K-1} \ldots \circ \alpha \circ C_1(x)$（$C_k (x_k) = W_k x_k + b_k$）。要点：
- **FFNN 主导**：文献中 PINN 主要用 5–10 层 FFNN；综述汇集的经验配置：3 隐层 ×50 tanh（原始 PINN 风格）、5–8 层 ×250（hard BC 的 PCNN）、PINNeik 用 10 层 ×20 + 局部自适应反正切激活、hp-VPINN 对双间断解从 4 层 ×20 加深到 8 层——"架构由问题决定"是综述反复出现的观察。
- **多网络**：两相 Stefan 问题用一个 DNN 表示界面 + 两个 DNN 表示两相温度；cPINN 每个子域一个网络；DeepONet 的 branch/trunk 双网结构。
- **浅网络**：ELM（只训外层权重）、X-TFC（单层 ELM 训练）、PIELM（PINN+ELM 混合，只适用线性算子）、SPINN（稀疏核网络，可解释）。
- **激活函数**：PINN 需二阶导，激活函数选择是关键——综述指出因二阶导求值需谨慎；ReLU 二阶导为 0 不宜；tanh 因无穷可微最常用（也保证泛化误差估计的正则性条件）；Swish（$x\cdot \mathrm{Sigmoid}(\beta x)$，$\beta$ 可训练）有更优收敛；无量纲化到 $[0,1]$ 而非更宽区间更好，因为 Sigmoid/Tanh/Swish 在 0 附近非线性最强。
- **CNN 系**： PhyGeoNet（坐标变换把不规则物理域映到矩形参考域、边界硬约束）；用有限差分/有限体积模板核做卷积的 PINN-CNN（padding 充当边界条件、去掉 pooling）。
- **RNN/LSTM**：结构辨识、Bouc–Wen 滞回系统等；**BNN/GAN**：贝叶斯 PINN、WGAN-GP 用于随机过程逼近；**多 PINN 集成**：cPINN（界面条件拼接、可并行、各子域可用不同架构）、Mortar PINN（非重叠域）、GatedPINN（门控网络在多个"专家"PINN 间加权）。

## 构建模块二：物理注入与损失

物理注入的机制是自动微分：残差 $r_{\theta}(\bm{z}):= \mathcal{F}( \hat{\bm{u}}_{\theta} (\bm{z}); \gamma ) - \bm{f}$、$r_\mathcal{B}:= \mathcal{B}(\hat{\bm{u}}_{\theta}) - \bm{g}$。四种求导途径（手推、符号、数值、自动）中 AD 胜出——综述强调 AD 是"解析求值"而非符号展开，无浮点精度误差；例外：分数阶算子 AD 不适用，需 L1 离散格式（fPINN 的混合方案：整数阶用 AD、分数阶用数值离散）；另一例外是 Fang 用局部拟合逼近微分算子从而获得收敛性验证（综述注"该结果在文献中相当独特"）。

损失的一般形式与三种 MSE 实现（配点/边界/数据）：

$$\mathcal{L}(\theta) = \omega_\mathcal{F} \mathcal{L}_\mathcal{F}(\theta) + \omega_\mathcal{B} \mathcal{L}_\mathcal{B}(\theta) + \omega_{d} \mathcal{L}_{data} (\theta),\qquad \mathcal{L}_\mathcal{F} = \frac{1}{N_c} \sum_{i=1}^{N_c} \|r_{\theta}(\bm{z}_i)\|^2,\quad \mathcal{L}_\mathcal{B} = \frac{1}{N_B} \sum_{i=1}^{N_B} \|\mathcal{B}(\hat{\bm{u}}_{\theta}) - \bm{g}\|^2,\quad \mathcal{L}_{data} = \frac{1}{N_d}\sum_{i=1}^{N_d}\|\hat{\bm{u}}_{\theta}(\bm{z}_{i}) - \bm{u}_i^*\|^2 .$$

综述的若干结构性观察：损失也可写成积分形式（NVIDIA Modulus 实现，可用非均匀采样高效逼近积分）；$\omega_\mathcal{F}$ 可编码 PDE 保真度（低保真模型给低权重）；设 $\omega_\mathcal{F}=0$ 退化为纯数据驱动，反之给出全部初边值即纯物理驱动——两端构成谱系。**soft vs hard 约束**：soft BC 的两大缺点（不保证精确满足、权重无理论指导）；hard BC 用网络结构精确满足 Dirichlet 条件；能量式损失比残差式更易最小化但对训练样本的大小/分辨率更敏感、PDE 式超参数更多（对比结论引自实验工作）。优化：Adam + L-BFGS(-B) 组合是主流（两步训练：先 Adam 后 L-BFGS-B）；少量数据/配点时 L-BFGS-B 收敛更快成本更低；噪声数据时增大样本量、仅用 L-BFGS 最优。初始化：先解低精度逆问题、以其参数作为正问题训练的初始化可加速收敛。

## 学习理论：三误差分解与已知结果

综述把 PINN 理论类比数值分析：想要"新 Lax 定理"（一致性 + 稳定性 $\Rightarrow$ 收敛性），但 PINN 无离散化，需在统计学习框架下重建。假设类 $\mathcal{H}_n = \{ u_\theta : \#\theta = n \}$；已知结果：tanh 网络、固定架构宽度趋于无穷时 $\hat{u}_{\theta(n)} \to u$；线性二阶椭圆/抛物 PDE 的极小化序列强收敛。三误差分解：经验风险 $\widehat{\mathcal{R}}[u_\theta] := \frac{1}{N} \sum_{i=1}^{N} \|\hat{u}_\theta(z_i) - h_i\|^2$、风险 $\mathcal{R}[\hat{u}_\theta] = \int_{\bar{\Omega}} (\hat{u}_\theta(z) - u(z))^2 \, dz$、优化误差 $\mathcal{E}_O := \widehat{\mathcal{R}}[\hat{u}_\theta^*] - \inf_{\theta} \widehat{\mathcal{R}}[u_\theta]$、泛化误差 $\mathcal{E}_G := \sup_{\theta} |\mathcal{R}[u_\theta] -\widehat{\mathcal{R}}[u_\theta]|$、逼近误差 $\mathcal{E}_A := \inf_{\theta}\mathcal{R}[u_\theta]$，全局误差界

$$\mathcal{R}[\hat{u}_\theta^*] \leq \mathcal{E}_O + 2 \mathcal{E}_G + \mathcal{E}_A .$$

具体结果：(1) 逼近误差——tanh 两隐层网络在 Sobolev 范数下 $\|\hat{u}_{\theta_N} - u\|_{W^{k,\infty}} \leq C\frac{\ln (cN)^k}{N^{s-k}}$（$u\in W^{ s,\infty} ([0,1]^d)$，网络宽度 $N^d$）；(2) NS 方程：$\mathcal{R}[\hat{u}_\theta] = \|u - \hat{u}_{\theta}\|_{L^2} \leq \left(C\widehat{\mathcal{R}}[u_\theta] + \mathcal{O}(N^{-\frac{1}{d}})\right)^{1/2}$——**该估计受维数灾难**；(3) Kolmogorov 型 PDE（热方程/Black–Scholes）：$\mathcal{R}[\hat{u}_\theta] \leq \left(C\widehat{\mathcal{R}}[u_\theta] + \mathcal{O}(N^{-\frac{1}{2}})\right)^{1/2}$，**与维数 $d$ 无关**；(4) 辐射输运方程（7 维）：$\mathcal{R}[\hat{u}_\theta] \leq \left(C\widehat{\mathcal{R}}[u_\theta]^2 + c\frac{(\ln N)^{2d}}{N}\right)^{1/2}$，维数只进对数因子——训练误差不依赖维数。综述以此说明"PINN 是否受维数灾难"依 PDE 类别而异，并列为开放问题（无形式化解释为何 PINN 计算代价常不随维数指数增长）。

## 已解微分问题谱系（按方程类型）

- **ODE**：Neural ODE（物理项 + 未知偏差项的结构辨识，4 自由度弹簧-质量、负刚度装置实验数据）；PINN+LSTM 解地震激励下非线性结构（Bouc–Wen）；Symplectic Taylor 神经网络（辛积分替代 Runge–Kutta；Lotka–Volterra、Kepler、Hénon–Heiles）。
- **稳态 PDE**：多孔介质非线性扩散 $\nabla \cdot [K(u)\nabla u]=0$ 反演 $K(u)$（PINN 优于 MAP 方法）；VPINN（分部积分降算子阶，稳态 Burgers、2D Poisson、薛定谔哈密顿量）；弹性/弹塑性非局部方法与 PDDO；Eikonal 方程（EikoNet 只对固定速度模型有效、换速度需重训——综述记为局限；各向异性 Eikonal + TV 正则学习心肌纤维取向）；Helmholtz（$\nabla^{2}E_z + \varepsilon_{r} k_{0}^{2}E_{z}=0$）。
- **扩散/相变**：复合材料固化放热（分两个子网络、Softplus/Sigmoid 输出激活按物理量值域选择）；**Stefan 自由边界问题**——三个网络（两相温度 $u_{\theta}^{(1)}, u_{\theta}^{(2)}$ + 界面 $s_{\beta}$）、四块边界损失（$\mathcal{L}_{s_{bc}}^{(k)}, \mathcal{L}_{s_{Nc}}, \mathcal{L}_{s_{0}}$），正问题精确但**逆问题因局部极小无法识别热扩散系数，需动态权重技术**（综述借该案例论证损失权重的重要性）。
- **对流**：advection-dispersion $u_t + \nabla \cdot (-\kappa \nabla u + \vec{v} u) = s$；综述特别记录一个**失败案例**：线性对流方程具有陡梯度解时 PINN 与 PIELM 都失败；cPINN 用先验激波位置做域分解捕捉陡降；PPINN（parareal：粗解算子 + PINN 细解）做长时间积分。
- **Navier–Stokes**：管腔狭窄参数扫描（active learning + FEM 数据）、drift-reduced Braginskii 等离子体湍流（从 2D 观测推 3D 湍流场）、金属增材制造熔池（hard Dirichlet + soft Neumann 表面张力）、Res-PINN（方腔/圆柱绕流；观察到压力分布形状对而幅值差的"奇怪现象"，综述原样记录）、NSFnets 的 VP 与 VV 两种形式化。
- **双曲**：无粘 Burgers、Buckley–Leverett（与 Lax–Friedrichs 格式对比）；1D Euler $\frac{\partial U}{\partial t} + \nabla\cdot f(U) = 0$（$U=[\rho, \rho u, \rho E]^T$）——**在间断附近随机散布少量配点即可捕捉激波；特征形式优于守恒形式；训练点位置至关重要**；受 Schlieren 实验摄影启发的反问题（用密度梯度与压力数据、不用 IC/BC 推断全部状态）。
- **量子**：1D NLS（$i\psi_t + \frac{1}{2}\psi_{xx} + |\psi|^2 \psi = 0$，复值解与周期边界的示范）、QHO（GatedPINN，达到谱方法精度）、耦合 NLS 的矢量孤子。
- **分数阶**：fPINN（整数阶 AD + 分数阶 L1 数值离散的混合损失），推广到时变分数阶。
- **不确定性**：B-PINN（BNN 先验 + HMC/VI 后验，量化噪声数据的 aleatoric 不确定性；算例含污染物源定位）；椭圆 SDE 的三个随机过程（$u,f,k$）随传感器配比从前向滑向反向的统一刻画；aBC-SMC 参数化 Fokker–Planck 形态景观。
- 综述还以 1D NLS 为例走一遍完整求解流程（配点选择、损失、Chebfun 参考解对比）。

## 未来挑战（综述的论证收束）

三模块框架下的问题清单：
- **理论**：PINN 是否收敛到正确解（最核心开放问题）；逼近-稳定性结果极少；F-原理（DNN 从低频到高频拟合）解释 PINN 中大尺度特征先出现、小尺度需多轮训练；初始化与损失对泛化误差的影响、非均匀/自适应配点的理论；PDE 刚度与梯度下降的关系；维数灾难为何（常）不出现；双下降风险曲线在 PINN 中是否成立；假设空间 $\mathcal{H}$ 按方程类型定制的函数空间理论；**失败模式**——PINN 失败往往不是表达力不足而是 soft PDE 约束的优化困难。
- **实现**：非 FFNN 架构研究缺口；宽度 vs 深度（是否存最小深度/宽度门槛）；可调激活函数；can-PINN（自动+数值微分混合，更省样本更准）；边界条件改变需重训网络的刚性；权重无客观确定方法、无先验的容差保证；Adam 之外的优化研究缺乏（L-BFGS-B 是"最关键的 PINN 技术"）、学习率影响未充分研究、梯度归一化/动态加权；全局误差估计只有 ODE 上的玩具级上界结果。
- **SciML 定位**：扩散/对流问题显示高对流/低黏系数下 PINN 会失败（损失地形随系数变大而复杂化，soft 约束的优化问题所致；sequence-to-sequence 式求解可降低误差）；PINN 作为线性求解器（Poisson，对标 PETSc）；与 FEM 对比——PINN 非线性逼近函数与导数、免网格、正逆问题同框架，代价是训练时间远超成熟数值方法且误差理论不完善；"超越 copy-paste"是综述对社区的核心呼吁。
