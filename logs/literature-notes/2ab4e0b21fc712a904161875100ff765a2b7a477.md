# 用变分信息瓶颈估计因果效应（Causal Effect Estimation using Variational Information Bottleneck, CEVIB）

Lu, Cheng, Zhong, Stoian, Yuan, Wang（北京理工大学 / 阿伯丁大学），2022，DOI: 10.1007/978-3-031-20309-1_25（arXiv:2110.13705，投稿时目标 IEEE TNNLS 专刊）。TeX 通道。注意：正文引用编号丢失（\cite 被剥离），涉及具体文献对比处（如 Dragonnet、CEVAE 的归属）只能依据正文残句。

## 核心主张与为什么非平凡

问题：因果效应 = 事实结果与反事实结果之差，但反事实永不可观测；RCT 可靠但昂贵且有时不可行。因此需从观测数据估计 ATE/ITE，关键难点是**识别同时影响处理 T 与结果 Y 的混杂变量**。

主张（摘要）：VIB 能"自然地从数据中蒸馏出混杂变量"，从而用观测数据估计因果效应。非平凡之处在于一个重构论证：因果推断通常需要先识别混杂因子再去除其影响，而 CEVIB 把混杂因子当作**潜变量集合**处理——假设观测协变量 X 包含所有可能原因，混杂因子是其中"同时最大程度告知 T 和 Y"的那部分信息，用 VIB 的压缩-充分权衡自动分离，无需显式识别哪些维度是混杂因子。

## 因果模型与假设（§II）

数据 D={X_i, T_i, Y_i}，T∈{0,1} 二值处理。观测数据模型（Fig.1 左）：X、T、Y 可观测，Z 是潜混杂因子，Z→T、Z→Y、X→Z。干预模型（Fig.1 右）：施加 Pearl 的 do(T)，切断混杂对 T 的影响。可识别性依赖三条标准假设（Assumptions 2.1–2.3）：一致性（T=t 则 Y=Y(t)）、正值性（∀X: P(T=0|X), P(T=1|X)∈(0,1)）、可忽略性（Y ⟂⟂ T | X）。

作者在此做了一个值得注意的桥接（原文明说）：Assumption 2.1 等价于**独立机制原则（PIM）**——系统中各条件分布互不影响。这正是"用观测数据学到的条件分布可以原封不动搬进干预模型做推断"的许可，是整个方法合法性的枢纽：训练时学的是观测模型的 conditionals，推断时按 do-演算重用它们。

ITE(x_i) = E_{Y|X,do(T_i=1)}[Y] − E_{Y|X,do(T_i=0)}[Y]（Eq.(1)），ATE ψ 是其对 X 的期望（Eq.(2)–(4)）。

## VIB 训练观测模型（§IV.1）

令 ỹ={Y,T}，优化目标（Eq.(5)–(6)）：max_θ I(Z;ỹ) s.t. I(X;Z) ≤ I_c，即拉格朗日形式 R_IB(θ) = I(Z;ỹ) − βI(X;Z)。直觉：Z 应最大程度告知"处理与结果"，同时只从 X 中保留这么多的信息——**被迫"忘记"的不是混杂因子的部分**。

变分下界（Eq.(9)）：用 q(ỹ|z) 近似后验得到可解形式 L = L_1 + L_2：
- L_1（Eq.(7)/(10)）：蒙特卡洛（M 个 ε 样本）估计 ∫p(z|x_n)[t_n log q(y_n|z,t_n=1) + (1−t_n) log q(y_n|z,t_n=0) + log q(t_n|z)]dz。这里 q(ỹ|z) = q(y|z,t=1)^t q(y|z,t=0)^{1−t} q(t|z) 照录——即结果头按处理分成两个（TARNet 式双头），另加倾向得分头。
- 参数化：p(z|x_n) = ∏_k N(z_k | μ_k(x_n), σ²_k(x_n))（对角多元正态），重参数化 z_k = f_k(x_n,ε) = μ_k(x_n) + σ_k(x_n)ε；q(y_n|·) ≈ −(y_n − g^{t_n}_θ(f(x_n,ε_m)))²，q(t_n|·) ≈ −(t_n − h_θ(f(x_n,ε_m)))²（Eq.(11)–(12)，注意这里以负平方代替高斯对数似然的完整常数项，照录）。
- L_2（Eq.(13)）：β·KL[p(z|x_n)||r(z)]，r(z)=N(0,1)，用标准 KL 恒等式 (1/2)Σ_k(σ_k²+μ_k²−1−ln σ_k²) 照录（注意 Eq.(13) 展开式中第二项原文写 μ_k(x_n) 而非 μ_k²(x_n)，为原文排版之误，照录并标疑）。

**关键的理论衔接（原文明说）**：作者推导 I(Y,T|X) 的上界（Eq.(14)），经 Jensen 不等式得到 −(1/N)Σ∫p(Z|x_n)[log p(y_n|Z)+log p(t_n|Z)]dZ，指出"VIB 下界自动满足条件独立假设"——即最小化该下界本身就在推进 Y ⟂⟂ T | X（对 X 条件、经由 Z）。这把"VIB 学到的表征就是去混杂的表征"从直觉提升为与 Assumption 2.3 相容的形式论证，是全文方法合理性主张的核心一环。【分析重建：严格地讲，这里证明的是 VIB 目标的最优解满足条件独立的必要条件方向，不等式链中使用 p(Y|Z)p(Z|X) 展开隐含了观测模型的图结构，文末未讨论近似 gap。】

## 因果效应推断（§IV.2）

训练后按 do-演算（Eq.(15)–(16)，逐步照录）：p(Y|do(T=t)) = ∫p(Y|Z,T=t)p(Z|X)p(X)dZdX ≈ ∫q(Y|Z,T=t)p(Z|X)p(X)dZdX——中间步骤依次用了干预模型结构（切断 T 的父节点）、PIM（条件分布不变）、及近似 p(Y|Z,T=t)≈q(Y|Z,T=t)。采样流程：x^(i)~p(X) → z^(i)~p(Z|x^(i)) → y_t^(i)~q(Y|z^(i),T=t)，蒙特卡洛估计 τ̂ = (1/N₁)Σy₁^(i) − (1/N₀)Σy₀^(i)。

## 实验证据（§V）

数据（均为半合成，因真值反事实不可得）：IHDP（100 个文件 × 747 被试，提供事实+反事实真值）、Twins（1989–91 美国双胞胎 11,399 人，t=1 为较重婴儿，Y 为首年死亡率）、ACIC 2018（LBIDD 衍生，30 种数据生成设定，样本 1,000–50,000）。指标：ε_ATE（平均处理效应绝对误差）、√ε_PEHE（异质效应估计精度）、相对 PEHE（消除量纲影响），公式照录。划分：IHDP/ACIC 63/27/10，重复 25 次；Twins 56/24/20，重复 50 次。

结果（Table 1，IHDP+Twins；Table 2，ACIC）：
- IHDP：CEVIB ATE out-of-s 0.15±0.02 最好（Dragon-tarreg 0.20、Dragonnet 0.21、CFRW 0.27）；√PEHE out-of-s 0.92 仅次于 CFRW 的 0.76（CFRW 的 ATE 为 0.27，明显差）——即 CEVIB 在 ATE 上全面最优、PEHE 上与最优者互补。
- Twins：CEVIB 的 ε_ATE 最好（within 0.0016±0.0009、out 0.0055±0.0018），√PEHE 略逊于 GANITE（0.297 vs 0.315）。作者表述为"among the best results"。
- ACIC（因算力限制只比 CEVAE/Dragonnet/Dragon-tarreg）：CEVIB 全面最优（如 √PEHE out 44.3 vs 62.2，ATE out 14.7 vs 24.5），量级差异显著。
- 逐文件分布图（Fig. relpehe，随机抽 10 个文件、log 相对 PEHE）：CEVIB 在全部被抽查文件上优于 Dragonnet 与 Dragon-tarreg。

**鲁棒性实验（§V.3）**：合成数据上人为控制选择偏倚——对照 5,000 样本来自 N(0, 0.5(Σ+Σ^T))，处理 2,500 样本来自 N(μ, 同协方差)，μ∈{1,2,3,4} 控制两分布 KL 距离；结果 Y=W^T X+ε。结论（原文明说，含谨慎措辞）：KL 越大误差越大（所有方法皆然）；Dragonnet 对偏倚更敏感；CEVIB 与 Dragon-tarreg 敏感度相近——"This may indicate that CEVIB and Dragon-tarreg could have a better ability to extract the latent confounders"。注意最后一句是 may/could 的推测，且 Dragon-tarreg 本身带 AIPW 目标正则，故该实验支持的结论是"与最强正则化基线相当"，而非"VIB 正则严格更优"。

## 限定与局限

- 全部实验为半合成/合成数据，真实 RCT 数据未验证；反事实真值只在半合成中存在。
- 假设 X 包含所有可能原因（无未观测混杂）——与可忽略性假设同源，真实场景无法检验；隐藏混杂是方法声称解决的"潜混杂"但仍要求混杂经 X 可达。
- T 限定二值；连续处理、多值处理未覆盖（被注释掉的 CETK 展望里提到）。
- Table 1 中 CEVIB 一行有两行数据（一行被注释掉），表明结果可能经多次调参更新，挑选过程未说明；β 的取值与扫描未在正文报告（超参表缺失）。
- L_1 的 q 定义中省略了高斯对数似然的方差项与归一化常数，且以平方损失替代——具体而言 q 的"分布"只是形式记号，实际训练目标是 MSE 式回归，作者未讨论这一近似对"q 是真实条件分布的变分近似"这一解释的影响。【分析重建，标注为推断】
- 疑点：Eq.(13) KL 展开第二项 μ_k(x_n) 缺平方（应为 μ_k²(x_n)）；正文引用编号全部丢失。
