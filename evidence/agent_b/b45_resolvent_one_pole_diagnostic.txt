实测判读（同一文件、同一次运行，seed 47813，逐位可复现；共 ~6650 个诊断样本）

[B1] 恒等式(1) 通过：**五格 resolved sign mismatches 全部 = 0/100**（raw 也是 0），
     即 D(cf) 的符号与 cf - lambda_min 的符号在这 500 个 general-Lam 样本里从不相反。
     => 'cf 站在 lambda_min 哪一侧' 由标量泛函 D(cf) = f(cf) - c^2/(1-t*cf) 单值决定，
        sign law 可以进正文。

[B2] 量级律：med|R-1| 五格 = 5.35e-06 / 3.12e-08 / 4.67e-06 / 6.85e-07 / 1.06e-04，
     最坏 1.06e-04 << 预登记的 0.05 门槛 => 诊断量不只给符号，给量级（绝对误差 4 位小数内）。
     记法：cf - lambda_min = D(cf)/|F'(xi)|，|F'| = 1 + int dnu/(x-xi)^2 >= 1，
     所以 |cf - lambda_min| <= |D(cf)| 是**严格不等式**，不是拟合。

[B3] 各向同性零检验：15 格（gamma=1/1.5/0.6 × 5 spectrum）max|D| <= 1.33e-15、
     max|gap| <= 1.41e-15 => D 在 Lam = gamma*I 时**恒等于 0**。
     这是 cor:iso 的第二条独立路径（泛函恒等，不是特征值恒等），且 gamma != 1 也成立，
     与 b44/T5、b44/T6 一致。

[B4] 修正后的对照**有效**（对照的是权重型，不是 kappa(Lam)）：
     top / ker 两族共 8 格，gap 全部在地板（2e-16 级）、max|D| <= 1.33e-15。
     与推导一致：weak 方向取 K 的 left 奇异向量 => nu 只剩**一个原子** => f == g => cf 精确。
     ker K^T 族额外给出 t - 1 = 1.33e-15（即使 delta=1e-3/1e-6）：
     即 **(Lambda - lambda I)^{-1} K = (gamma-lambda)^{-1} K** 只要 Lambda 的扰动落在 ker K^T 里。
     => cor:iso 的假设可从 'Lambda = gamma*I_p' 推广到 'Lambda = gamma*I_p + Z, ran Z ⊆ ker K^T'，
        非空当且仅当 p > q（过完备字典）。这是本轮正文里唯一'加强'而非'改标'的结论。
     诚实标注：B4 的 mism raw=(30..41) 不是反例 —— gap 与 D 同时是地板时符号是硬币，
     只有 resolved 列（此格恒为 0）可读。

[B4b] 判别格给出机制的正面证据：mid / low 十二格全部留在地板且 min slack ≈ -1e-15
     （仍是单原子：Lambda 的弱方向与 K 的 left 基对齐，权重只落在一个指标上）；
     而 'mix'（弱方向取 U[:,0]+U[:,1] 的 45°，真多原子）在 2-45-88 两格里 gap 离开地板
     （7.69e-09 / 7.02e-08，100/100 flip，|gap/lin| = 1.00e+00）。
     等角 20d 的 mix 仍在地板：等角使 E0 = R^q，slack_eff 在整空间上取 max => 恒 0。
     => 'cf 精确 ⟺ nu 单原子' 这个解释成立，但**不充要**：单原子是精确的充分条件之一，
        各向同性（B3）是另一条路，两者不互相包含。

[一阶律的可用范围，本轮唯一'意外的负面'读数]
     lin = -cf*slack/|F'(0)| 在**所有翻转格**里 |gap/lin| = 0.92~1.02（14 个 ladder 档 + B5 三格 + B4b 两格），
     但在**不翻转**的两族里 |gap/lin| = 1.3e+01 (B5 0.866/0.10)、1.26e+02/3.94e+02 (30-88-89)。
     这不是矛盾而正是预言的内容：一阶项是 -cf*slack（永远站在翻转侧），
     只有当它压过 D 的 O(cf^2) 余项时符号才真的翻；|gap/lin| 离 1 多远就是余项占优多少。
     所以正文只能写：'一阶展开解释翻转的**量级**（|gap/lin|≈1 处），
     并给出翻转的必要条件 cf*slack > 余项'，**不能**写'gap ≈ -cf*slack/|F'|'作为一般式。
