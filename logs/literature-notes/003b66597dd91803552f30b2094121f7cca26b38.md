# 半监督组织学分类：CPC 预训练 + 注意力 MIL 的两阶段管线

原题：Semi-Supervised Histology Classification using Deep Multiple Instance Learning and Contrastive Predictive Coding（arXiv:1910.10825，2019）。LaTeX 源通道，定位用章节号。

## 论证起点：MIL 在组织学上的两个失效模式

论文的推理从"为什么直接把 Deep MIL 用在组织学上会失败"展开（Introduction）。MIL 框架把每张带弱标注的图像 $X_i = \{x_1, ..., x_N\}$ 当作无序 patch 的"包"，$Y_i$ 为正在当且仅当至少一个实例为正。作者指出的困难不是泛泛的"数据少"，而是两条具体的失效链：

1. 监督信号弱 → 特征网络学不到东西。端到端训练注意力 MIL 时，特征网络只从"对包表示有实质贡献的实例"收到梯度（Method 节明说这一机制），标注图像少时弱监督信号不足以学出丰富的高层表示，模型严重过拟合。
2. 内存约束 → 训练被迫妥协。一个包包含大量实例需一次前向，组织微阵列与全切片尺寸使反向传播不可行，只能采样 patch（导致包标签噪声）或冻结特征网络省内存。

这两条失效模式恰好对应解法的两个组件：自监督预训练解决 (1)，冻结编码器解决 (2)——方法的每一半都是针对性反应，这是全文论证的内在线索。

## 两阶段方法：CPC 预训练 + 正则化注意力 MIL

**阶段一（CPC）**：利用 MIL 数据集中天然存在的大量无标注实例。按 CPC 惯例（Method 节），编码器 $g_{enc}$ 把观测编码为 $z_t$，自回归网络 $g_c$ 聚合历史得上下文 $c_t = g_c(\{z_i\}), i \le t$，目标最大化 $c_t$ 与未来 $z_{t+k}$ 的互信息，用对比损失实现：网络需在含负样本的集合中识别真正的 $z_{t+k}$，预测线性完成 $\hat{z}_{t+k} = W_k c_t$，双线性打分下损失为

$$\mathcal{L}_{\mathrm{CPC}}=-\underset{Z}{\mathbb{E}}\left[\log \frac{\text{exp}(z_{t+k}^T \hat{z}_{t+k})}{\sum_{z_{i} \in Z} \text{exp}(z_{i}^T \hat{z}_{t+k})}\right].$$

图像上的做法：栅格扫描切出小 patch 网格，总结上方若干行、自上而下预测下方未见行；同图与其他图的 patch 均可作负样本。

**阶段二（正则化 MIL）**：两处改动均针对上文失效链。其一，用平滑 margin-based SVM 损失替代交叉熵——作者以经验观察陈述（"We observed the model is less prone to overfitting"，未给出机理分析，属原文的经验性论断）。其二，注意力可能过拟合到给少数负实例分配高权重，故当包标签为负时最小化注意力分布与均匀分布的 KL 散度，鼓励平等使用负实例。注意力池化公式（Eqn 1-2）：$a_k$ 由 $\tanh(\mathbf{V}\mathbf{z}_k^\top) \odot \mathrm{sigm}(\mathbf{U}\mathbf{z}_k^\top)$ 经 $\mathbf{w}^\top$ 打分后 softmax 归一，包嵌入 $\mathbf{z} = \sum_k a_k \mathbf{z}_k$。（疑点：Eqn 1 分母中 $\operatorname{sigm}(\mathbf{U}\mathbf{z}_j^\top)$ 与分子处 $\operatorname{sigm}(\mathbf{U}\mathbf{h}_k^\top)$ 记号不一致，源文即如此，疑为排版笔误 $\mathbf{h}_k$ 应为 $\mathbf{z}_k$；照录不改。）

## 实验证据链：三组对照各验证一个主张

数据：ICIAR 2018 BACH，400 张 $2048\times1536$ H&E 染色图像，二分类（carcinoma in situ/Invasive vs Normal/Benign）；组织区域轮廓内取 $256\times256$ patch（CPC 用 50% 重叠，MIL 不重叠，Appendix A）。每个 split 100 张验证、300 张训练，类别均衡、固定种子，五次随机 split 报均值±标准差。

**对照一（损失函数与正则的作用，Table 1）**：MIL + ImageNet (CE) 准确率 84.4±9.40%、AUC 0.933±0.514；换 smooth SVM + KL 正则后 86.0±4.64%、0.939±0.240——均值略升且标准差大幅收窄。MIL + CPC (CE) 91.8±7.53%、0.959±0.052；加正则后达最优 95.0±2.65%、0.968±0.022。注意 AUC 的标准差从 0.514 降到 0.022，稳定性的改善比均值更显著——这支撑"正则主要压制过拟合"的解读（推断；原文未明说这一层）。

**对照二（预训练来源对比，Table 2）**：无预训练 MIL 仅 62.6±11.6%、AUC 0.611——直接印证引言的失效模式；ImageNet 迁移 86.0±4.64%、0.939；CPC 预训练 95.0±2.65%、0.968。CPC 优于 ImageNet 迁移约 9 个百分点，支撑"自监督能学到组织病理特异表示"的主张。

**对照三（冻结编码器）**：冻结时 MIL + ImageNet 82.8±2.95%、0.891；MIL + CPC 冻结仍达 90.6±2.88%、0.939。这直接验证主张 (2)：冻结编码器省显存后性能仍可用——冻结时整个 MIL 网络可训练参数不足 800k，作者据此声称可扩展到大图与更大包。

**数据效率曲线（Fig. data_eff）**：在全网 CPC 预训练（无监督）编码器上做半监督：每类 150 个标注是上限，用 50%（每类 75）仍达平均 AUC 超 0.94；每类仅 16 标签时平均验证 AUC 超 0.82。具体数值以曲线图给出，正文未列点值。

**注意力可视化（Fig. attention）**：网络总体关注高核密度区与单一形态细胞团、忽略脂肪组织等无信息区域；但作者明说即使分类正确，有时也漏看坏死区与可疑浸润细胞团——这是原文自报的失败模式，不是纯正面证据。

## 与既往工作的差异主张

作者声称三个"首次"：(i) 首个将 MIL 框架正式用于该弱标注 BACH 数据集；(ii) 首个在 MIL 中用平滑 SVM 损失与负包 KL 正则；(iii) 首个弱监督组织学分类中依赖 CPC 自监督特征学习的工作。对比的既往方法（Rakhlin、Golatkar 等）均为 patch 级分类器，把图像标签天真地赋给每个 patch 并依赖 ImageNet 迁移；本文不作 patch 标签假设、可处理变长包。这些首创性声明是原文自述，未逐条核验。

## 技术实现细节（Appendix B/C，支撑可复现性）

CPC 侧：$256\times256$ patch 内再取 $64\times64$、50% 重叠小 patch；编码器为去掉 BatchNorm 的 ResNet50，截断至第 3 残差块后空间池化得 1024 维向量，每个 $256\times256$ 图形成 $7\times7\times1024$ 特征网格。上下文网络为 PixelCNN 式掩码卷积："pad and downshift"操作（Masked Conv Block A 顶部补零、去底行，配掩码卷积）保证感受野只看上方行并避免原版 PixelCNN 的感受野盲区；1024→256 通道，门控激活（一半通道 tanh、一半 sigmoid、逐元素乘）；Block B 为 $3\times3$ 掩码卷积 128→256 加残差，共 11 个块，末层 $1\times1$ 卷积回 1024 维。每图预测最多 3 行未见特征；batch 16/GPU，4 块 Tesla P100，Adam lr 1e-3。MIL 侧：微调时 gated attention（256 隐单元）直接接编码器；冻结时先加一层可训练全连接把 1024 维降到 512——作者报告这层显著提升速度与性能，并推断（"likely signals"）二分类在 CPC 特征空间并非完全线性可分。训练用 Adam，微调 lr 5e-5、冻结 lr 2e-4，25 epoch 验证损失不降即早停。

## 限定条件与边界

- 结论限于 BACH 二分类（400 张图、5 个随机 split 的 25% 验证集），未在全切片图像上验证——作者自己把"扩展到 whole slide images"列为未来工作。
- "冻结编码器可扩展到大图"是基于参数量（<800k）的理论可扩展性论证，实验本身仍是 $2048\times1536$ 图。
- CPC 优于 ImageNet 迁移的结论依赖同一 ResNet50 架构（迁移学习时为一致性加回 BatchNorm 层），架构未严格控制完全相同。
- 平滑 SVM 损失的选择是经验观察，无消融隔离 KL 正则与损失各自的独立贡献（Table 1 只对比二者组合与 CE）。
