# 用随机化先验为 DeepONet 提供可扩展的不确定性量化（UQDeepONet）

原题：Scalable uncertainty quantification for deep operator networks using randomized priors（Perdikaris 组，2022，arXiv:2203.03048，发表于 CMAME）。DOI: 10.48550/arxiv.2203.03048。LaTeX 源通道，定位用章节/公式号。

## 论证起点：用一个最小反例先证明"确定性 DeepONet 不可靠"

本文的论证策略是把"为什么需要 UQ"做成一个**实验先行**的动机（§2.1）：作者构造了一个多尺度反导算子学习问题——$\frac{d s}{d x} = u(x), s(0)=0$，输入函数 $u(x)$ 从高斯过程先验采样，但输出尺度取 $k = 10^{\alpha}$、$\alpha\sim\mathcal{U}(-2,2)$，每个尺度 100 个实现共 1,000 个训练对。这一设计的用意是让不同量级的目标函数混在同一训练集中，直接打击 DeepONet 的已知软肋：未缩放的损失 $\mathcal{L}(\theta) = \frac{1}{NP}\sum_{i=1}^{N}\sum_{j=1}^P|\curlyF_{\theta}(u^i)(y_j^i) - s^i(y_j^i)|^2$ 会让大量级输出主导反向传播梯度。结果（Fig. 1 与 Table 1）给出三层证据：(1) 用 $\|s^{i}(y^i_j) \|_{\infty}^2$ 归一化的损失（Eq. 4）误差系统性更小；(2) 未缩放损失下误差随目标输出尺度减小而增大（Table 1：$\log$ 尺度 $-2.00$ 组平均误差 3.07% vs $2.00$ 组 1.81%）；(3) 全测试集最大误差约 25%——即确定性 DeepONet 的最坏情况预测不可靠。作者还引用文献指出 DeepONet 深度集成存在一个边界情形：若集成内每个网络在权重上是凸的，所有网络收敛到同一权重、不确定度为零。这四条动机（误差离群、多尺度偏置、稀缺数据、分布外样本）共同把"确定性方法在函数空间学习上缺乏可靠性"立为论题。

方法选型论证（§2.2）是排除式的：HMC 是后验推断金标准但需全数据集算 Metropolis 接受率、难以扩展；mean-field VI 低估后验方差、对多模态后验近似粗糙；dropout 不确定度粗糙；SWAG 虽有低秩近似仍难以对大网络采样；deep ensembles 校准好且可并行，但在小数据下可能过度自信且有上述零不确定度边界情形。而 randomized prior networks（Osband et al.）被选中的理由有三：预测为可训练网络加固定随机先验网络 $\hat{f}_{\theta} = f_{\theta} + \beta f_{\Theta}$（$\Theta$ 训练中冻结，$\beta$ 控制先验不确定度假门）；对高斯线性模型有收敛到真后验的一致性理论保证；近期理论结果表明其不确定度是**保守的**（conservative）且能可靠做分布外检测——"保守"正对着 deep ensembles "过度自信"的缺陷。这一节实际上为后续所有主张预先声明了评价标准：宁可保守不可自信。

## 核心构造：把随机先验分别植入 Branch 与 Trunk

§2.3 的构造很直接：在 DeepONet 前向 $\curlyF_{\theta} (u) (y) = \sum_{i=1}^n b_{i}(u) t_{i}(y)$ 的两个子网络上分别加随机先验副本，
$$\hat{b}_{\phi}(u) = b_{\phi}(u) + \beta b_{\Phi}(u), \qquad \hat{t}_{\psi}(y) = t_{\psi}(y) + \beta t_{\Psi}(y),$$
其中 $b_{\Phi}, t_{\Psi}$ 与骨干网络架构完全相同但参数随机初始化且训练中冻结；预测为 $\curlyF_{\theta}(u^*)(y^*) = \sum_{i=1}^n \hat{b}_{\phi}(u^*)_i \hat{t}_{\psi}(y^*)_i$，可训练参数 $\theta = [\phi, \psi]$ 不含 $\Phi,\Psi$。注意与标准随机先验公式 $\hat{f}_{\theta} = f_{\theta} + \beta f_{\Theta}$ 的差别：先验不是加在算子输出上，而是分别加在 branch/trunk 特征上、再经内积耦合——这意味着先验的贡献在输出空间不是简单加性的（内积产生交叉项 $b_\Phi t_\Psi + b_\phi \beta t_\Psi + \ldots$），原文未讨论这一点，为分析重建的观察。

集成统计用 MC 平均：$\mu (s|u^*,y^*) \approx \frac{1}{N_s}\sum_{i=1}^{N_s} (\curlyF_{\theta}(u^*)(y^*))_i$，$\sigma^{2}(s|u^*,y^*) \approx \frac{1}{N_s}\sum_{i=1}^{N_s} [(\curlyF_{\theta}(u^*)(y^*))_i - \mu]^2$，集成规模统一取 $N_s=512$（对照前人 DeepONet 集成只能用 5–10 个副本）。评估定义了配套的相对不确定度 $\textrm{uncertainty}_2 = \frac{\|\sigma (s|u^*, y^*)\|_2}{\|s\|_2}$，作者明说该尺度设计使其"在预测误差更高处报告更高的不确定度"——这实际上让"不确定度与误差相关"成为部分内置于指标的性质，解读校准图时应注意（分析重建）。训练的关键工程设计是分层 minibatch 采样：每次迭代随机选 $N_s$ 个标签跨全集成共享、再为集成中每个 DeepONet 取不同的 $N_b$ 大小的输入/输出对批次，大幅降低数据加载开销。超参统一：branch/trunk 各 3 隐层 × 128 神经元，Adam $l_r=10^{-3}$、每 1,000 迭代衰减 0.9、共 $5\times10^5$ 迭代，单卡 RTX A6000 上全部基准训练 6 小时。

教学例（§2.3 末）复用反导算子：UQDeepONet 的最大误差降到多数情形约 5%（确定性为 25%），且误差随输出尺度的散布被压平；误差-不确定度散点图与边缘密度显示预测准处不确定度小、误差大处不确定度同步大，作者据此称"calibrated and conservative"。$\beta$ 敏感性（附录 B）：$\beta\in\mathcal{O}(1)$（0.1、0.5、1）不敏感，过大（10）导致先验方差过大、可训练网络难以拟合数据，不确定度过度保守；全文取 $\beta=1.0$。

## 四个基准：从最坏情况鲁棒性到真实噪声数据

**反导算子-鲁棒性**（§3.1）：核心证据是最大测试误差随集成规模的饱和曲线（Table 3）：$N_s=1$（即单个网络）26.91%、2 个 20.12%、4 个 8.31%、16 个 6.26%、32 个 4.37%、64 个 4.36%、128 个 4.43%、256 个 4.51%、512 个 4.99%——饱和点在 $N_s=32$，此后最大误差稳定在约 4.4–5%，即"32 个网络换来最坏情况 6 倍误差下降，再往上加网络只花算力不降误差"。这组数字同时回答了"要多少个副本"和"随机先验解决的是尾部风险而非平均精度"两个问题（后半句为分析重建）。成本侧（附录 A）：训练 64 个网络的单卡墙钟时间仅为单个网络的 4 倍（48.66 s vs 172.53 s），512 个网络半小时训练完，近线性扩展——支撑"可扩展"主张的直接证据。

**反应扩散-分布外检测**（§3.2）：$\frac{\partial s}{\partial t} = \nu\frac{\partial^2 s}{\partial x^2} + k s^2 + u(x)$，$\nu=k=0.01$，$m=500$ 传感器、$100\times100$ 输出网格、1,000 训练对。多数测试样本预测准、方差小；被挑出的最坏样本相对误差 5.5%，其真解形态与训练/测试集主体不同，且 UQDeepONet 对它的不确定度显著高于其他样本——作者以此论证集成不确定度可作为 OOD 标志物。注意这里的"OOD"是由测试集内部的最坏样本事后辨认的，并未构造受控的 OOD 测试集来测检测率（此局限为分析重建）。

**Burgers-可靠不确定度**（§3.3）：$\frac{\partial s}{\partial t} + s\frac{\partial s}{\partial x} = \nu\frac{\partial^2 s}{\partial x^2}$（$\nu=0.01$，周期边界），初始条件采自 GRF $\mathcal{N}(0, 25^2(-\Delta + 25I)^{-2})$，Chebfun 谱求解器生成真值。代表性样本误差约 3%，且呈现"上两例准确+窄界、下两例均值欠准处不确定度变大"的对应关系。附录 C.1 给出最坏样本：相对误差 21.6%，目标函数量级极小且频率组成异于主体——均值预测失败但不确定度分布与逐点绝对误差相关良好。作者在此给出了本文最强的实用性论点：真值未知的现实场景中，不能依赖不报告置信度的确定性 DeepONet。

**气候建模-真实噪声数据**（§3.4）：学习地表气温场到气压场的黑箱算子 $T(x) \mapsto P(y)$，NCEP/PSL 再分析 2000–2010 日数据，2000–2005 训练（1,825 对，$144\times72$ 网格降采样到 $72\times72$）、2005–2010 测试（1,825 对）——测试集是时间外推。为应对数据周期性引入调和特征展开 $\xi(\bm{y}) = [\bm{y}, \sin(2\pi\bm{y}), \cos(2\pi\bm{y}), ..., \sin(2^H\pi\bm{y}), \cos(2^H\pi\bm{y})]$（$H=5$），作者称其通过缓解谱偏置显著提精度。输入输出均为含噪实测；最坏样本相对误差 13.1%，且不确定度几乎在所有预测均值与参考测量有偏差处给出真实反映。该基准把方法从合成 PDE 推到"黑箱算子+双端噪声+时间外推"的现实设定。

## 结论、边界与疑点

结论（§4）：方法在四个基准上同时给出 (1) 比确定性 DeepONet 更稳的预测、(2) 稀缺多尺度数据下的可靠不确定度、(3) OOD/对抗样本检测能力、(4) 对模型偏置与数据噪声的不确定度刻画；JAX 实现的 UQDeepONet 库使数百网络集成在单 GPU 上数小时可训。作者列出的开放方向：扩展到其他算子学习架构（FNO、LOCA）、高维输入函数域的降维、以及把 UQ 用于算子学习的数据主动获取。

适用条件与边界：UQ 机制是频率派集成式后验近似，依赖"随机先验保守"的理论性质（其一致性保证严格来说只对高斯线性模型成立，原文照录了这一限定）；不确定度只来自参数集成，无显式 aleatoric/epistemic 分解——气候例中双端噪声的影响只体现为经验性更宽的不确定度带；$u^\ast$ 必须在与训练相同的传感器位置离散化（推理约束，原文明确）；输出归一化损失是所有多尺度结论的前提；OOD 检测只有轶事性个案证据，无受控评测。

疑点清单：(1) 正文 §2.3 称先验"以完全相同的架构"初始化，但文中存在残句 "not a concept is only applicable"（§4 讨论）等语法噪音，系抽文问题；(2) 集成规模饱和点 32 与摘要"数百集成"之间的张力：512 副本相对 32 副本无精度收益，原文未解释为何固定 $N_s=512$（分析重建的疑问）；(3) 相对不确定度指标 $\|\sigma\|_2/\|s\|_2$ 与相对误差同尺度，"uncertainty 反映误差"的图证部分源于指标构造本身；(4) 气候基准测试集为 2005–2010 时间外推，但正文未单独报告外推期的误差分布，只在附录 C.2 给最坏个案。
