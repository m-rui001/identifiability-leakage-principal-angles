# 加速副本交换随机梯度 Langevin 扩散增强的贝叶斯 DeepONet 求解含噪参数化 PDE

原题：Accelerated replica exchange stochastic gradient Langevin diffusion enhanced Bayesian DeepONet for solving noisy parametric PDEs（2021，arXiv:2111.02484，后发表于 JCP 2022）。DOI: 10.48550/arxiv.2111.02484。LaTeX 源通道，定位用章节/公式号。

## 论证起点：DeepONet 的阿喀琉斯之踵是噪声目标

引言的推理路线是"优点翻转为缺陷"（§1）：DeepONet 用 Branch/Trunk 双子网络逼近算子、在较小数据集上就有很好的逼近与泛化，但此前所有工作**都用无噪数据训练**；实践中算子训练目标 $\{\tilde{G}^\dagger_i\}$ 常被噪声或数值误差污染，而梯度类算法（如 Adam）"倾向于追逐噪声"，导致泛化差。因此作者的问题被限定为：给 DeepONet 配一个能在噪声下训练并附带不确定度估计的贝叶斯框架。作者声称这是第一篇解决"噪声数据训练 DeepONet"的工作。

目标 PDE 为参数化原型 $(\mathcal{L}_a s)(x) = f(x), x\in D$，$a: D\to\mathbb{R}$ 为进入算子定义的参数；解算子 $G^\dagger$ 把输入函数 $u$（可为参数、源项或初/边值）映到输出函数。DeepONet 结构（§2.1）：Branch Net 吃 $u$ 在 $m$ 个传感器上的离散值 $(u(x_1),\ldots,u(x_m))$、输出特征 $b\in\mathbb{R}^q$；Trunk Net 吃查询点 $y\in Y$、输出 $t =(\varphi_1(y),\ldots,\varphi_q(y))$，可解释为 $Y$ 上的一组基函数；输出为内积
$$G_\theta \left(u(x_1),\ldots,u(x_m)\right)(y) := \langle b,t \rangle = \sum_{i=1}^{q} b_i \cdot \varphi_i(y),$$
即 Branch 输出 $b$ 是 Trunk 基函数的可训练系数。这一"线性逼近方法"的解读（DeepONet 经由 $\text{span}\{\varphi_1(y), \dots, \varphi_q(y)\}$ 张成的线性空间逼近非线性算子空间）是后面加速设计的理论支点，作者在此处已埋下伏笔。

## 贝叶斯设定与 reSGLD：从 Langevin 扩散到无偏交换率

§3 的贝叶斯化是直接的：目标 $\tilde{G}^\dagger_i = G^\dagger(u_i)(y_i) + \epsilon_i$，$\epsilon_i \sim \mathcal{N}(0, \sigma^2)$ 且标准差**已知**；似然
$$P(\mathcal{D}|\theta) = \prod_{i=1}^N \frac{1}{\sqrt{2 \pi \sigma^2}} \exp \left( - \frac{(G_\theta(u_i)(y_i) - \tilde{G}^\dagger_i)^2}{2 \sigma^2} \right),$$
后验 $P(\theta | \mathcal{D}) \propto P(\mathcal{D}| \theta) P(\theta)$。预测用 $M$ 个后验参数样本的集成 $\{\theta_k\}_{k=1}^{M}$，取均值作点预测、标准差作不确定度。

采样器的推导链分三步（§3.2–3.3），这是本文方法部分真正的推理核心：

1. **Langevin 扩散**：$d \theta_t = -\nabla U(\theta_t)+\sqrt{2\tau}dB_t$，能量 $U(\theta) \sim -\log P(\theta) - \sum_{i = 1}^N \log P(\tilde{G}^\dagger_i|\theta)$。在适当假设下 $\{\theta_t\}$ 收敛到 $\pi_{\mathcal{D}} \sim \exp( - U(\theta)/\tau )$；$\tau$ 小时分布集中在能量极小点 $\theta^*$ 附近——于是"优化"被转写为"低温采样"。温度的微观含义构成 exploration–exploitation 二难：低温粒子在局部快速收敛（exploit），高温粒子全局游走、能跳出局部极小（explore）。
2. **副本交换**：两个粒子配两个温度 $\tau_1$（低）、$\tau_2$（高），$d \theta_t^1 = -\nabla U(\theta_t^1)+\sqrt{2\tau_1}dB_t^1$、$d \theta_t^2 = -\nabla U(\theta_t^2)+\sqrt{2\tau_2}dB_t^2$；按速率 $r(\theta^1_t, \theta^2_t) = e^{\tau_{\delta}(U(\theta_t^1) - U(\theta_t^2)) }$（$\tau_\delta = \frac{1}{\tau_1} - \frac{1}{\tau_2}$）交换，交换后的 Markov 过程收敛到不变分布 $\pi(\theta^1, \theta^2) \propto e^{-\frac{U(\theta^1)}{\tau_1}-\frac{U(\theta^2)}{\tau_2}}$。交换的作用是让低温粒子借高温粒子的"探索"逃出局部极小。
3. **噪声能量的无偏交换率**：实践中 $U$ 只能用 mini-batch 估计 $\hat{U}(\theta) = -\log P(\theta) - \frac{N}{n}\sum_{i = 1}^n \log P(\tilde{G}^\dagger_{s_i}|\theta)$，且假设 $\hat{U}(\theta) \sim \mathcal{N}(U(\theta), \sigma_e^2)$。关键论证：把**有噪的能量估计器**直接代进交换率会造成交换率估计的大偏差，修正方案是双估计器平均加方差修正项：
$$\Hat{r} = e^{\tau_\delta\bigg(a_1\big(\Hat{U}_1(\theta^1)-\Hat{U}_1(\theta^2)\big)+a_2\big(\Hat{U}_2(\theta^1)-\hat{U}_2(\theta^2) \big) - (a_1\sigma_1 + a_2\sigma_2)^2\tau_\delta \bigg)}, \quad a_1+a_2=1,$$
带此无偏率的算法即 reSGLD（$\sigma_1=\sigma_2$）或 m-reSGLD（$\sigma_1\ne\sigma_2$）。这一步是从"理论 sampler"到"可运行算法"的桥，也是本文相对 re-LD 的方法学增量（继承自作者前作的 m-reSGLD 思想）。

## 加速设计：只随机训一半网络的依据

§4 处理 reSGLD 的代价问题：两个粒子使每迭代计算量翻倍。加速方案（Algorithm 2）：burn-in 后，低温粒子 $\theta^1$（负责 exploit）保持全参数训练，高温粒子 $\theta^2$（负责 explore）改为每步以概率 $c$ 只训 Branch Net 或只训 Trunk Net（$c>0.5$ 偏向 Branch）。理论依据是过参数化网络梯度训练中"参数几乎不动而训练损失指数归零"的收敛结果，及作者的经验观察"DeepONet 指数快速收敛到零训练损失"——由此推断让一部分参数近似冻结也应能收敛。**为什么优先训 Branch**：因为 Branch 输出 $b$ 是 Trunk 所张线性空间的系数，DeepONet 属线性逼近方法类，系数比基函数更值得频繁更新。代价上界有简单论证：若两子网规模相同，$\theta^2$ 的计算至多减半，总体至多省 25%。由于两粒子能量估计方差不再相同，算法自然落入 m-reSGLD 名下——加速与"多方差"机制在此闭环（这是分析重建的连接，原文分别陈述）。

## 四个算子实验：误差、覆盖率与时间的系统三角

实验（§5）统一协议：反导算子 $\frac{ds}{dt} = u(t)$、重力摆 $\frac{ds_1}{dt} = s_2, \frac{ds_2}{dt} = -k \sin(s_1) + u(t)$（$k=1$）、扩散反应 $\frac{\partial s}{\partial t} = D \frac{\partial^2 s}{\partial x^2} + k s^2 + u(x)$（$k=-0.01$）、周期边界对流扩散 $\frac{\partial s}{\partial t} + \frac{\partial s}{\partial x} - D \frac{\partial^2 s}{\partial x^2} = 0$（$D=0.1$，$s(x,0)=u(x)$）。输入 $u$ 均为 RBF 核（$l=0.2$）GRF，$m=100$ 传感器；训练 8,000 epochs；指标为 100 条测试轨迹上的相对误差均值 $e_1 = \frac{\|v_u-w_u\|_1}{\|w_u\|_1}100$、$e_2 = \frac{\|v_u-w_u\|_2}{\|w_u\|_2}100$，以及 95% 置信区间覆盖率 $e_3 = \frac{\text{区间内真解点数}}{\text{真解网格点数}} 100$。三方对照：Adam、reSGLD、m-reSGLD（Adam 的不确定度用 dropout 非贝叶斯策略）。

反导算子（§5.1）：小噪声 $\mathcal{N}(0,0.01^2)$ 下 burn-in 后平均误差 $e_1$：Adam 13.099 vs reSGLD 6.954 vs m-reSGLD 7.828——贝叶斯框架把误差砍掉近一半；$e_3$ 三者均 100%，但 Adam 的置信带更宽（过度估计不确定度）。加噪到 $\mathcal{N}(0,0.05^2)$：Adam 14.878 / reSGLD 11.970 / m-reSGLD 11.368，此时 m-reSGLD 反超 reSGLD。每迭代时间：m-reSGLD 分别为 reSGLD 的 80.1% 与 76.9%，接近 25% 理论上界且不牺牲精度。

重力摆（§5.2）：小噪声 $e_1$：Adam 16.857 / reSGLD 6.215 / m-reSGLD 6.700，且 $e_3$ 出现分化：Adam 71%（带更宽的带却漏掉部分真轨迹）、reSGLD 100%、m-reSGLD 100%——"带宽更宽但覆盖更差"是 dropout 不确定度校准失败的直接证据。加噪后 $e_1$：18.894 / 12.614 / 12.300；$e_3$：Adam 77%、reSGLD 93%、m-reSGLD 100%。时间比 79.06% 与 80.8%。

扩散反应（§5.3）：这是 Adam 表现最差的算子——小噪声 $e_1$：31.855 / 9.644 / 11.344，$e_3$：71% / 100% / 100%；大噪声 $\mathcal{N}(0,0.1^2)$ 下 $e_1$：31.955 / 11.671 / 9.041，$e_3$：68% / 100% / 100%。Adam 在该算子上误差超过 30% 且几乎不随噪声变化，说明其失败主因不是噪声而是损失景观的局部极小（后一句为分析重建；原文只陈述数值与"噪声更有效被处理"的结论）。时间比 83.0% 与 81.5%。

对流扩散（§5.4）：小噪声 $e_1$：14.352 / 8.926 / 7.341，$e_3$ 100% / 99% / 100%（reSGLD 唯一一次不到 100%）；大噪声 $e_1$：21.514 / 11.246 / 14.255（此处 m-reSGLD 劣于 reSGLD，是全文唯一明显的加速反例，原文未单独讨论），$e_3$ 均 100%。时间比 79.44% 与 80.2%。

汇总结论（§5.4 末、§6）：reSGLD/m-reSGLD 在全部四算子上收敛更快、均值预测更准（噪声越大优势越明显）、$e_3$ 覆盖普遍 100% 而 Adam 在 68–77% 间波动且置信带更宽；m-reSGLD 省 17–23% 计算时间（接近 25% 上界），部分算子上甚至比 reSGLD 更准。作者把"贝叶斯采样器的均值预测也优于 Adam"标记为 remarkable——其机理归因于副本交换逃离局部极小的能力（这是原文反复使用的解释，未给出独立的机理验证实验）。

## 适用条件与疑点

适用条件：输出端高斯噪声且标准差已知（似然形式所需）；不确定度来自参数后验集成（$M$ 样本），只量化 epistemic 项，无 aleatoric 分解；加速机制依赖 DeepONet 的 Branch/Trunk 分解与"DeepONet 收敛快、部分参数可冻结"的经验性质，作者明说加速框架的理论分析留待未来工作；实验限于 1D 空间的四个算子、GRF 输入、单一网络规模，未测高维 PDE 或真实数据。

疑点清单：(1) Algorithm 1（reSGLD）中交换率写为 $\hat{r} = e^{\tau_\delta ((a_1-a_2)(\hat{U}_1 - \hat{U}_2) - (a_1\sigma_1+a_2\sigma_2)^2\tau_\delta)}$，与 §3.3 正文的 $\hat{r} = e^{\tau_\delta(a_1(\Hat{U}_1(\theta^1)-\Hat{U}_1(\theta^2))+a_2(\Hat{U}_2(\theta^1)-\hat{U}_2(\theta^2)) -\cdots)}$ 形式不一致（正文为双估计器平均，伪代码为一估计器乘 $(a_1-a_2)$），疑为伪代码排版错误；(2) 若干图 caption 噪声标注与正文矛盾：重力摆大噪声图 caption 写 "$\mathcal{N}(0, 1^2)$" 而正文为 $\mathcal{N}(0,0.05^2)$，对流扩散大噪声 caption 亦写 "$\mathcal{N}(0, 1^2)$" 而正文为 $\mathcal{N}(0,0.1^2)$；(3) Experiment 4 小噪声 caption 误写 "gravity-pendulum"；(4) 扩散反应方程的边界条件写作 "$u(x,t)=0$"，应为 $s$ 的边界条件，疑为符号笔误；(5) 摘要 "Langeving Diffusion"、"desing" 等拼写噪音；(6) 疑似缺失 burn-in epoch 数、$M$ 与 $\tau_1,\tau_2$ 等超参数值的明确记录，复现性受影响（分析重建）。
