# 基于贝叶斯神经网络的 PDE 弱解求解与不确定性量化

原题：Bayesian neural networks for weak solution of PDEs with uncertainty quantification（2021，arXiv:2101.04879，mechanoChem 团队，Toyota Research Institute 资助）。DOI: 10.48550/arxiv.2101.04879。LaTeX 源通道，定位用章节/公式号。

## 论证起点：为什么不用强形式、为什么 BC 要进输入

论文的问题设定不是"解一个 PDE"，而是"为一个 PDE 反复求解器造代理"（§1）：均匀化、优化、逆问题等场景需要对同类 PDE 做大量重复求解，FEM 太贵。已有无标签路线（PINN、Deep Galerkin 等）的公共缺陷被作者点明：它们把**某一组特定 BC 写进损失函数**，换一组 BC 就要重训。本文的反转设计是：**把 Dirichlet 与 Neumann BC 作为 NN 的输入**（以图像通道编码），让一个网络同时覆盖"同一 PDE、不同域、不同 BC"的多组边值问题（BVP）。第二个设计决策是损失基于**离散化弱形式残差**而非强形式——动机直接来自 FEM：弱形式连同 BC 完整定义物理系统，且离散残差天然适配像素网格。作者声称这是首次"单代理求解器 + 不同域不同 BC + UQ"三者同时做到（§1 末）。

数学骨架（§2）：统一椭圆型 PDE $\nabla \cdot \BA(\Bvarphi) = \Bzero$ 于 $\Omega$，$\Bvarphi = \bar{\Bvarphi}$ 于 $\Gamma^{\Bvarphi}$，$\Bk = \bar{\Bk}$ 于 $\Gamma^\Bk$；弱形式为 $\int_\Omega \nabla \Bomega \cdot \BA(\Bvarphi) ~ dV - \int_{\Gamma^\Bk} \bar{\Bk} \cdot \Bomega ~dS =0$（乘以变分 $\Bomega$、分部积分、代入 Neumann BC 得到）。离散化后 $\Bvarphi^h = \BN \Bd_{\Bvarphi}$，残差为对单元求和：
$$\BR = \sum_{e=1}^{n_\text{elem}} \left\{ \int_{\Omega^e} \BB^T \BA(\Bvarphi^h) dV - \int_{\Gamma^{e,\Bk}} \BN^T \bar{\Bk}~dS \right\}$$
体积分与面积分用 Gaussian 求积。关键表示选择：问题域用图像像素表示，相邻像素构成单元 $\Omega^e$，连接性由图像数据自动保留——代价是域边界只有像素级分辨率、非光滑曲线（作者显式承认，并指出可用 FEM 等参映射推广但不在此工作范围）。

## 弱 PDE 损失层：FEM 组装的无参数化重写

§4 是本文的技术核心：把 FEM 残差计算改写为卷积 + 向量化运算，作为"弱 PDE 损失层"挂在 NN 后面。这一层**不引入任何可训练参数**，只做前向 FEM 计算，因此 NN 主干架构（本文选 encoder-decoder CNN）完全自由。以 $5\times5$ 像素稳态扩散为例（Algorithm 1）：

1. Dirichlet BC 强制：用输入通道 $\BI_\text{D}^{5,5}$ 的值**替换** NN 输出在 Dirichlet 边界像素处的节点值，得 $\BM_{5,5}$——即 Dirichlet 条件是硬约束（代入解而非罚项）。
2. 体积分：四个 $2\times2$ 卷积核 $k_{B,1},...,k_{B,4}$（单位阵式排布）把节点解转成单元表示 $\BM_{25,4}$，每行对应一个单元的局部节点解；对每个 Gauss 点算 $(\BR_\text{bulk}^{25,4})^i = \omega_i D \BM_{25,4} \BB_{i,4,2} \BB_{i,2,4}$（$2\times2$ Gauss 点，B 矩阵尺寸 $4\times2\times4$），再用 `tf.roll` 把单元型残差展开回节点位置，最后 `tf.reduce_sum` 一次性完成传统 FEM 中需要遍历单元的组装。
3. Neumann 边界：两组卷积核 $k_{I,1}, k_{I,2}$ 与 $k_{II,1}, k_{II,2}$ 构造两节点表面单元，形状函数 $\BN_{2,2}$ 下算 $(\BR_\text{Neu,I}^{25,2})^i = \omega_i \BI^{25,2}_\text{Neu,I} \BN_{i,2} \BN_{i,2}$，同样 roll + reduce_sum 组装。
4. 总残差 $\BR_\text{tot}^{5,5,1} = \BR_\text{bulk}^{5,5,1} - \BR_\text{Neu}^{5,5,1}$；再乘两个掩码矩阵剔除 Dirichlet 边界处与网格边距（margin）处的残差，得缩减残差 $\BR_\text{tot}^\text{red}$。

域/边界检测（§5.2）靠输入编码的哨兵值：Dirichlet 通道内问题域填 $-2$（训练时由自定义层 `LayerFillRandomNumber` 填 $[0,1]$ 均匀随机数，从而卷积核只能学到真实边界值）、边距填 $-1$（残差被掩码排除）；Neumann 通道问题域填 0。作者注释强调 $-1,-2$ 是无物理含义的任意选择。数据归一化到 $[-1,1]$ 且保证物理有效数据 $>0$，这是后面线性弹性案例失效分析的伏笔。

## 贝叶斯化：残差当似然、$\Sigma_2$ 当可学阈值

§3.2 的贝叶斯化沿用标准 VI 框架：后验 $P(\BTheta | \calD) = P(\calD|\BTheta) P(\BTheta)/P(\calD)$，用 $Q(\BTheta)$ 最小化 $D_\text{KL}(Q(\BTheta)||P(\BTheta | \calD))$，等价于最大化 ELBO $\mathbb{E}_{Q}[\log P(\calD | \BTheta )] - D_\text{KL}( Q(\BTheta) ||P(\BTheta) )$，损失 $\calL = D_\text{KL}\left( Q(\BTheta) ||P(\BTheta) \right) - \mathbb{E}_{Q}[\log P(\calD | \BTheta )]$。选 VI 而非 MCMC 的理由原文明说：MCMC 迭代推断昂贵、不适合大量参数（与上一批 B-PINN/多保真 BNN 选 HMC 的取舍正相反——此处参数量达数万，HMC 不可行）。梯度方差控制用 Flipout：权重扰动 $\Delta W_n = \widehat{\Delta W} \circ r_n s_n^t$，$r_n, s_n$ 为 $\pm1$ 随机符号向量，使 minibatch 内每个样本获得伪独立扰动、解相关梯度；实现在 TensorFlow Probability 的 `Convolution2DFlipout`/`DenseFlipout` 层。

UQ 结构（§3.2.3）：aleatoric 部分用加性高斯噪声 $\By = \Bf(\Bx, \BTheta) + \Bepsilon$，$\Bepsilon \sim \calN(\Bzero, \Sigma_1\BI)$（同方差假设，作者脚注承认异方差情形更有用但未做）。关键改造是**似然挂在残差上而非解上**：
$$P(\BR_\text{tot}^\text{red}|\Bzero, \Sigma\BI) = \prod_{k=1}^{K} \calN \left( R_\text{tot}^{\text{red},k}|0, \Sigma_2 \right)$$
点残差期望为零对应"PDE 在每点弱满足"，保证无标签。作者脚注诚实处理了非线性传播问题：对非线性 PDE，即便输出噪声是高斯，残差噪声一般非高斯；在 $\Sigma_1$ 小、非线性算子局部近似线性时可近似高斯。$\Sigma_2$ 因难以由 $\Sigma_1$ 误差传播直接算出，被当作**可学习参数**，原文称其"本质上充当残差收敛的阈值"。预测分布 $P(\By^*|\Bx^*, \calD) \approx \frac{1}{S} \sum_{s=1}^{S} P(\By^*|\Bx^*, \BTheta^s)$，方差
$$\text{Var}[\By^*|\Bx^*, \calD] \approx \frac{1}{S} \sum_{s=1}^{S} \left( \Bf(\Bx^*, \BTheta^s)\Bf^T(\Bx^*, \BTheta^s) + \Sigma_1\BI \right) - \left( \frac{1}{S} \sum_{s=1}^{S} \Bf(\Bx^*, \BTheta^s) \right)\left(\frac{1}{S} \sum_{s=1}^{S} \Bf(\Bx^*, \BTheta^s) \right)^T,$$
即 epistemic（参数后验展开）+ aleatoric（$\Sigma_1\BI$）两项合成。UQ 用 $S=50$ 个 MC 样本。

## 训练中的两个工程性补救：零初始化与最优参数初始化

§5.3 记录了两个负面结果及补救，是本文论证链里少见的"失败模式驱动设计"：

- **Neumann 加载收敛慢**：Dirichlet 加载的 BVP 收敛快，纯 Neumann 加载有时无法找到正确解——原因是后者的损失下降由未知量的**梯度**驱动而非未知量本身。零初始化补救：前若干 epoch（100 个）用值 0.5 的哑标签（归一化后等价于真实 0）做 MSE 训练而不加 PDE 约束，模仿 FEM 零初值。若不做，随机初始化的输出（归一化下 0 等价于真实 $-1$）会违反物理——如非线性弹性中变形梯度行列式为负。Fig. 4 显示零初始化后 500 epoch 即接近 DNS，且总体训练更快。
- **BNN 多 BVP 收敛失败**：BNN 直接训练时先收敛到纯 Dirichlet 子问题（扩散 bc id 1、3），一旦陷入次优状态，带非零 Neumann BC 的 BVP 就很难再优化。补救是"最优参数初始化"：先训同架构确定性 NN 至收敛，用其参数初始化 BNN 后验均值，再用**极小学习率**（$10^{-8}$ vs 确定性 $2.5\times10^{-4}$）在局部参数空间探索。这个设计的代价是：BNN 的 epistemic 不确定度只在确定性最优解的邻域内度量，是局部后验近似而非全局后验（此批评为分析重建；作者只陈述了做法与动机）。后续所有 BNN 仅训 100 epoch——作者用 Fig. 7 论证：$\Sigma_2$ 演化与损失符号变化相关，但解分布在 epoch 100–4000 间稳定，故少量 epoch 足以评估统计矩。

## 数值结果：20/30 个 BVP 同时求解与三处诚实的失败记录

稳态扩散（§6.1）：5 个矩形域 × 4 组 BC = 20 个 BVP，$16\times16$ 分辨率，网络为 Conv2D(8)–Conv2D(16)×2 + Dense(64)×2 + 解码卷积（BNN 参数 66,202，确定性 33,209；$\calD$ = 20 × 增强 $2^{10}$）。DNS 对照用自研 mechanoChemFEM（deal.II）。Fig. 5 显示 bc id 1（Dirichlet 加载）与 bc id 2（Neumann 加载）两个代表 BVP 的 DNS/确定性/BNN 均值吻合，且 BVP (ii) 中 Neumann 边界处不确定度高于其他位置——符合"信息由通量而非值给定"的预期；Dirichlet 边界处标准差被硬置零（BC 已强制代入解，非推断量）。

八边形域混合 BC（§6.1.3）：解在 X、Y 双向非线性，$32\times32$ 与 $64\times64$ 两种输出分辨率均与 DNS 可比，细分辨率更准；水平线上的不确定度大于竖直线，作者归因于水平方向解的非线性更强。

线性弹性（§6.2）：$\Bsigma = \lambda\tr (\Bvarepsilon) \Bone + 2\mu\Bvarepsilon$，$\lambda=14.4231$，$\mu=9.61538$；30 个 BVP 同时求解。三处值得记录的失败/局限：(1) 三个所选 BVP 中混合加载的 (iii) 结果略差于 DNS——原因是小变形下缩放后的解落在极窄区间 $[0.5, 0.55]$，NN 难以分辨，纯 traction 加载尤甚；作者据此提出"数据归一化的选取对 PDE 约束代理求解器性能很重要"，并以非线性弹性大变形下反而成功作为旁证。(2) L 形域插值实验（§6.2.3）：单点加载不足以让 NN 学到 BC 的物理含义，必须暴露多级增量加载（10 个输入点，训 5 个、插值测 5 个）；解场插值预测准确，但底边反力预测失败——$F_x$ 真值近零，确定性 NN 无法预测 $F_x$，BNN 因 $u_x,u_y$ 在底部极小而对反力给出很大不确定度（预测偏离 DNS 但作者称"符合预期"）。这暴露了从解场到导出量（反力）的误差放大问题（后半句为分析重建）。(3) 像素域表示使边界只有像素级分辨率。

非线性弹性（§6.3）：可压缩 Neo-hookean 自由能 $W=\frac{1}{2} \mu(\text{tr}(\BC)-3-2 \ln(J))+\lambda \frac{1}{2}(J-1)^2$（注意抽文把 $\text{tr}(\BC)3$ 的排版丢了，应为 $\text{tr}(\BC)-3$，此为抽文疑点），$\BP = \lambda(J^2-J)\BF^{-T} +\mu(\BF-\BF^{-T})$。30 个 BVP 全部成功。此处出现早期训练的物理违例问题：NN 早期输出可能给出 $J\le0$，残差无法计算，故训练时**剔除** $J<0.1$ 与 $J>5.0$ 像素的残差贡献作为正则化，训练后期该正则自然失效。外推实验（§6.3.3）：4 个训练加载步递减的案例中，插值预测反力普遍准确，外推在训练范围外**短区间**内合理（$F_x$ 尤其）——与摘要"to a certain extent"的限定一致。效率对照（Table）：FEM 单核 110 ms vs 确定性 NN 0.22 ms、BNN 0.29 ms（GTX 1050 Ti），加速约 500/380 倍（倍数为分析换算，原文只给两列数值）；时间与体积平均的 $L_2$ 误差 $L_2 = \frac{1}{L} \sum_{l=1}^{L} ( \frac{1}{K} \sqrt{\sum_{k=1}^K ( y_{l,k}^\text{DNS} - y_{l,k}^\text{NN} )^2})$（$L=30$ 增量加载步、$K=16\times16$ 像素）为 3.06e-4（确定性）/4.04e-4（BNN）。

## 结论的边界与疑点

结论（§7）：方法可同时解变域变 BC 的 BVP、有插值与（短程）外推能力、可共享复用；瞬态问题留待后续工作。适用条件显式化：椭圆型稳态问题（扩散/线弹/非线弹三类）；固定方形背景网格 + 像素域（边界像素级锯齿）；材料参数固定（脚注说明可作输入但本文未做）；同方差 aleatoric 噪声；BNN 后验是确定性最优解邻域的局部 VI 近似；外推能力明确限定为"短范围"。

疑点清单：(1) 抽文 Neo-hookean 自由能显示 "$\text{tr}(\BC)3-3$"，疑排版丢失减号，正确形式应为 $\text{tr}(\BC)-3$；(2) 队列 note 称本文为"B-PINN 派生"，但正文只在相关工作中引用 B-PINN（HMC/VI 似然构造的先行者），本文实际走的是"弱形式离散残差 + BC 输入化 + Flipout-BNN"的独立路线，推断 N 上与 B-PINN 是并行而非派生关系；(3) 多处 "threeBVPs"、"The. Deep Galerkin"、"obtaoned" 等抽文空格/拼写噪音，不影响内容；(4) BNN 训练仅 100 epoch 且学习率 $10^{-8}$，其不确定度的校准性（coverage）未定量评估，原文只做定性对比——这是本文 UQ 论证中最薄弱、也最值得后续核查的一环（分析重建）。
