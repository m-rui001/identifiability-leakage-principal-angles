# UQ-SONet：集合变换器嵌入 + 条件变分自编码器，为置换不变算子学习内置不确定性量化

Deep set based operator learning with uncertainty quantification，Lei Ma, Ling Guo, Hao Wu, Tao Zhou，JCP 2026（arXiv 2509.25646，LaTeX 源，定位用章节/公式号）。

## 问题定位：VIDON 解决了传感器灵活性，但留下两个不确定性缺口

论文的推理起点是对算子学习谱系的精确缺口分析。FNO 依赖笛卡尔网格，DeepONet 能处理复杂域但 branch 网络要求传感器数量与位置在训练/测试间固定且充分稠密——文章列出两条由 branch 结构 $\hat{\mathcal G}(\kappa)(y)=\sum_{n=1}^p b^n(\kappa(x_1),\dots,\kappa(x_m))t^n(y)$ 直接导出的限制。VIDON 用集合变换器引入置换不变性解决了第一条，但作者指出其"假设观测数据足够信息量以允许从输入到输出的确定性映射"——在稀疏/噪声/不完整观测下解算子本身带不确定性，VIDON 不予处理；此外算子可能固有随机（$u$ 在 $\kappa$ 完全给定时仍不确定）。既有 UQ-算子学习方法（BNN、deep ensemble、IB-UQ）均未在置换不变框架内显式研究。UQ-SONet 的答案是给随机算子模型 $\hat{\mathcal G}(h(\mathcal O),z)(y)=\sum_{n=1}^p b^n(h(\mathcal O),z)t^n(y)$，其中 $h(\mathcal O)$ 是观测集 $\mathcal O=\{(x_i,\kappa(x_i))\}_{i=1}^m$ 的置换不变嵌入，$z\sim\mathcal N(0,I)$ 是吸收两类不确定性的潜变量。

## 方法链：从函数空间 cVAE 到可实现的有限维损失

**集合变换器嵌入（§3.1）**分两个模块：输入嵌入把每个传感器的坐标与值分别经 $\Lambda_x,\Lambda_\kappa$ 映射后相加 $\Lambda_i=\Lambda_x(x_i)+\Lambda_\kappa(\kappa(x_i))\in\mathbb R^{d_{emb}}$；注意力池化用 $H$ 个头计算 $h^{(l)}(\mathcal O)=\sum_{i=1}^m\frac{\exp(w_l(\Lambda_i)/\sqrt{d_{emb}})}{\sum_k\exp(w_l(\Lambda_k)/\sqrt{d_{emb}})}\,v_l(\Lambda_i)$，拼接后得固定维向量——池化对任意传感器数量可用且严格置换不变。

**cVAE 结构（§3.2）**：输出函数以有限网格值 $\bar u=(u(y_1),\dots,u(y_M))^\top$ 表示。解码器定义 $p_D(\bar u|\mathcal O,z)=\prod_{i=1}^M\mathcal N(u(y_i)|\sum_n b^n(h(\mathcal O),z)t^n(y_i),\,M\sigma_u^2)$——一个关键的 remark 指出人工噪声方差按 $M$ 缩放，使 $M\to\infty$ 时损失可解释为函数空间 cVAE 的损失；$z$ 先验取标准高斯。编码器给出近似后验 $q_E(z|\mathcal O,\bar u)=\mathcal N(z|\mu_z(h(\mathcal O),\bar u),\Sigma_z(h(\mathcal O),\bar u))$（$\Sigma_z$ 取对角）。注意编码器同时以观测和**输出**为条件，训练与推断的角色分离：训练用 $q_E$ 估计后验，推断时直接从先验 $p(z)$ 采样——这是 cVAE 的标准做法，也意味着推断侧的不确定性完全由 $z$ 的先验经解码器传播产生。

**损失推导（§3.3）**：对解码器的条件边际似然用 Jensen 不等式展开 $\log p_D(\bar u|\mathcal O)\ge-D_{\mathrm{KL}}(q_E\|p)+\mathbb E_{q_E}[\log p_D(\bar u|\mathcal O,z)]$（等号当且仅当 $q_E$ 等于真后验），得负 ELBO 损失的显式形式（两分布均高斯故 KL 项闭式）：

$$\mathcal L=\frac12\,\mathbb E\big[-\log|\Sigma_z|+\mathrm{tr}(\Sigma_z)+\|\mu_z\|^2-d_z\big]+\frac{1}{2\sigma_u^2}\,\mathbb E\Big[\sum_{i=1}^M\frac{(\hat{\mathcal G}(h(\mathcal O),z)(y_i)-u(y_i))^2}{M}\Big].$$

作者补充两点解读：网格均匀且 $M$ 充分大时第二项正比于算子输出与 $u$ 之差的均方 $L^2$ 范数；整体损失是期望负对数似然的上界（附录 A.3 从函数空间 VAE 原理重新推导了不离散化的版本）。训练（Algorithm 1）在每个 mini-batch 随机采样传感器数量 $m\in\mathcal M$ 与位置，推断时对固定的 $m$ 个任意位置传感器重复"$z\sim\mathcal N(0,I)$、前向"得到条件分布的样本统计量。

**评估指标**：Wasserstein-2 距离（对 Polish 空间上的测度对取下确界），以及相对误差 $err_{E[u]}=\|E[u]-E_\theta[u]\|_2/\|E[u]\|_2$ 与 $err_{\sigma[u]}$。参考分布的构造是本文评估可信度的支点（附录 A.2）：由于输入函数先验是 GP，观测后的输入后验仍是 GP（闭式后验均值/协方差公式，含噪声观测时的 $\mathcal K+\sigma^2I$ 修正），从输入后验抽 1,000 个样本经有限差分解算子前传，得到输出条件分布的参考解——这使 UQ 评估不依赖真值标签而依赖可验证的贝叶斯传播。边界条件用硬约束构造 $u(x)=(1-x)(1+x)u_\theta(x)$（1D）、$u(x,y)=x(1-x)y(1-y)u_\theta(x,y)$（2D）施加。

## 数值证据链：消融 → 对照 → 加噪 → 随机算子 → NS 方程

**1D 扩散方程**（$-\frac{1}{10}(ku')'=2\sin(2\pi x)$，$\log k$ 为 GP（$\mu=\sin2\pi x,\sigma=0.5,l=0.1$），$N=10{,}000$ 对）：三组消融确定默认配置——Wasserstein-2 距离在潜维达到 10 后稳定（后续均用 $d_z=10$）；误差随训练集增大而降（取 10,000）；预测标准差的均值随输入传感器数增加而下降——证实模型能随观测信息增加而收窄不确定性。可变传感器实验（$\mathcal M=\{1,\dots,10\}$，10 个预生成批次各 1000 样本，100,000 次迭代）显示 $m=2,4,7,10$ 的均值与标准差带均与参考吻合且随 $m$ 收缩。与 VIDON 的公平对照（防止 VIDON 过拟合的批内传感器一致性策略、5 次独立训练）：稀疏输入下 UQ-SONet 的均值误差普遍更低（$m=1$：$4.47\pm0.83$ vs $5.35\pm0.15$；$m=7$：$5.88\pm0.74$ vs $8.73\pm1.03$，均 $\times10^{-2}$），且额外给出 $err_{\sigma[u]}\approx8\%$ 量级的稳定条件分布。附录的 deep ensemble 对照给出机理诊断：VIDON 集成的均值准，但不确定性带"一致地窄于参考"——集成不确定性只反映确定性预测器间的变异性，而 UQ-SONet 直接建模 $p(u|\mathcal O)$。乘性噪声实验（观测为 $k(x)\cdot e^{\epsilon(x)}$，$\sigma\in\{0.1,\dots,1.0\}$）：均值误差稳定在 6.5–7.2%、标准差误差 7.5–9.7%，几乎不随噪声水平恶化，展示了对重噪声输入的鲁棒性。

**2D Poisson**（$-\frac1{10}\Delta u=f$，$f$ 为 2D GP，$N=80{,}000$，$\mathcal M=\{1,\dots,4\}$，传感器用 PyEMMA 正则空间聚类从 $[0.1,0.9]^2$ 内采样保证最小间距）：噪声-free 下 UQ-SONet 的均值误差与 VIDON 相当或更好（$m=1$：4.00 vs 3.26 略差，$m=3,4$：5.92/5.48 vs 5.99/7.01 更好）；加噪 $\mathcal N(0,0.5^2)$ 与 $\mathcal N(0,1.0^2)$ 后多数配置反而略降（$m=4$：5.03/5.54 vs 噪声-free 5.48），标准差误差保持 7.3–9.5%。

**1D 随机椭圆方程**（$k$ 与 $f$ 均为随机过程，学习 $\mathcal G:k\mapsto u$）：这是方法的关键区分测试——解的不确定性现在有双重来源。结果显示 $err_{E[u]}$ 随训练集增大达到平台；当 $m$ 从 2 增到 10 时预测不确定性带收缩但不消失，"来自输入信息不足的不确定性随传感器增多而消退，算子固有随机性继续在解中显现"——这正是潜变量设计所要分离的两种不确定性。误差量级：$err_{E[u]}\approx1.8\text{–}2.5\%$、$err_{\sigma[u]}\approx3.6\text{–}5.7\%$（5 次独立实验）。

**2D 随机椭圆方程**（学习 $f\mapsto u$，$k$ 亦随机）：在 $x=0.5,0.7$ 与 $y=0.5,0.7$ 切线上评估，均值误差 3.2–7.6%、标准差误差 6.5–8.5%（3 次实验）。

**Navier–Stokes**（涡量-速度形式，$\nu=0.001$，$f=0.1\sin(2\pi(x+y))+0.1\cos(2\pi(x+y))$，学习 $w_0\mapsto w|_{t=10}$，初始涡量场乘边界因子 $x^{1/3}(1-x)^{1/3}y^{1/3}(1-y)^{1/3}$；伪谱法生成数据，4 批次各 20,000 样本、50,000 迭代）：UQ-SONet 对 VIDON 的优势最显著——$err_{E[w]}$ 全线更低（$m=2$：$1.89\pm0.60$ vs $5.98\pm0.36$），且随 $m$ 增大 VIDON 误差上升（8.74）而 UQ-SONet 稳定（2.55），标准差误差 6.25–7.32%。

## 代价与限定

计算成本（附录 A.4，RTX 3090）：UQ-SONet 训练与推断均贵于 VIDON——训练多一个编码器网络，推断需潜变量采样与统计量计算；作者声明该代价"因能更全面刻画条件分布而是值得的"。作者自列的边界：条件高斯解码器"对强非高斯或多模态后验可能限制性强"，扩展方向包括更表达性的潜变量/解码器分布、HMC 或扩散模型采样；当前框架只处理输入端稀疏，输出观测受限（输入输出双端稀疏）的情形留待未来；主动学习（以不确定性引导传感器布设）与时间依赖系统的长期 rollout（不确定性累积）是未来工作。

疑点：2D Poisson 的 GP 协方差公式排版为 $\exp[\frac{-(x-x')}{2l_1^2}+\frac{-(y-y')^2}{2l_2^2}]$，首项缺平方，疑为排版遗漏（照录不作证据）；1D PDE 案例的 $\sigma_u^2$ 与 2D 的 $d_z$（10 vs 100）差异大，正文未解释选择依据；$err_{\sigma[u]}$ 参考值依赖 GP 先验已知这一前提，实际场景先验错配时参考构造失效。
