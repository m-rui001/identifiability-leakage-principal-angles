# 用变分信息瓶颈增强多模态实体与关系抽取（Enhancing Multimodal Entity and Relation Extraction with Variational Information Bottleneck, MMIB）

Cui, Cao, Cong, Sheng, Li, Liu, Shi（中科院信工所 / 北邮），IEEE TASLP，2024，DOI: 10.1109/taslp.2023.3345146（arXiv:2304.02328）。TeX 通道。注：\cite 引用编号丢失，基线归属（如 UMT、UMGF、HVPNeT 的出处）只能依赖正文残句；后文有直接署名处（Zheng et al.、Lu et al.、Wang et al.、Jia et al.）为原文残留的作者名。

## 两个问题定义与总体设计（§I, §III）

任务：MNER（句 + 图 → BIO 序列标注）与 MRE（句 + 图 → 给定实体对的关系分类）。作者归纳两个未被充分解决的内在问题：

1. **模态噪声（modality-noise）**：每个模态都含任务无关信息，会误导预测。例证（Figure 1）讲得很具体：文本侧 "handsome/dinner" 给 "Rob" 赋予人名特征（实为猫的主人语境）；图像侧噪声有两层——全局层多数区域对识别目标实体无信息，局部层即便显著物体也携带超出需要的复杂语义（"猫躺在地毯上" vs 只需要"猫"）。MRE 中绿色框冗余区域会把关系引向"人-人"而非"组织-人"。
2. **模态鸿沟（modality-gap）**：文本/图像来自不同编码器，特征空间与分布不一致，妨碍语义对齐；已有"把视觉物体转成文本标签"的对策受制于外部工具的误差传播。

总体方案：变分编码 + 两个正则——**Refinement-Regularizer (RR)**（IB 原则，解决噪声）与 **Alignment-Regularizer (AR)**（MI 对比，解决鸿沟）。声称是首个把变分 IB 估计用于 MNER/MRE 的工作。

## 方法推理链

**变分编码（§III.B）**：BERT 编文本、ResNet50 编全图与 grounding 工具提取的局部物体（224×224，2048→d 线性投影），得 X^T 与 X^V。编码器 "Attentive Propagation Encoder"（APEnc）是标准 Transformer 层（多头注意力 Eq.(4) + FFN/残差/LN Eq.(5)，公式照录），模态内自注意力传播：每 token/图像作 query 与本模态全部表示作 key-value 交互，输出高斯分布参数 μ_i、σ_i²（Eq.(6)），重参数化采样 z_i = μ_i + σ_i⊙ε（Eq.(8)）。文本侧同构（Eq.(10)）。【分析重建：把"每个元素的 query 对全模态 key-value"称作模态内信息传播，其实就是一个自注意力层的重述；方法的新意不在编码器，而在其上的两个正则。】

**RR 的推导（§III.C.1）**：目标 L_rr = β₁I(Z^T;X^T) − I(Z^T;R) + β₂I(Z^V;X^V) − I(Z^V;R)（Eq.(11)）。一个关键的化简步骤（原文明说）：基于 Z^T 与 Z^V 独立的假设，用互信息链式法则把两个充分项合并 I(Z^T;R)+I(Z^V;R) = I(Z^T,Z^V;R)（Eq.(12)），得

L_rr = [β₁I(Z^T;X^T) + β₂I(Z^V;X^V)]（Minimality） − I(Z^T,Z^V;R)（Reconstruction）

可解化（§III.E.1）：最小性两项用 KL 变分上界——先写 I(Z^V;X^V) = D_KL(p_θ^V(Z^V|X^V)‖p(Z^V))（Eq.(15)），先验取 N(0,I)，变分后验 q_φ^V 替代，得上界 = Σ_i D_KL(N(μ_i^v, diag(σ_i^v)²) ‖ N(0,I))（Eq.(16)，即标准 VAE KL 项）；重建项用变分下界 I(Z^T,Z^V;R) ≥ E[log p(Y|Z^T,Z^V)]（Eq.(18)），且展开成 log p(Y|·) + Σ_{Y'≠Y} log(1−p(Y'|·))（Eq.(19)，照录——注意这是对"其他标签概率应为 0"的逐项惩罚式展开，比标准交叉熵更强，原文未讨论此差异）。p(Y|Z^T,Z^V) 直接取任务预测头：MNER 用 CRF（Eq.(14) 照录），MRE 用实体池化 + Softmax 分类（Eq.(15) 照录）。即**重建项与任务损失共用同一预测头**。

**AR（§III.C.2, §III.E.2）**：L_ar = −I(Z^T;Z^V)（Eq.(13)），按 infomax/对比式估计：判别器 D（Sigmoid(MLP(Pooling(Z^T)⊕Pooling(Z^V)))，Eq.(22)，mean-pooling 解决形状不匹配 n+2 vs m+1），下界 = log D(Z^T,Z^{V+}) + log(1−D(Z^T,Z^{V−}))（Eq.(21)），配对样本为正、批内负样本为负，二元交叉熵优化。

总损失 L = L_rr + L_ar + L_task（Eq.(25)）。【分析重建：由于重建项下界即 log p(Y|·)，L_rr 的重建部分与 L_task 实为同一量的两次计入——即任务损失被隐式加权，原文未指出这一重复。】

## 实验证据

设置：Twitter-2015（4000/1000/3257 tweets，4 类实体）、Twitter-2017、MNRE（9,201 句-图对、23 关系）；BERT_base + ResNet50，hidden 768；AdamW lr 3e-5，batch 8，β₁=β₂=0.1（手工调）。基线四组：纯文本（CNN-BiLSTM-CRF 等）、vanilla 多模态（GVATT、UMT、VisualBERT、UMT 等）、处理模态鸿沟（UMGF、MAF、MEGA）、处理模态噪声（HVPNeT、MKGformer）。

主结果（Table MNER/MRE）：MNER Twitter15 F1 76.02（vs UMGF 74.85、HVPNeT 75.32）、Twitter17 87.60；MRE F1 83.23（vs HVPNeT 81.85、MKGformer 81.95），作者声称与所有基线差异显著（p<0.05）。观察链：多模态普遍优于纯文本（视觉有用）→ 处理鸿沟/噪声的后两组基线优于 vanilla（两个问题确实存在）→ MMIB 同时超过两组（两个正则协同有效）。

**消融（Table ablation）**：去 L_rr：Twitter15 −1.07、MRE −1.32；去 L_ar：−1.13/−1.53；双去：−1.60/−2.92（MRE 掉幅最大）——支撑"两正则各自有效且协同"。

**β 敏感性（§IV.C，IB 机制的直接检验）**：三组实验（固定 β₁=1 调 β₂、反之、同时同值调），候选 {0, 0.01, 0.1, 0.5, 1.0, 1.5, 2.0}。发现：β=0 时性能严重下降（不丢弃噪声有害）；β=2.0 最差（过度压缩、保留信息不足以重建任务信息，作者原话推测 "might that the model compress ... too much"）；β₁=β₂=0.1 最优。这组实验把"IB 权衡存在内点最优"从理论叙述落到 F1 曲线上。

**噪声分析（§IV.B）**：自定义 contribution-score（X^V/Z^V 点积矩阵按行求和）可视化，展示去掉 L_rr 后图像均匀注意最终视觉表示导致融合注意力错误（两名歌手 → per/per/peer），完整 MMIB 则丢弃无关视觉信息；案例含 UMT（跨模态注意被噪声网格干扰）、HVPNeT（只滤视觉噪声、忽略文本噪声，"die" 一词使视觉前缀被人形物体误导）等对照解释。

**鸿沟可视化（§IV.D）**：150 对实体-物体、t-SNE（500 迭代、perplexity 10）：无 L_ar 时实体/物体表示各散在己方空间，有 L_ar 后跨模态语义聚合。

**错误分析（§IV.E，作者自陈边界）**：从每数据集各取 100 个错例，MMIB 在图文内容明显无关时失败（"Celtic" 球队配广告牌图 → 误判 MISC；纽约游览配人-房子图 → 误判 per/loc/place_of_residence）。作者推断：即便能丢弃噪声，图文明显无关时噪声仍不可避免地被引入。

## 限定与疑点

- 消融在测试集上报告（作者注明 "Following prior studies"），且只报单点性能，无多次运行的显著性检验（主结果的 p<0.05 未给检验方法与对象数）。
- L_rr 的两个正则项与 L_task 的关系（重建项下界与任务损失同源）原文未讨论；总损失中任务项实际被计入两次，权重解析未给出。
- Eq.(12) 的链式化简依赖 Z^T ⟂ Z^V（独立假设在融合层 T2V/V2T 交互之后是否仍成立，未论证）。
- AR 用 mean-pooling 后的对比判别器，本质是 InfoNCE 式下界，其 MI 估计的紧致性未讨论；"最大化配对 MI"与"最小化非配对 MI"（摘要表述）在实现中只是二元判别的两面。
- 数据集规模有限（MNRE 9,201 对、23 类），错误分析揭示的图文无关场景是该类方法的共同边界。
- 疑点：§IV.C 候选值集合写作 "\{0,0, 0.01, ...\}"，含重复的 0，为原文排版错误，照录；Eq.(19) 下界展开式的第二项把所有错误标签的 log(1−p) 相加，与标准做法不同，疑为原文特有的推导选择，照录不修正。
