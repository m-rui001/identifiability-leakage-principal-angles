# 分子性质预测中神经网络不确定性量化方法的系统评估（Hirschfeld, Swanson, Yang, Barzilay & Coley）

原题：Uncertainty Quantification Using Neural Networks for Molecular Property Prediction。作者单位：MIT CSAIL / 剑桥 / UC Berkeley / MIT 化工系。arXiv:2005.10036，DOI: 10.1021/acs.jcim.0c00502（J. Chem. Inf. Model. 2020）。通道：TeX 源（含 Supporting Information）。抽文引用以 `\citeauthor` 键名保留（部分可读），见疑点。

## 论证框架：四类方法 × 五数据集 × 四指标的系统比较

论文的问题意识：QSAR 分子性质预测中神经网络日益成为标准架构，但其预测最不透明，UQ（不确定性量化）对指导实验设计至关重要；已有大量 UQ 方法，但数据集、评估准则、超参选择的差异使客观比较困难（引言明说），本文做系统评估。**模型**：MPNN（Chemprop：3 步消息传递、ReLU、hidden 300 → 两层 300 密集层 → 线性输出）与 FFN（Morgan 指纹 2048、radius 3、useChirality，同后半网络）；另加两个不依赖 NN 的 FP 基线（FP GP、FP RF）。**数据**：四个公共回归基准（Delaney 水溶性、freesolv 溶剂化能、lipo 亲脂性、QM7 原子化能）+ 一个合成数据集 CLogP（四个数据集分子并集、RDKit Crippen 启发式估计）——特意构造为**没有偶然不确定性（aleatoric）**的对照场景。**划分**：50/20/30，八个随机 split 控制运气 + 一个 scaffold split（Murcko 骨架贪心装箱，测试分子更"域外"）。**误差模型**：$M(x)-y\sim\mathcal N(0,\hat\sigma^2(x))$，$\hat\sigma^2(x):=f(U(x))$；定量型方法取 $f$ 为恒等，相对型方法经线性校准。

## 方法分类与实现细节

**集成类**（16 个模型）：预测取算术平均 $\tilde M(x)=\sum_MM(x)/n$，不确定性取预测方差 $U_\text{ensemble}=\sum_M(\tilde M(x)-M(x))^2/n$。四个变体：(i) 传统集成（不同随机初始化，Lakshminarayanan 等；计算成本随集成规模线性增长）；(ii) Bootstrap 集成（每个模型只用随机 25% 训练分子——若 $|\mathcal X_i|\ll|\mathcal D_{\rm train}|$ 可大幅省时；预期稀疏特征上模型间分歧大）；(iii) Snapshot 集成（每 3 个 epoch 存权重、存后重置学习率促差异；Cortés-Ciriano 等证明其性能与传统集成相当）；(iv) MC Dropout（10% 与 20% 两种 dropout 率，Gal 等证明近似贝叶斯推断）。

**Mean Variance Estimation（MVE）**：输出层改为同时预测 $\mu(x)$ 与 $\sigma^2(x)$（softplus 保证正值），高斯负对数似然损失 $\mathrm{NLL}(x,y)=\frac12\ln(2\pi)+\frac12\ln\sigma^2(x)+\frac{(y-\mu(x))^2}{2\sigma^2(x)}$。作者注明贝叶斯 NN（每个权重是高斯随机变量）因精确损失对大数据不可行而被排除。

**距离类**：$U_{\rm dist}(x)=\min\{d(x,x')\}$ 对离群点敏感，故取与 $k=8$ 个最近邻的平均距离。两种度量：(i) 结构空间——log 缩放 Tanimoto 距离 $D_T=-\log_2(|x\cap x'|/|x\cup x'|)$（相对型度量；前提假设"输入表示到输出的映射较平滑"，作者明确指出对存在 structure-activity cliffs 的任务此假设被破坏）；(ii) 潜空间——输出层前的 300 维学习嵌入上的欧氏距离（Janet 等）。

**串联（union）类**：NN 先正常训练，去掉输出层得嵌入网络 $M'$，把整个验证集变换为 $\mathcal D_{\rm val}'=\{(M'(x),y)\}$，训练第二模型输出均值+方差：线性核 GP（GPy SparseGPRegression，标准 GPRegression 训练不可行）或随机森林（sklearn，128 棵树，不确定性取树间方差）。设计要点（原文明说）：必须用**验证集**而非训练集训练补充模型——NN 在训练集上的过拟合会让补充模型见到不具代表性的误差分布；该验证集同时用于 early stopping。

**评估指标**（四个，各对应一种使用场景）：(1) Spearman 秩相关 $\rho=\mathrm{cov}(r_{L_1},r_{L_2})/(\mathrm{std}(r_{L_1})\mathrm{std}(r_{L_2}))$，在 UQ 值与绝对误差之间（秩比较，适用于相对型度量；$\rho=1$ 本就不被期待，因误差近似正态、高不确定预测也可能随机低误差）；(2) Miscalibration area——观测的"$z$ 个标准差内误差比例"曲线与期望曲线（68%/95%/...）之间的面积，0 为完美、0.5 为最大失配；只度量**系统性**过/欠置信，对逐分子的误差不敏感，也不适用于相对型度量；(3) NLL——$U(x)$ 直接当方差的平均负对数似然；并计算与最小可达 NLL（由预测精度决定）之差以解耦 UQ 与精度；(4) cNLL——先在验证集上优化 $\hat\sigma^2=a_*U(x)+b_*$ 再算 NLL，用于相对型度量，但引入对校准集的敏感性。**统计汇总**：改进的 Wilcoxon 符号秩检验（WSRT）z 分数，对每对方法跨 5 数据集 × 8 随机 split 判定谁更常占优；SI 给出公式 $z=\frac{S-\frac14n(n+1)}{\frac1{24}n(n+1)(2n+1)}$（带符号版本，$S=\sum_i i$ 为按幅值排序后主方法胜出的秩和）。

## 结果：四个指标下的发现

**Spearman $\rho$**：数据集内、数据集间变化都大。lipo 上没有任何方法表现好（作者解释：该实验数据采集噪声可达 0.5 log10 单位、测量范围窄，"不应期待方法表现好"）；合成 CLogP 上多数方法表现好。核心警示（原文明说）：在单一数据集上做基准可能得出完全错误的结论；没有方法在所有数据集上一致强，MPNN MVE、MPNN RF、FP RF 常排名靠前；偶有方法出现负相关。低不确定子集的 RMSE 检验（100%→5%）：理想的 UQ 应给出单调下降的 RMSE；**反例**——MPNN MVE 在 lipo 上最有信心的预测反而产生高于平均的误差。scaffold split 的排名普遍弱于随机 split 的中位数。

**Miscalibration area**：MPNN MVE 与 union 方法（MPNN/FFN 版 RF、GP）优于大多数方法，FP GP/RF 也不错。随机 vs scaffold split 差异显著：CLogP 上前六个 MPNN 方法的 miscalibration area 在 scaffold split 下是随机 split 的数倍——与 Scalia 等的观察一致：**集合/dropout 技术对域外样本持续低估认知（epistemic）不确定性**；而 MPNN GP/RF 在 scaffold split 上反而常常好于随机 split。

**NLL**：MPNN GP、MPNN RF、FP RF、FP GP 在所有数据集上表现好；MPNN MVE 中位数强但跨 split 方差最大（FFN MVE 更极端、被作为离群点剔除出图）；**MPNN Ensemble 一致低估误差**，Bootstrap 与 Snapshot 集成同向但程度较轻（SI 校准斜率图：集成类大量斜率 $\ge10$）。所有估计器在 CLogP 的 scaffold split 上都远差于随机 split——作者推论许多估计器难以处理偶然不确定性。

**cNLL**：线性校准有"拉平"效应，使许多方法 cNLL 相近；对前四个数据集，校准把所有估计器/split 的最大 NLL 降低近一个数量级；但校准损害原本校准良好的方法（MPNN MVE/GP/RF），且优化参数常导致 $a\approx0$ 的**近常数方差**——校准后的模型实际上忽略分子结构相关的不确定性（SI 校准斜率图支持）。

**WSRT 汇总与最佳方法**：排名上 MPNN MVE / MPNN RF 最佳（Spearman），MPNN Ensemble、FP RF 紧随；miscalibration 最低是 FP RF，其后 FFN RF/GP、MPNN GP/RF/MVE；NLL 最低是 MPNN RF、MPNN GP、MPNN MVE（FP RF、FP GP 四五名）。架构一致性：FFN 的 RMSE 常是 MPNN 的两倍，但各 UQ 方法带来的相对 RMSE 降幅与各指标表现跨架构相似（cNLL 例外：MPNN 普遍优于 FFN，CLogP 反向——作者用精度差解释）。与既有文献的对齐：Scalia 等（ensemble 排名强于 bootstrap 但校准较差）、Tran 等（材料性质预测中卷积高斯过程最佳，类似本文 MPNN GP；本文发现 MPNN RF 三指标全面优于 MPNN GP 但差距不大，超参优化或可弥合）。

## 讨论与实用结论

三点不一致性（跨架构一致、跨数据集不一致、跨指标不完全一致）构成论文的主要负结果：**没有任何方法全面占优、也没有方法能在多数据集上产生可靠误差排名**。跨数据集差异的实际后果被量化：MPNN MVE 在 CLogP 平均 Spearman 约 0.65、在 lipo 约 0.1——前者按 UQ 选出的前 25% 预测的 RMSE 比全测试集低 75%，后者前 25% 的 RMSE 反而**更高**。作者承认未找到任何能预测这种失效的数据集性质，"试错是当前唯一已知策略"。最终实用建议：以 NLL（同时反映精度与 UQ 质量）为主要指标时，**MPNN RF 是合理的首选**，FP RF 是强基线，同时强调跨数据集/split 的巨大变化。展望：stacking（组合多个弱估计器的元估计器；Scalia 等已试过 MVE+集成的简单求和）、假设方法间性能近独立则"学习何时用哪个估计器"、更大数据集（集成类实现扩展性不实际）、分类任务的 UQ。

## 推理重建（标明为推断）

- "union 方法必须用验证集训练第二模型"的设计论证（过拟合 → 误差分布失真）是原文显式给出的，但它同时意味着 union 方法的性能上限受验证集大小制约（50/20/30 划分就是为此设计的）——这层因果由我补全。
- CLogP scaffold split 全线失败被归因于"难以处理偶然不确定性"（作者用 suggesting 措辞）：由于 CLogP 无偶然不确定性而 scaffold 测试集域外，更贴切的机制可能是域外样本的认知不确定性被低估；原文的两处归因（NLL 段 vs miscalibration 段）侧重不同，我并列呈现。
- lipo 上 MPNN MVE 反常（高信心 → 高误差）的机制未在原文中解释；结合其对结构 cliff 的敏感性是可能的解释，属推断。

## 限定条件与边界（原文显式）

- 只评估回归任务；只测试 Morgan FP 一种指纹表示；只测试 Chemprop 默认超参（作者明说未探索其他 FP 表示）。
- miscalibration area 与 NLL 对相对型（距离）度量无意义，被排除；cNLL 引入对校准集的依赖并可能退化为常数方差。
- 集成类方法训练成本随规模线性增长（16 个模型），作者承认若干实现"scale impractically"。
- 结构-活性悬崖破坏距离法的平滑性假设。
- 结论的实用建议明确附带"巨大的跨数据集/跨 split 变化"警告。

## 疑点

- `\citeauthor` 键名保留但编号与完整题录在抽文中缺失（如 yang2019chemprop、lakshminarayanan2016simple、gal2016dropout、tran2019material、scalia2019evaluating、janet2019quantitative 可按键名识别，其余无法核对）。
- Supporting Information 标题 "Uncertainty Quantification in Molecular Property Prediction using Message Passing Networks" 与正文标题不同，疑为 SI 沿用旧标题。
- WSRT 公式（SI）写为 $z=\frac{S-\frac14n(n+1)}{\frac1{24}n(n+1)(2n+1)}$：标准 Wilcoxon 符号秩检验的均值应为 $\frac{n(n+1)}4$、方差 $\frac{n(n+1)(2n+1)}{24}$，故分母应为开根后的标准差；抽文如此照录，疑原文即用此近似形式或排版丢了根号。
- 正文公式 (2) 集成方差的写法 $\sum_M(\tilde M(x)-M(x))^2/n$ 与常规方差定义等价（差一个总体方差/样本方差因子），照录。
- 图 fig:rmse 等在抽文中只有图注无图像数据，具体数值只能依据文中文字陈述。
