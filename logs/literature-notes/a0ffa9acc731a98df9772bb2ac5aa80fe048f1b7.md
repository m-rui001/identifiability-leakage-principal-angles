# 用 Koopman 算子做数据驱动控制的主动学习

*Active Learning of Dynamics for Data-Driven Control Using Koopman Operators · 2019 · DOI 10.1109/TRO.2019.2923880（arXiv 1906.05194；Ian Abraham, Todd D. Murphey，Northwestern）*

## 论文主张

机器人学自己的动力学模型必然要靠控制去"激发"数据——数据采集本身是个主动过程。本文主张：把 Koopman 算子表示（非线性系统的线性无穷维表示）与信息论主动学习结合，得到一个能**同时**做任务与学模型的控制器，且学习快到"单次执行"（single-execution）可用：自由落体四旋翼在掉落的前一秒内学出模型并完成自稳。三项贡献：Koopman 表示提升控制权威（control authority）、基于模式插入梯度（mode insertion gradient）的主动学习控制器、可自动化观测量函数发现。

## 推理链：从"线性表示更好控"到"主动激发更有信息"

**第一步：Koopman 表示 + LQ 控制优于局部线性化 LQR。** 有限维近似 $z(x)=[\psi_1,\dots,\psi_c]^\top$ 上做最小二乘 $\mat K=\mat A\mat G^\dagger$（可递推在线更新）；含控制输入时块分解 $\mat K=[[\mat K_x,\mat K_u],[\cdot,\cdot]]$，观测动态 $\dot z=\mat K_x z+\mat K_u v(x,u)$（§Koopman Operators）。受迫 Van der Pol 振子上，同一条 LQ 目标下，用 Koopman 动态算出的控制器积分跟踪误差低于"对已知非线性方程在平衡点线性化"的 LQR；用同批数据、同组基函数学出的原状态空间模型（贝叶斯优化）与已知动力学模型表现相当——说明增益来自"在高维空间里用线性系统承载非线性约束"这一表示本身，而非额外信息（§Enhancing Control Authority，Fig. ehanced_control_koopman）。作者同时承认：此例的数据是用随机输入采的，"需要大量数据才能覆盖状态空间"——这正是引入主动学习的缺口。

**第二步：把主动学习写成带切换约束的最优控制。** 目标 $\ell=\ell_{\text{learn}}+\ell_{\text{task}}$，任务策略 $\mu(z)$ 已给定，希望控制器"有界地偏离" $\mu$ 去最大化信息。工具是模式插入梯度（Prop. 1）：在时刻 $\tau$ 以时长 $\lambda$ 从 $\mu$ 切换到 $\mu_\star$，目标的一阶敏感度为

$$\frac{\partial J}{\partial\lambda}\Big\vert_{\tau,\lambda=0}=\rho(\tau)^\top(f_2-f_1),$$

$\rho$ 是伴随方程 $\dot\rho=-(\partial\ell/\partial z+\partial\mu/\partial z^\top\,\partial\ell/\partial u)-(\partial f/\partial z+\partial f/\partial u\,\partial\mu/\partial z)^\top\rho$ 的解。最小化二次次级目标 $J_2$ 得闭式控制律（Prop. 2）：

$$\mu_\star(t)=-\tilde{\bold R}^{-1}\Big(\mat K_u\frac{\partial v}{\partial u}\Big)^{\!\top}\rho(t)+\mu(z(t)).$$

推论给出方向性保证：控制仿射 Koopman 动态 $\dot z=\mat K_x z+\mat K_u v(x)u$ 下，代入得 $\frac{\partial J}{\partial\lambda}=-\|(\mat K_u v(x))^\top\rho\|^2_{\tilde{\bold R}^{-1}}<0$——**切换永远改进目标**，即该控制律一阶意义上同时降低任务代价与学习代价。

**第三步：信息度量用 Fisher 信息的 T-最优性，而非互信息。** 把 Koopman 参数 $\kappa=\{\mat K_{i,j}\}$ 当作高斯似然的最大似然估计问题，Fisher 信息阵 $\bold I=(\partial f/\partial\kappa)^\top\Sigma^{-1}(\partial f/\partial\kappa)$，取迹 $\mathfrak I(\mat K)=\operatorname{tr}\bold I\ge0$，学习代价设为 $\ell_{\text{learn}}=1/(\mathfrak I+\epsilon)$（Definition + T-optimality 措辞）。Theorem 1 在假设"当前估计 $\tilde{\mat K}$ 的 $\mathfrak I>0$ 蕴含真值 $\mathfrak I>0$"下证明相对信息增益一阶为正：

$$\Delta\bold I\approx\Big(\|(\mat K_u v(x))^\top\rho\|^2_{\tilde{\bold R}^{-1}}+\ell_{\text{task}}(z,\mu_\star)-\ell_{\text{task}}(z,\mu)\Big)\,\mathfrak I_{\mu_\star}\mathfrak I_\mu+\mathcal O(\Delta t).$$

注意两个限定：增益是**相对"只用 $\mu$ 的基线"**的；结论只有一阶精度。信息权重可在任务关键时刻置零（机器人实验里 $t=20\,\mathrm{s}$ 后置零），或按 $\gamma^{i+1}$ 衰减——工程开关而非理论必然。

## 证据与对照

**四旋翼自由落体（§Single Execution）**：1 秒内学习并稳定（成功判据 $\|x-x_d\|^2<0.01$），20 个均匀采样初值对比三种基线（两阶段 motor babble、最小二乘自适应稳定、主动高斯过程）。值得注意的诚实结果：**总信息增益上本文方法不如对手**——"其他方法通过过度激发动力学获得更多信息"；但那些方法把四旋翼导向不稳定区域，来不及稳定。本文方法在稳定误差上最快收敛，主动 GP 则因依赖局部线性化而"缺乏单次执行所需的非线性信息"。这是个有意义的方法论观察：原始信息量与完成任务并非一回事，任务约束下的信息激发才是关键。
**敏感性**（§Sensitivity）：Koopman 初始化方差在 $\{0.01,0.1,1.0,10.0\}$ 内表现相当，但作者明言"并非对所有自洽系统都如此"；$\tilde{\bold R}$ 太大不探索、太小有危险；时域 $T$ 小则反应式、大则意图式，均需按问题调。
**神经网络自动发现观测量**（§Automating Discovery）：$z_\theta,v_\theta$ 用同一组参数 $\theta$ 参数化，联合最小化 $\min_{\mat K,\theta}\frac12\sum_m\|\tilde z_\theta(x(t_{m+1}),u(t_{m+1}))-\mat K\tilde z_\theta(x(t_m),u(t_m))\|^2$；Fisher 信息只对 $\mat K$ 计算以省算力。效果：小车摆 50 次迭代稳定（加性噪声基线超过 100 次），二连杆 5 次迭代到位。已知坑：$z_\theta,v_\theta\equiv0$ 平凡解，本文的解法是把状态 $x$ 直接拼进网络输出。
**真机**（§Robot Experiments）：Sphero SPRK 沙地轨迹跟踪（20 s 主动学习后切任务），Koopman 控制器 RMSE 0.3010 / 相关 0.4028 / 相位滞后 1.1262 rad，对照 0.3535 / 0.1034 / 1.4667；Sawyer 7 自由度机械臂 100 Hz 对比内建控制器，RMSE 0.0228 对 0.0443、相关 0.9777 对 0.6026、相位滞后 0.2826 对 0.7041。作者注明 Sawyer 的内建逆动力学模型可以做得一样好甚至更好，但 Koopman 路线**不需要预先建模、不需线性化**，且模型随在线数据持续更新。

## 适用条件与边界

理论部分的条件链：控制仿射 Koopman 动态；能从 $z$ 恢复 $x$（脚注承认这是假设）；$\partial\mathcal H/\partial\mu\neq0$；Assumption 1（采样估计的正信息传递到真值）。观测量函数仍是最大软肋——作者在 Discussion 里明确说：单次执行的惊艳表现"依赖对底层系统的先验知识"（四旋翼基函数里特意放了 $v_i\omega_j$ 交叉项），随机多项式/Fourier 展开常导致 Koopman 算子特征值不稳定、难以设计基于模型的控制；自动发现又损失单执行效率且费算力。四旋翼对比中唯一在原状态空间建模的基线是主动 GP（其余都是 Koopman 字典内学习），公平性上作者以"相同基函数构造核"补救。术语提示：本文的"信息论主动学习"指 Fisher 信息 T-最优性（参数估计信息），与信息瓶颈/互信息那条线（Tishby、VIB、IB-UQ）不同源，属同名 "information-theoretic" 的另一支。源文为 LaTeX，\cite 键被抽取剥除，引用归属按正文作者描述保留；(REF(eq:regression)) 处源文本有一处括号缺失的排版损伤，不影响理解。
