# 高维非线性随机动力系统的流模型贝叶斯滤波（推理链）

- 原题：Flow-based Bayesian filtering for high-dimensional nonlinear stochastic dynamical systems
- 作者：Xintong Wang, Xiaofei Guan, Ling Guo, Hao Wu；CMAME（2025，DOI: 10.1016/j.cma.2025.118285；arXiv:2502.16232）
- 通道：TeX 源，无页码，定位用章节/公式标签；抽文中引用编号与 \ref 丢失（见疑点）。
- 关联：同批的 b340813f（Flow-based linear embedding for Bayesian filtering）为本方法的姊妹/变体论文，本篇为核心方法 FBF 的主文献（对比见文末"与姊妹论文关系"）。

## 论文自身的推进顺序

引言先历数三类既有滤波器的短板（高斯假设类、粒子类、数据驱动可处理分布类），指出现有 NF 滤波工作（NKF、CNF-DPF）的两个具体缺陷，然后给出本文方案：用 NF 把原空间 SSM 嵌入为潜空间线性高斯 SSM，使每一步滤波分布都严格高斯、可用类 Kalman 流程在线更新。第 2 节给背景与 NF 预备；第 3 节是方法主体（模型结构 → 训练算法 → 滤波两步更新的证明）；第 4 节三个数值实验按"低维非高斯 → 高维 Lorenz-96 → 随机平流扩散"递进；附录给出与标准线性潜 SSM（FBF'）的对比。

## 引言的问题设定

滤波问题：给定离散时间 SSM $\bm{x}_{k} =f(\bm{x}_{k-1},\bm{e}_{k})$，$\bm{y}_{k} =h(\bm{x}_{k},\bm{v}_{k})$，估计 $p(\bm{x}_k|\bm{y}_{1:k})$。贝叶斯递推为

$$p(\bm{x}_{k}|\bm{y}_{1:k}) \propto \int p(\bm{x}_{k},\bm{y}_{k}|\bm{x}_{k-1})p(\bm{x}_{k-1}|\bm{y}_{1:k-1})\,\mathrm{d}\bm{x}_{k-1}.$$

既有方法的缺陷链条（原文明说）：
1. KF/EKF/EnKF 依赖高斯拟设，不适用非高斯滤波分布；
2. 粒子滤波 PF 能表达非高斯后验，但高维下需要大量粒子且粒子退化（权重集中于少数粒子）；
3. QKF 用求积规则，精度优于 KF 但代价随维数激增；
4. score-based 非线性滤波（Bao et al.）在极高维表现好，但依赖对 SSM 的显式知识；
5. 数据驱动路线（RNN/LSTM/GRU 难以刻画不确定性；RKN、VAE 滤波器）都用可处理分布（高斯）近似目标分布，复杂滤波分布受限；
6. NF 滤波的已有尝试各有具体缺陷：NKF（Bézenac et al.）中状态只是潜变量、无法用于估计真实物理状态；CNF-DPF（Chen et al.）沿用粒子滤波流程，高维下采样低效。

由此引出本文的场景设定（原文斜体强调）：**SSM 的 $f,h$ 未知的非线性系统滤波**，只有仿真/实验轨迹数据可用。

## 第 2 节预备：NF 与条件密度变换

NF 把 $\bm x\in\mathbb{R}^D$ 经双射 $\mathcal{T}$ 映到 $\bm z=\mathcal{T}(\bm x)$ 服从简单分布（高斯），密度用换元公式

$$p_{\bm{x}}(\bm{x}) = p_{\bm{z}}(\bm{z}) \left|\mathrm{det}\left(\frac{\partial \mathcal{T}(\bm{x})}{\partial \bm{x}}\right)\right|.$$

一条被后续训练目标直接使用的引理（原文 Eq. 组）：对两个变量及其各自的 NF 映射 $\bm z=\mathcal{T}(\bm x)$、$\bm z'=\mathcal{T}'(\bm x')$，

$$p(\bm{x}|\bm{x}') = p(\bm{z}|\bm{z}')\cdot\left|\mathrm{det}\left(\frac{\partial\mathcal{T}(\bm{x})}{\partial\bm{x}}\right)\right|,$$

推导是分母的 Jacobian 行列式恰好约去。这一条把"潜空间条件高斯"翻译回原空间条件密度的手续固定下来。实现选 RealNVP（多仿射耦合块）。

## 第 3 节 FBF：模型结构与高斯性的来源

核心定义：$\bm{\chi}_{k} = \mathcal{T}(\bm{x}_{k})$，$\bm{\gamma}_{k} = \mathcal{V}(\bm{y}_{k})$，潜空间 SSM 取

$$\bm{\chi}_{k} = A(\bm{\gamma}_{k}) + B(\bm{\gamma}_{k}) \bm{\chi}_{k-1} + \bm{\epsilon}_{k},\quad \bm{\epsilon}_{k}\sim\mathcal{N}(0,{Q}_{\chi}(\bm\gamma_k)),$$
$$\bm{\gamma}_{k} = C + D \bm{\chi}_{k-1} + \bm{\nu}_{k},\quad \bm{\nu}_{k}\sim\mathcal{N}(0,{Q}_{\gamma}),$$

其中 $A:\mathbb{R}^{n}\to\mathbb{R}^{m}$、$B:\mathbb{R}^{n}\to\mathbb{R}^{m\times m}$、$Q_{\chi}:\mathbb{R}^{n}\to\mathbb{R}^{m\times m}$ 是 DNN，$C\in\mathbb{R}^{n}$、$D\in\mathbb{R}^{n\times m}$、$Q_{\gamma}$ 是可训练参数；$Q_\chi,Q_\gamma$ 取对角阵（附录给出 Softplus 参数化保证正定：$Q_{\chi}(\bm\gamma_k)$ 对角元为 $\mathrm{Softplus}(\tilde{Q}_{\chi,i})$，$\tilde Q(\bm\gamma_k)$ 是网络输出）。

高斯性的论证（原文给出直观解释，形式证明体现在第 3.3 节两步更新公式中）：反向看，观测方程里 $\bm{\gamma}_k$ 是 $\bm{\chi}_{k-1}$ 的线性函数加与状态无关的高斯噪声，故若 $p(\bm{\chi}_{k-1}|\bm{\gamma}_{1:k-1})$ 高斯，则给定 $\bm{\gamma}_k$ 的后验仍高斯；正向看，状态更新方程对固定的 $\bm{\gamma}_k$ 而言 $A,B,Q_\chi$ 都是常数，$\bm{\chi}_k$ 是两个高斯变量 $(\bm{\chi}_{k-1},\bm{\epsilon}_k)$ 的线性函数，仍高斯。两个 Remark 划定设计边界：$A,B,C,D$ **不得**依赖 $\bm{\chi}_{k-1}$，否则线性性被破坏、高斯性失效；该模型与传统线性 SSM 不同之处在状态更新对观测 $\bm{\gamma}_k$ 的非线性依赖，传统线性 SSM 是其特例（附录 A 给出等价改写），数值实验显示本文模型更优。

原空间滤波分布由换元恢复：

$$p(\bm{x}_{k}\mid\bm{y}_{1:k})=p(\bm{\chi}_{k}\mid\bm{\gamma}_{1:k})\left|\mathrm{det}\left(\frac{\partial\mathcal{T}(\bm{x}_{k})}{\partial\bm{x}_{k}}\right)\right|.$$

【分析重建：这个设计的关键权衡是"非高斯性全部打包进 NF 的双射 $\mathcal{T},\mathcal{V}$，动力学部分则约束为观测条件下的仿射模型"——滤波递推需要的高斯闭包在潜空间维持，表达能力由 NF 承担】

## 训练：极大似然 + 条件密度翻译

由条件密度引理，潜 SSM 给出两个原空间条件密度的参数化模型：

$$p(\bm{x}_{k}|\bm{x}_{k-1},\bm{y}_{k}) = \mathcal{N}\left(\mathcal{T}(\bm{x}_{k})\,\big|\,A(\mathcal{V}(\bm{y}_{k}))+B(\mathcal{V}(\bm{y}_{k}))\mathcal{T}(\bm{x}_{k-1}),Q_{\chi}(\mathcal{V}(\bm{y}_{k}))\right)\left|\mathrm{det}\left(\frac{\partial\mathcal{T}(\bm{x}_{k})}{\partial\bm{x}_{k}}\right)\right| \triangleq f_{s}(\bm{x}_{k-1},\bm{x}_{k},\bm{y}_{k}),$$

$$p(\bm{y}_{k}|\bm{x}_{k-1}) = \mathcal{N}\left(\mathcal{V}(\bm{y}_{k})\,|\,C+D\mathcal{T}(\bm{x}_{k-1}),Q_{\gamma}\right)\left|\mathrm{det}\left(\frac{\partial\mathcal{V}(\bm{y}_{k})}{\partial\bm{y}_{k}}\right)\right| \triangleq f_{o}(\bm{x}_{k-1},\bm{y}_{k}).$$

训练目标（对轨迹数据 $\bm{x}_{0:K}^{\mathrm{train}},\bm{y}_{1:K}^{\mathrm{train}}$ 的极大似然）：

$$\mathcal{L}(W) = \frac{\alpha}{K} \sum_{k=1}^{K} \log f_s(\bm{x}_{k-1}^{\mathrm{train}}, \bm{x}_k^{\mathrm{train}}, \bm{y}_k^{\mathrm{train}}) + \frac{\beta}{K} \sum_{k=1}^{K} \log f_o(\bm{x}_{k-1}^{\mathrm{train}}, \bm{y}_k^{\mathrm{train}}),$$

用 SGD（Algorithm 1）小批更新；实验中统一取 $\alpha=\beta=1$。初始分布的处理是一个务实近似（原文明说）：训练时不建模 $p(\bm x_0)$（理由：实践中常取大方差无信息先验），训练后用 $\mathcal{T}(\bm x_0)$ 样本的均值/协方差直接估计 $\bm\mu_0,\bm\Sigma_0$，取 $p(\bm{\chi}_0) = \mathcal{N}(\bm{\chi}_0 | \bm{\mu}_0, \bm{\Sigma}_0)$；数值上仍取得满意效果。

## 滤波：两步闭式更新

设 $p(\bm{\chi}_{k-1}|\bm{\gamma}_{1:k-1}) = \mathcal{N}(\bm{\mu}_{k-1}, \bm{\Sigma}_{k-1})$，新观测 $\bm{\gamma}_k=\mathcal{V}(\bm y_k)$ 到来。

Step 1（用线性观测方程做"预测-校正"）：由贝叶斯规则合并两个高斯因子，配平二次型得

$$\bm{\mu}_{k-1}^{'} = \bm{\mu}_{k-1} + \bm{\Sigma}_{k-1}D^{\top}Q_{\gamma}^{-1}(\bm{\gamma}_{k} - C - D\bm{\mu}_{k-1}),\qquad \bm{\Sigma}_{k-1}^{'} = \bm{\Sigma}_{k-1} - \bm{\Sigma}_{k-1}D^{\top}Q_{\gamma}^{-1}D\bm{\Sigma}_{k-1}.$$

【分析重建：这是标准共轭高斯更新——把 $\bm\gamma_k$ 视作对 $\bm\chi_{k-1}$ 的线性量测，$D$ 扮演观测矩阵】

Step 2（用条件仿射状态方程推进）：对高斯线性模型积分掉 $\bm{\chi}_{k-1}$，

$$\bm{\mu}_{k} = A(\bm{\gamma}_{k}) + B(\bm{\gamma}_{k})\bm{\mu}_{k-1}^{'},\qquad \bm{\Sigma}_{k} = B(\bm{\gamma}_{k})\bm{\Sigma}_{k-1}^{'}B(\bm{\gamma}_{k})^{\top} + Q_{\chi}(\bm{\gamma}_{k}).$$

注意 $\bm\gamma_k$ 已知时 $A,B,Q_\chi$ 都是确定值，所以这两式与 Kalman 增益无关、无需求解增益方程——这是该模型结构带来的简化。在线采样：$\bm{\chi}_k^{(j)}\sim\mathcal{N}(\bm{\mu}_{k},\bm{\Sigma}_{k})$，$\bm{x}_k^{(j)} = \mathcal{T}^{-1}(\bm{\chi}_k^{(j)})$（Algorithm 2）。密度求值与采样都由 NF 的可逆性保证。

## 第 4 节数值实验

评测指标（附录 B 给出公式）：RMSE（后验均值与真值的误差，$\mathrm{RMSE} = \sqrt{\frac{1}{mK} \sum_{k=1}^{K} \|\bm{x}_k^{\mathrm{true}} - \frac{1}{N} \sum_{j=1}^{N} \bm{x}_k^{(j)}\|^2}$）；MMD（用核 $\mathrm{ker}(\bm{x},\bm{y}) = \exp(-\|\bm{x} - \bm{y}\|^2/(2\sigma^2))$，$\sigma=2$，把样本经验分布与真值点分布比对后按时间平均）；CRPS（逐分量 CDF 差的 $L^2$ 积分，再对分量与时间平均）。基线：PF（用真实 SSM 执行）、RKN（编码器-解码器 + 循环 Kalman 层，高斯解码器）、CNF-DPF（条件 NF 构造提议分布的可微粒子滤波）。硬件：Intel Xeon E5-2650 v4 + RTX 2080 Ti。

**实验 1（二维合成非线性模型）**：$\bm{x}_{k} = 0.9\,\mathrm{sin}(1.1\bm{x}_{k-1} + 0.1\pi) + 0.01 + \bm{e}_k$（$\bm e_k\sim\mathcal{N}(0,q^2I_2)$，$q^2=0.1$），量测 $y_{k} = \mathrm{arctan}(x_{k,2}/x_{k,1}) + v_{k}$（$\bm v_k\sim\mathcal{N}(0,r^2I_2)$），$r^2\in\{0.025, 0.05, 0.075, 0.1\}$，$K=100$，$N=1000$ 条训练轨迹，先验均值 $(1,1)$、协方差 $0.1I_2$。结果（Fig. 2，200 条测试轨迹）：PF 精度最高（低维下粒子足以覆盖）；FBF 接近 PF；$r^2\ge 0.05$ 时 FBF 显著优于 RKN 与 CNF-DPF。Fig. 3（$k=50$ 的分布可视化）显示 FBF 捕捉到与 PF 一致的强非高斯后验，RKN 因高斯假设失效，CNF-DPF 接近但有偏差。计算成本（表 1，500 次训练迭代 / 200 条测试轨迹，单位秒）：offline FBF 435.18、RKN 5965.41、CNF-DPF 12840.28；online PF 17.09、FBF 120.44、RKN 52.49、CNF-DPF 1084.45——FBF 训练比两个数据驱动基线快一个量级以上，在线慢于 RKN 是因为要把样本逆变换回原空间，但仍远低于 CNF-DPF。

**实验 2（随机 Lorenz-96 高维状态估计）**：$\frac{\mathrm{d}x_{t,j}}{\mathrm{d}t} = x_{t,j-1}(x_{t,j+1} - x_{t,j-2}) - x_{t,j} + F + \frac{\mathrm{d}W(t)}{\mathrm{d}t}$，循环边界，$F=8$（混沌），初值 $x_{0,j} = \mathrm{sin}(2\pi j/m)$；量测 $\bm y_t = \bm x_t^3 + \bm v_t$，$\bm v_t\sim\mathcal{N}(0,I_m)$。RK4 仿真，观测间隔 $\Delta t = 0.01$，维数 $m = 10,20,\cdots,50,100$；每个 $m$ 用 2000 条长度 $K = 500$ 的轨迹训练、200 条测试。结果（Fig. 5）：PF 与 CNF-DPF 在高维误差显著变大（CNF-DPF 只做到 $m\le 30$，更高维 GPU 显存不够）；RKN 在 $m\le 30$ 与 FBF 相当，$m\ge 40$ 开始失准；FBF 在高维持续最好。作者将 RKN 的高维退化归因于其简单解码器不足以表达复杂高维分布，而 FBF 的 NF 架构更灵活。区间可视化（Fig. 6–7）：$m=10$ 时 CNF-DPF 均值有偏、PF 因粒子退化不确定性区间覆盖失效、FBF 与 RKN 均良好；$m=100$ 时 RKN 误差与不确定性显著增大、PF 严重退化，FBF 后验均值仍贴合真值、标准差有效覆盖。计算成本（表 2，秒）：offline FBF 从 $m=10$ 的 9419 到 $m=100$ 的 23704，RKN 为 297987–378972（约 30 倍）；online FBF 590–968，RKN 357–498（RKN 略快），PF 高维在线极贵（$m=100$ 达 111081），CNF-DPF 不可行。

**实验 3（随机平流–扩散方程）**：$\mathrm{d}u + (\kappa\partial_{s}u - D\partial_{ss}^{2}u + g(s))\,\mathrm{d}t = \sigma\,\mathrm{d}W(t)$，$s\in [-1, 1]$，$t\in [0, 1]$，零边界，初值 $u(0, s) = -\mathrm{sin}(\pi s)$；$g(s) = 5(s^2 - 1)$，$\sigma = 10$，$D = 0.01$，$\kappa = 0.5$。隐式有限差分在 $201\times 100$ 网格上生成参考解；状态 $\bm x_k$ 为 100 个网格点的浓度，量测 $y_{k,i} = e^{-u(k\Delta t,s_{i}^{\prime})-1} + v_{k,i}$（$\bm v_k\sim\mathcal{N}(0,r^2 I_n)$），$n$ 个等距传感器，$\Delta t = 0.005$；1000 条训练、200 条测试；CNF-DPF 因显存被排除。结果：FBF 在不同噪声水平（$n=25$）下精度与 UQ 均最优（Fig. 9 a,c,e）；传感器减到 $n=10$ 时 FBF 性能下降但仍优于 PF、RKN（Fig. 9 b,d,f）。区间图（Fig. 10，$n=10$）揭示一个机制性差别：RKN 的标准差没有在传感器附近收缩，而 FBF 在测点附近标准差小、无测点区域标准差大——不确定性随观测密度自适应。PF 退化导致区间不覆盖误差（尤其 $t = 0.75$、$t = 1.0$）。成本（表 3，秒）：offline FBF 895.26 对 RKN 95956.56；online PF 6443.25（每粒子每步要解 100 维隐式差分线性方程组）、FBF 455.51、RKN 162.12——FBF 在两个阶段间取得平衡。

## 附录 A：与标准线性潜 SSM（FBF'）的对比论证

FBF' 用传统线性高斯潜 SSM：$\bm{\chi}_{k} = E + F\bm{\chi}_{k-1} + \bm{\zeta}_{k}$（$\bm{\zeta}_{k} \sim \mathcal{N}(0, P_{\chi})$），$\bm{\gamma}_k = G + H\bm{\chi}_{k} + \bm{\xi}_{k}$（$\bm{\xi}_{k} \sim \mathcal{N}(0, P_{\gamma})$），滤波用标准 Kalman 更新（$\bm{\mu}_{k} = E + F\bm{\mu}_{k-1} + K_k(\bm{\gamma}_k - HF\bm{\mu}_{k-1} - HE - G)$，$\bm{\Sigma}_{k} = (I_m - K_kH)(F\bm{\Sigma}_{k-1}F^{\top} + P_{\chi})$，$K_k = (F\bm{\Sigma}_{k-1}F^{\top} + P_{\chi})H^{\top}S_k^{-1}$，$S_k = H(F\bm{\Sigma}_{k-1}F^{\top} + P_{\chi})H^{\top} + P_{\gamma}$）。论文用一组消元证明 FBF' 是 FBF 的特例：合并 $p(\bm{\gamma}_{k}|\bm{\chi}_{k})\cdot p(\bm{\chi}_{k}|\bm{\chi}_{k-1})$ 得

$$\bm{\chi}_{k} = \underbrace{E - K_{k}^{'}(G+HE) + K_k^{'}\bm\gamma_{k}}_{A} + \underbrace{(F - K_{k}^{'}HF)}_{B}\bm\chi_{k-1} + \bm\zeta_{k}^{'},\quad \bm\zeta_{k}^{'}\sim\mathcal{N}(0, (I_m - K_k^{'}H)P_{\chi}),$$
$$\bm{\gamma}_{k} = \underbrace{G+HE}_{C} + \underbrace{HF}_{D}\bm{\chi}_{k-1} + \bm{\xi}_{k}^{'},\quad \bm{\xi}_{k}^{'}\sim\mathcal{N}(0, HP_{\chi}H^{\top} + P_{\gamma}),\qquad K_{k}^{'} = P_{\chi}H^{\top}(HP_{\chi}H^{\top} + P_{\gamma})^{-1}.$$

即 FBF 的 $A(\bm\gamma_k)$、$B(\bm\gamma_k)$ 取成 $\bm\gamma_k$ 的仿射函数、$D$ 常数时恰好回收 FBF'。数值对比（附录 A 表）：FBF' 与 FBF 计算量同阶（offline 469.97 对 435.18 秒，online 132.81 对 120.44 秒）但误差全面更高——支持"对观测的通用非线性依赖带来表达力增益"这一主张。

## 适用条件与边界

- 场景限定：$f,h$ 未知、仅有轨迹数据；若 SSM 显式已知，score-based 滤波（引言承认）在极高维精度更高——FBF 的卖点是精度-成本-免模型三者的平衡。
- 高斯性成立要求 $A,B,Q_\chi$ 只依赖 $\bm\gamma_k$、$C,D,Q_\gamma$ 为常数；若允许依赖 $\bm\chi_{k-1}$ 结构即破坏闭式更新（Remark 1）。
- $Q_\chi,Q_\gamma$ 强制对角化（为实现便利），作者称实验上不影响性能，但无理论证明。
- 初始分布训练时不建模，用样本均值/协方差近似；论文自述这是近似处理，先验极宽（无信息）时按训练分布外推的行为未验证。
- 状态维数与观测维数固定于训练配置；实验未测非平稳、变维或在线适应场景。
- 训练数据要求覆盖系统动力学的轨迹（实验用数百到数千条），数据稀少时的泛化未讨论。

## 反例与失败模式

- PF 与 CNF-DPF 的高维失败（粒子退化、显存溢出）被论文用作反例刻画既有方法的边界。
- FBF 自身的弱点（原文承认）：在线阶段比 RKN 慢（逆变换开销）；$n$ 减少时精度下降；结论与被注释的展望段指出未来要引入物理信息、扩展到参数辨识与真实场景（地球物理反演、气候建模）。

- 附录中 $f_s'$ 的定义式 $\mathcal{N}(\mathcal{T}(\bm{x}_k)|E + F\mathcal{T}(\bm{x}_{k-1}),P_{\gamma})$ 的协方差写作 $P_{\gamma}$，按上下文应为 $P_{\chi}$（疑点，原文/抽文如此）。
- 与姊妹论文 b340813f（flow-based linear embedding）的关系：本篇提出并验证 FBF，含 FBF' 特例对比；姊妹篇侧重线性嵌入框架的展开（待对照其内容确认差异后在其推理链中记录）。
