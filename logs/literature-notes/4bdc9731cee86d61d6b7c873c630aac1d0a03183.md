# 高斯信息瓶颈与非微扰重整化群（Gaussian Information Bottleneck and the Non-Perturbative Renormalization Group）

Kline & Palmer，arXiv:2107.13700，2021。LaTeX 源通道，定位用章节/公式号。

## 论证主线：把"IB 与 RG 是否形式等价"归结为非确定性粗粒化映射

论文提出的核心等价命题有明确的筛选逻辑：IB 的压缩映射 $P_\beta(\tilde{x}|x)=\argmin_{P(\tilde{x}|x)} I(X;\tilde{X}) - \beta I(\tilde{X};Y)$ 是非确定性的（随机）映射，因此能与之精确对应的 RG 方案必须使用"软截止"。Wilsonian 动量壳层方法的 decimation 是确定性映射，被作者明确排除在精确对应之外；软截止 NPRG（Wegner-Houghton 的替代方案：Wilson-Kogut、Polchinski、Wetterich）的粗粒化映射 $P_k[\tilde{\chi}|\chi]$ 恰是高斯的，从而与 IB 匹配。作者还预先列出三个"明显不匹配"并逐一处理：临界性要求无穷多自由度而 IB 的 $X$ 有限维；"降维"在 RG 指模型空间收敛到临界流形、在 IB 指表示维数真实减少；RG 中没有 $Y$ 的对应物——最后一点恰是本文要利用的特质：IB 可以"强加"一种以功能/相关性定义的"大尺度结构"。

为使一切可解析，全文限定在高斯统计（GIB，Chechik 等的精确解）：给定联合高斯 $P(x,y)$，粗粒化映射参数化为 $\tilde{X}=AX+\xi$（$\xi\sim\mathcal{N}(0,\Sigma_\xi)$），精确解为

$$A(\beta) = \text{diag}\{\alpha_i(\beta)\}V^T,\quad \alpha_i(\beta) = \left[\frac{\beta(1-\lambda_i) - 1}{\lambda_i s_i}\right]^{1/2}\Theta\left(\beta - \frac{1}{1-\lambda_i}\right),\quad \Sigma_\xi = I,$$

其中 $\Sigma_X^{-1}\Sigma_{X|Y}V = V\,\text{diag}\{\lambda_i\}$ 为"典型相关矩阵"的特征分解（$\lambda_i\in[0,1]$，$V$ 一般非正交），$s_i=[V^T\Sigma_X V]_{ii}$，$\beta_i=(1-\lambda_i)^{-1}$ 为各模的临界瓶颈值。映射的非唯一性来自 IB 目标对可逆变换的不变性；保持高斯性的对称群是可逆线性变换 $\tilde{X}\to L\tilde{X}$，检验最优性的不变量是 $V^{-1}A^T\Sigma_\xi^{-1}AV^{-T}$。

## 第一个结果：GIB 的半群结构与信息论"长度标尺"

作者证明了逐次 GIB 压缩的复合仍是 GIB 最优（附录 A 给出完整推导）：在自然基 $X\to V^TX$ 下两个映射 $(A_1,\Sigma_{\xi_1})=(A_1,I)$、$(A_2,\Sigma_{\xi_2})=(A_2,I)$ 的复合为 $(A,\Sigma_\xi)=(A_2A_1, A_2A_2^T + I)$，直接验证 $[A_1A_2(A_2^2+I)^{-1}A_2A_1]_{ij} = \alpha_i^2(\beta_2\circ\beta_1)\delta_{ij}$，其中复合算子

$$\beta_2 \circ \beta_1 = \frac{\beta_2 \beta_1}{\beta_2 + \beta_1 - 1}.$$

推导的关键中间步骤是 $\lambda'_i = \min\{\frac{\beta_1}{\beta_1 - 1} \lambda_i,\, 1\}$ 与 $s'_i = \frac{\beta_1(1 - \lambda_i)- 1}{\lambda_i}\Theta(\beta_1 - \frac{1}{1 - \lambda_i}) + 1$（第一级压缩后 $\tilde{X}_1$ 的典型相关统计量，需用 $\Sigma_{\tilde{X}_1|Y} = A_1 \Sigma_{X|Y} A_1^T + I$ 回到原 $X$-$Y$ 统计量表示）。作者强调 $\circ$ 是被这一计算所"定义"的：若 GIB 无半群结构则根本无从识别 $\circ$。该算子封闭于 $(\mathbb{R}_{>1},\circ)$、满足结合律，$\beta=\infty$ 是单位元（对应零压缩极限），且交换——但 $P_{\beta_1\circ\beta_2}(\tilde{x}|x)$ 与 $P_{\beta_2\circ\beta_1}(\tilde{x}|x)$ 只需在压缩总量上一致，因 $\tilde{X}\to L\tilde{X}$ 对称性可以不同。

与 RG 类比的关键一步是引入满足 $b(\beta_2\circ\beta_1)=b(\beta_2)b(\beta_1)$ 的函数

$$b(\beta) = \frac{\beta}{\beta - 1},$$

作为"长度重标因子"的信息论类似物。边界检查符合直觉：$\beta\to\infty$（无压缩）时 $b\to1$；$\beta\to1$ 时由数据处理不等式最优解退化为完全粗粒化（$\tilde{X}$ 与 $X$ 独立），对应 $b\to\infty$。作者随即自我限定：GIB 只描述纯高斯统计故无反常标度、无法定义临界指数；$X,Y$ 有限维故不能连接动量壳层 RG；"模型空间"对应物尚未找到——这些限制被明说，$b(\beta)$ 的意义暂限于"信息论量"而非已实现 RG 标度分析。作者还提出一个实用推论：若一般 IB 问题也有半群结构，则可用多次低压缩（高 $\beta$）逐步训练代替一次大压缩，例如把前馈 IB 网络的训练分解为逐层小问题。

## 第二个结果：软截止 NPRG 的粗粒化映射可以反过来定义调节子

论证的桥梁（§3.1）是软截止 UV 调节的平均作用量 $-\Gamma_k^{\text{av}}[\tilde{\chi}] = \log \int \mathcal{D}\chi\, P_k[\tilde{\chi}|\chi] \exp(-S[\chi])$，其中高斯粗粒化映射 $P_k[\tilde{\chi}|\chi] = \exp\{-\frac{1}{2}(\tilde{\chi}- A_k\chi)^\dagger \Delta_k^{-1}(\tilde{\chi}-A_k\chi) - C_k\}$。作者证明：仅从 $P_k$ 一族映射即可同时重构 IR 与 UV 两支流——把 $P_k$ 代入配分函数得 $\tilde{J}[\tilde{\chi}] = A_k^\dagger \Delta_k^{-1} \tilde{\chi}$，且

$$\Delta S_k[\chi] = \frac{1}{2}\chi^\dagger A_k^\dagger \Delta_k^{-1} A_k \chi,$$

即 IR 调节子 $R_k = A_k^\dagger \Delta_k^{-1}A_k$ 来自粗粒化映射中的 $\chi^2$ 项（作者解读为"粗粒化映射的自由能"）。注意该表述相对 Polchinski 方案的一个差异（作者明说）：源 $J$ 非线性地进入有效相互作用势，因为这里对每个初始源构型定义流而非在真空流上加线性源项。

把 $P_k[\tilde{\chi}|\chi]$ 与 $P_\beta(\tilde{x}|x)$ 等同后，GIB 最优性强制出唯一的调节子（附录 B 给推导：$R_\beta^{(\text{IB})} = A(\beta)^T \Sigma_\xi^{-1}A(\beta)$，再作 $\beta_i=(1-\lambda_i)^{-1}$ 替换，自然基下）：

$$[R_\beta^{(\text{IB})}]_{ij} = \frac{\beta - \beta_i}{s_i (\beta_i - 1)} \Theta(\beta - \beta_i)\delta_{ij}.$$

作者逐条验证它满足 NPRG 调节子的三条设计约束（低动量模增质、高动量模不受影响、$k\to\infty$ 时 $\Gamma_k$ 回到裸作用量），并指出两个边界情形：$\beta_i\to1$ 对应某模与 $Y$ 确定性相关、$\beta_i\to\infty$ 对应完全独立，均需修正或删除该模。概念转换："长程模"的类比被替换为"携带最多关于 $Y$ 信息的模"，截止参数的对应为 $k^2\to\beta$、$q^2\to\beta_i$（注意 $\beta,\beta_i$ 应在 $k^2,q^2\to0$ 时趋于 1）。

## 第三个结果：BA 自洽更新可替代流方程，以及"集体模不必是 Fourier"

§4.1 把 Blahut-Arimoto 迭代 $P_\beta(\tilde{x}|x) = Z_\beta(x)^{-1} P_\beta(\tilde{x})\exp(-\beta D_{\text{KL}}[P(y|x)||P_\beta(y|\tilde{x})])$ 用 NPRG 关心的对象重新参数化（附录 C 给推导），得到紧凑的自洽更新：

$$\Sigma'_{X|\tilde{X}} = [\Sigma_X^{-1} + \beta^2 B^T \Sigma'_{\tilde{X}|X}B]^{-1},\quad \Sigma'_{\tilde{X}} = [\Sigma'^{-1}_{\tilde{X}|X} - \beta^2 B \Sigma_{X|\tilde{X}} B^T]^{-1},\quad \Sigma'_{X\tilde{X}} = \beta \Sigma'_{X|\tilde{X}}B^T\Sigma'_{\tilde{X}},$$

其中 $\Sigma_{X|\tilde{X}}$ 类比 Wetterich 的有效传播子 $G_k$（IR 调节流）、$\Sigma_{\tilde{X}}$ 对应 UV 调节部分。作者对"这是否真的提供了新杠杆"做了诚实的自我检验：Wilsonian RG 的全部意义在于绕开 $\int dx\,P(y|x)P(x|\tilde{x})$ 这个不可直接计算的积分，IB 自洽方案要同样有效需要 (1) 参数化 BA 过程、(2) 参数化推导不要求显式边缘化 $x$——高斯情形满足 (1) 但不满足 (2)（推导中显式做了高斯积分），且这两条只是必要条件。结论是开放而非断言：目前尚不清楚 IB 结构能否一般地参数化 $P(y|\tilde{x})$。

§4.2 的玩具模型回答"IB 调节子在熟悉语境中长什么样"：$d$ 维实标量场 $\chi$ 带无序源场 $h$ 作 $Y$，$\mathcal{H}[\chi|h] = \frac{1}{2}\chi^T G_0^{-1} \chi - h^T\chi$，$\log P[h]\sim-\frac{1}{2}h^TH^{-1}h$，整个 $P[\chi,h]$ 联合高斯。核心恒等式是 $\Sigma_\chi^{-1}\Sigma_{\chi|h} = (I + H G_0)^{-1}$（只由高斯积分恒等式得出）。三种 $H$ 构造给出递进结论：其一，$H=\eta\delta^d(x_1-x_2)$ 时特征函数为平面波 $V(x,q)=(2\pi)^{-d/2}e^{iq\cdot x}$、$\lambda(q)=(1+\eta\tilde{G}_0(q))^{-1}$（$\tilde{G}_0(q)=1/(t+q^2)$），临界值 $\beta(q)=\frac{1}{\eta \tilde{G}_0(q)} + 1$，代回得

$$R^{(\text{IB})}_k(q) = \frac{t + q^2}{t + q^2 + \eta} (k^2 - q^2) \Theta(k^2 - q^2) = \lambda(q) R^{(\text{L})}_k(q),$$

即 IB 调节子恰为 Litim 调节子乘以典型相关特征值，且 $\eta\to0$ 时回到 Litim——作者称 Litim 在此的出现"非平凡"，因其原始推导诉诸与 IB 无关的最优性。其二，$H$ 在 Fourier 基下对角但 $\eta$ 带 $q$ 依赖时得到带色散的动量截止；作者指出极端选择如 $\eta(q)\sim \tilde{G}^{-2}_0(q)$ 可使 $\beta(q)$ 随 $q$ 单调递减、长波模先被积出——但承认这种构造有病理、在连续极限下难解释，故未深入。其三，$H=\eta\,\mathcal{F}^\dagger \tilde{G}^{-1/2}_0 \mathcal{F}_\alpha \tilde{G}_0 \mathcal{F}_\alpha^\dagger \tilde{G}^{-1/2}_0 \mathcal{F}$（$\mathcal{F}_\alpha$ 为分数 Fourier 变换）时特征模 $V^\dagger[\cdot](u)=\{\tilde{G}_0^{1/2}\mathcal{F}_\alpha^\dagger \tilde{G}_0^{-1/2}\mathcal{F}\}[\cdot](u)$ 的标签 $u$ 既非位置也非波数，调节子仍保持简洁形式 $R^{(\text{IB})}_v(u) = \lambda(u)R^{(\text{L})}_v(u)$，但 $u,v$ 只有"按对 $h$ 的预测力排序集体模"的信息论含义。作者明示这类计算的病理（$V$ 作为 $|q_{\text{max}}|\to\infty$ 发散、在 $x,u$ 中不连续）源于"IB 只适合有限自由度而场论无限"，属越界演示；但其含义对无局域概念的系统（作者举大脑长程连接为例）可能关键。

## $Y$ 的多重物理诠释与适用边界

§4.3 列出 $Y$ 的三种构造：环境型（区域外自旋，Gordon 等已证明在 buffer 无穷大时低 $\beta$ 的 IB 集体变量对应最小标度维数即 RG 最相关算符）；时间预测型（$Y$ 为未来，等价于慢特征分析的一类）；驱动型（$X$ 被随机信号 $Y$ 驱动，此时最相关模不再简单是慢变分量）。一般构造规则：高斯联合分布 $\{Z_i\}$ 划分为不相交的 $X$、$Y$（及可选的哑集），若不相交性被破坏则 $X,Y$ 确定性相关、GIB 失效。作者明示这些联系不覆盖动力学的非平衡 NPRG（要求 $P(X,Y)$ 平稳）。

结论中的边界声明相当明确：IB 一般极难求解，"把 NPRG 方案限制在一族精确 IB 解上是完全不现实的"；作者提出两条务实路线——更好的参数化 BA（但"鉴于我们导出的精确高斯形式已经很复杂，似乎不太可行"），或放松 IB 最优性约束、直接用 $R^{(\text{IB})}$ 代入标准 NPRG 流方程（统计量不再严格 IB 最优，但实施难度与普通 NPRG 相当）。理想适用场景是"大而有限"的 $X$ 与大量随机变量 $Y$ 统计耦合的系统，生物物理系统被点名为佳例，因为 $Y$ 可取生物学功能。

## 疑点

- 正文 Eq. REF(eq:R_IB_def) 的调节子在附录 B 中出现两种基（原始基带 $V$、自然基为对角），正文给出的是自然基形式；两处系数 $\frac{\beta - \beta_i}{s_i(\beta_i - 1)}$ 的推导依赖 $\alpha_i^2$ 的替换，代数链条完整但未逐行展示（附录 B 有中间式）。
- 正文一处文字与公式不严格一致：Fig. 1 图注说"较小的 $\lambda$ 的模携带更多关于 $Y$ 的信息"并"在流后期才被积出"，而按 $\beta_i=(1-\lambda_i)^{-1}$，$\lambda\to0$ 给 $\beta_i\to\infty$，即该模最迟被积出——正文口述与公式一致，但"smaller eigenvalue carry more information"的表述容易与 GIB 中保留条件熵 $\Sigma_{X|Y}=s_i\lambda_i$ 的方向混淆（$\lambda$ 小意味着条件方差小、保留信息多），此处为表述歧义而非错误。
- 附录 C 的 BA 更新式中 $B$ 与 $\Sigma'_{\tilde{X}|X}$ 的完整表达式被作者声明"fully given in appendix"，但源文本所含附录 C 只给到 $y=Wx+z$ 的展开起点，完整 $B$ 的显式表达未见于所提供的 TeX（可能截断）——标为疑点。
- 源文本引用为裸引用（bibliography 未含），Chechik、Wetterich、Litim、Gordon 等具体编号无法核对。
