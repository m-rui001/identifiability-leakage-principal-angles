# 强化学习中的泛化：选择性噪声注入与信息瓶颈（IBAC-SNI）

原题：Generalization in Reinforcement Learning with Selective Noise Injection and Information Bottleneck（Igl et al., NeurIPS 2019，arXiv:1910.12911，DOI: 10.48550/arxiv.1910.12911）。LaTeX 源通道，定位用章节号与公式号。

## 核心主张与其非平凡性

论文的主张分为三层。第一层（诊断性主张）：把监督学习的随机正则化技术（Dropout、BatchNorm、VIB 等）直接搬进 RL 会失效甚至有害，根源在于 RL 的两个结构性差异——训练数据由被学习的模型自身生成（数据分布依赖正则化方法），且训练早期数据分布非平稳、多样性低。第二层（方法主张）：提出选择性噪声注入（SNI），在需要正则化的地方保留噪声、在损害梯度质量的地方暂时悬置噪声。第三层（方法主张）：提出 IBAC（信息瓶颈 actor-critic），利用 IB 在低数据 regime 偏向压缩特征的性质加速学习更泛化的特征。组合后 IBAC-SNI 在 Multiroom 与 Coinrun 上大幅超越当时最优。

非平凡性在于：此前工作（论文引用的 Coinrun 基准上的正则化研究）把"监督学习正则化对 RL 有效"当作可整体迁移的结论，而本文论证迁移必须以 RL 梯度估计的具体结构为条件——噪声进入 rollout 策略、critic 和 off-policy 重要性权重三条通道的后果各不相同。这不是"加正则化"而是"在哪里加、何时加"的结构性论证。

## 诊断论证的重建：噪声为何伤及 RL 梯度

原文明说部分：作者对比两个目标。监督学习为 $\max_\theta \mathbb{E}_{\mathcal{D}}[ \log p_\theta(y|x)]$，被更新的 $p_\theta(y|x)$ 不参与数据生成；RL 的 actor 目标为 $J(\pi_\theta)=\mathbb{E}_{\pi_\theta(a|s)}[ \sum_t \gamma^t R_m(s_t,a_t) ]$，被学习的分布 $\pi_\theta(a|s)$ 本身就在数据生成路径上。对于所评估的 off-policy actor-critic 类方法（PPO），策略梯度定理加上 critic 基线/自举后的梯度估计为（原文 Eq.(4)，颜色标注在源文中区分蓝/橙角色，此处照录其公式本体）：

$$\nabla_\theta J({\pi_\theta}) = \mathbb{E}_{ \pi^r_\theta(a_t|s_t)}\left[ \sum_t^T \frac{\pi_\theta(a_t|s_t)}{\pi^r_\theta(a_t|s_t)} \nabla_\theta \log \pi_\theta(a_t|s_t) (r_t + \gamma V_\theta(s_{t+1}) - V_\theta(s_t)) \right]$$

critic 的目标为（Eq.(5)）：

$$L_{\text{AC}}^V = \min_\theta \mathbb{E}_{ \pi^r_\theta(a_t|s_t)}\left[\left( \gamma V_\theta^\perp(s_{t+1}) + r_t - V_\theta(s_t) \right)^2\right]$$

（上标 $\perp$ 表示该项被视为常数。）从这两式，作者指出噪声进入三个位置的后果：i) 注入 rollout 策略 $\pi^r_\theta$ 会导致不良动作、提前终止回合，恶化观测数据质量；ii) 对 $\pi_\theta$ 与 $\pi^r_\theta$ 注入的噪声可以不同，抬高 off-policy 修正项 $\pi_\theta/\pi^r_\theta$ 的方差，进而抬高梯度方差；iii) critic $V_\theta$ 中的噪声同时增大策略与 critic 梯度更新的方差。

分析重建（作者未逐字说出但论证隐含）：监督学习里随机正则化的"噪声即正则"逻辑成立于损失是数据上的期望、且数据固定的情形；而 Eq.(4) 中蓝色（被更新）量与橙色（数据生成与方差来源）量交织，噪声落在橙色位置时不再起"隐式集成"作用，而是变成纯方差源。这解释了为何同一技术在两个范式中的收益/成本结构不同。这一重建是对原文 §3 论证步骤的补全，原文只以三条 i/ii/iii 列举后果，未明说"正则化收益与方差代价分属不同通道"这一总结。

## SNI 的设计与理由

SNI 的前提是多数噪声注入技术可"临时悬置"噪声：Dropout 可冻结一个 dropout mask，VIB 可取后验的众数（mode）而非采样，BatchNorm 可用移动平均或冻结统计量。记 $\bar{\pi}_\theta$ 为悬置噪声后的组件（原文注意 $\bar{\pi}_\theta$ 不必然整体确定，例如网络输出分布参数时）。SNI 对策略梯度损失的修改为（Eq.(6)）：

$$\mathcal{G}^{\text{SNI}}_{\text{AC}}(\pi_\theta^r, \pi_\theta, V_\theta) = \lambda \mathcal{G}_{\text{AC}}(\bar{\pi}_\theta^r, \bar{\pi}_\theta, \bar{V}_\theta) + (1-\lambda) \mathcal{G}_{\text{AC}}(\bar{\pi}_\theta^r, \pi_\theta, \bar{V}_\theta)$$

三项对应三条噪声通道：critic 一律用去噪的 $\bar{V}_\theta$（消掉通道 iii）；rollout 一律用 $\bar{\pi}^r$（消掉通道 i，且两 term 共享同一批采集数据）；被更新策略在 $\bar{\pi}_\theta$（确定性项）与 $\pi_\theta$（保留正则化噪声）之间按 $\lambda$ 混合（处理通道 ii——确定性项保证重要性权重低方差）。注意原文强调 $\lambda=1$ 时若作用于 VIB，等效于对激活的 L2 惩罚：因 $z$ 的方差被忽略，高斯间的 KL 退化为均值平方差。

推理步骤重建：为什么混合而不用纯确定性？因为悬置噪声后正则化效果消失，所以第二项保留噪声以维持正则；为什么两 term 共享 $\bar{\pi}^r$？原文说这允许复用同一采集数据并共享大部分计算——这是把"保留正则"与"压低方差"分离成可加项的工程化表达。此段推理链原文较完整，重建成分少。

## IBAC：IB 作为低数据 regime 的正则

动机链（原文明说）：RL 训练早期状态集中在初始状态附近、数据多样性低，而 policy/critic 未收敛导致目标值方差大，低信噪比下网络易学到依赖虚假相关的特征；已有最坏情形泛化界结果表明数据点越少、最优解越依赖压缩特征，因此显式偏向压缩。作者同时明确限定：更高压缩不保证在移动的数据分布下稳健，"压缩即泛化"只是基于多数 MDP 有一致底层转移机制（如物理规律）这一假设的合理推断——原文用 believe 标注了这一步的语气。

技术路径：将策略梯度更新重解为在数据分布 $p(s,a):=\frac{\rho^\pi(s)\pi_\theta(a|s)A^\pi(s,a)}{\mathcal{Z}}$ 下最大化 $\log$ 边际似然，取半梯度（视 $p(s,a)$ 固定）可恢复策略梯度（Eq.(7)）：

$$\nabla_\theta \mathcal{Z} \, \mathbb{E}_{p(s,a)}[\log \pi_\theta(a|s)] = \int \rho^\pi(s) \pi_\theta(a|s) \nabla_\theta \log \pi_\theta(a|s) A^\pi(s,a) \dif s \dif a.$$

随后按 VIB 的做法引入随机潜变量 $z$，最小化 $\beta I(S,Z)$ 同时最大化 $I(Z,A)$，得（Eq.(8)）：

$$L_{\text{IB}} = \mathbb{E}_{p(s,a),p_\theta(z|s)}\big[ -\log q_\theta(a|z) + \beta D_{KL}[p_\theta(z|s)\| q(z)] \big]$$

经重参数化把编码器写成 $f_\theta(s,\epsilon)$ 后其梯度分解为修改的策略梯度项与 KL 正则项（Eq.(9)）：$\nabla_\theta L_{\text{IB}} = \nabla_\theta( L^{\text{IB}}_{\text{AC}} + \beta L^{\text{KL}})$。一个细节论证值得注意：常规熵 bonus $H[\pi_\theta(a|s)]$ 会波及 $z$ 上的分布，但 rollout 用的是去噪 $\bar{\pi}_\theta$，只需防 $q_\theta(a|z)$ 塌缩，且 $p_\theta(z|s)$ 已被 KL 项隐式熵正则（原文脚注给出 $D_{KL}[p_\theta(z|s)\| r(z)] = -H[p_\theta(z|s)] - \mathbb{E}_{p_\theta(z|s)}[\log r(z)]$），故换成条件熵式 bonus（Eq.(10)）：

$$H^{\text{IB}}[\pi_\theta(a|s)] := \int p_\theta(s, z) H[q_\theta(a|z)] \dif s \dif z,$$

总损失（Eq.(11)）：$L^{\text{IBAC}}_t(\theta) = L_{\text{AC}}^{\text{IB}} + \lambda_V L_{\text{AC}}^V - \lambda_H H^{\text{IB}}[\pi_\theta] + \beta L^{\text{KL}}$。IBAC 与 SNI 的接口：$\bar{\pi}_\theta$、$\bar{V}_\theta$ 取 $z=\mu_\theta(s)$（后验众数）作为 $q_\theta(a|z)$ 与 $V_\theta(z)$ 的输入，critic 亦条件在压缩特征上。

## 证据链

合成低数据实验（§5.1，无编号图 fig:toy）：训练数据把类别 $c_i$ 以两种编码 $g^c$（训练/测试共享，即更泛化）与 $f^c$（不共享，泛化性由 $\omega^f$ 控制，越大越不泛）嵌入；所有模型都完美拟合训练集，故测试性能度量模型对 $g^c$ 的相对依赖。结果是各正则技术大体相当，唯独 VIB 在低数据与多信号泛化差距小的两种情形下都能找到更泛化的特征。此实验支撑"IB 适合 RL 早期低数据 regime"这一前提，是 IBAC 动机的直接证据；但注意它是监督式合成任务，向 RL 的外推依赖 §5.2/5.3 的实验补足。

Multiroom（§5.2）：每回合从 $q(m)$ 随机生成 $n_r\in\{1,2,3\}$ 房间布局，训练即测试、成功只能靠泛化。结果（fig:grid 中图）：其余全训练模型在两房间布局成功率不足 3%、三房间为 0，而 IBAC-SNI 达 43% 与 21%。这支撑 IBAC 在强泛化要求任务上"能学出来"的主张。附注观察：单房间时 SNI 略降性能（减少的策略随机性在此无益），多房间时 SNI 提升——原文以此说明噪声的危害随任务复杂度增加。

Coinrun（§5.3）：沿用先前工作的 500 训练关卡设置，所有实验统一加 weight decay 与数据增强，Baseline 指仅这两项。发现一：几乎全部既有随机正则（含先前最优组合中的 BatchNorm）相对 baseline 反而降性能，BatchNorm 最差（作者猜测与 weight decay 的异常交互有关）；发现二：IBAC-SNI 显著超越新 baseline，且 $\lambda=0.5$ 优于 $\lambda=1$，验证 Eq.(6) 两项都必要。机制性证据：以 rollout 策略与更新策略间的平均近似 KL 散度作为重要性权重方差的代理（fig:coinrun 右图），确定性项的 KL 更低（解释其正向作用），且随机项的 KL 对 Dropout 远高于对 IBAC——由此解释 Dropout 用 $\lambda=1$ 更好而 IBAC 可用 $\lambda=0.5$。这是论文中少有的把方法差异追溯到梯度方差量级的机制验证。

附录补充证据：不含 weight decay/数据增强时（fig:ap:coin2 右），IBAC 单独使用并不能防止过拟合（训练久了测试性能下降），只加快早期学习；作者推断它先找到更泛化的特征但最终仍会过拟合，且其正则作用与 weight decay 性质不同，故二者组合有协同。这条负面结果是对主结论的诚实限定：IBAC 的贡献是"早期特征选择"而非全程防过拟合。

## 限定条件与失败模式

- 三条噪声通道的诊断针对的是含 off-policy 修正项与 critic 的 actor-critic 族（原文说明任何带 off-policy 修正的 RL 方法皆可用），纯 on-policy、无 critic 的形式不在此论证范围内。
- 合成实验中"多数技术相当、唯 VIB 突出"是在特定合成的可调难度 regime（$n_g=3$、$\sigma_\epsilon=1$、$d_x=100$、$d_g=20$、$n_c=5$）内观察到的，作者称在超参范围内定性稳定。
- Coinrun 上"随机正则有害"的结论是在已叠加 weight decay 与数据增强的前提下得出的；作者明确 conjecture 这是随机正则的额外不稳定与既有正则收益重叠所致，不含上述两项时（附录）SNI 对 Dropout/IBAC 均有正向作用。因此"有害"不是无条件命题。
- Multiroom 中 SNI 在单房间略降性能，说明悬置噪声并非总是有利。
- λ 的最优值因技术而异（Dropout 为 1，IBAC 为 0.5），说明混合系数是需要按噪声方差量级调节的超参数而非通用常数。
- 论文自陈仅聚焦 Dropout 与 VIB 的 SNI 化，BatchNorm 等其他技术的悬置实现留给未来工作。
- 相关工作限定：本文处理的是"特征稳健性"（高维观测下的特征泛化），不针对"对不确定性稳健"（域随机化、sim-to-real）那一支。

- 源文为 LaTeX 摘录，REF(...) 形式的交叉引用与 \gls 宏未展开，图均为 pdf 文件名、无数值轴信息；fig:coinrun 中的具体性能数字在源文中不可读，正文仅有的具体数值（3%/43%/21% 等）来自 fig:grid 的图注描述。引用编号全部缺失（如 "shown in " 后直接接句点），涉及先前工作的具体结论只能按上下文理解，本文不做证据使用。
- Eq.(2) 中 $L_{\text{PPO}}^V$ 的定义混用 $V^r$、$V^T$、$V_{\text{target}}$ 三个记号（原文如此，照录），"previous value function $V^r$"与"$V^T$"的关系未在摘录文本中说明，属疑点，不作为推理依据。
