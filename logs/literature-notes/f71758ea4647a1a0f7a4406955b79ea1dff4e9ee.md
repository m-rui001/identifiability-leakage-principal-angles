# 基于自监督信息瓶颈的深度多视图子空间聚类

原题：Self-Supervised Information Bottleneck for Deep Multi-View Subspace Clustering（arXiv:2204.12496，2023，DOI: 10.1109/tip.2023.3246802，IEEE TIP）。LaTeX 源通道，定位用章节/公式号（源中交叉引用为 REF 占位）。

## 问题设定与核心主张

多视图子空间聚类的目标是融合不同视图的信息以发现数据的子空间结构。作者指出的既有缺口呈两层（§1）：线性方法（LRR、LMVSC 及大量亲和矩阵方法）无法处理复杂非线性结构；已有的深度方法（DMSC、MvDSCN、gLMSC）虽然非线性，却没有从信息论角度控制"每个视图保留什么信息"——gLMSC 学的是"综合所有视图信息的表示"，而作者的论点是：并非每个视图里的全部信息都对发现子空间结构有用。信息瓶颈（IB）原则此前已被用于表示学习（VIB、MIB 等，§2），但据作者所知尚未被用于多视图子空间聚类——"第一个做 IB + 多视图子空间聚类"是其主张的新颖性声明。

核心主张可拆为两条：(1) 用扩展的 IB 学"视图共同"表示 $\mathbf{z}_c^i$，以另一视图的表示 $\mathbf{z}_c^j$ 作为自监督信号，既删去对其他视图无用的信息又保证充分性；(2) 再学一个"视图特有"表示 $\mathbf{z}_s^i$，用互信息正则使其与 $\mathbf{z}_c^i$ 互补（解耦且联合充分），进一步提升性能。支撑性结论是：基于最小充分视图共同表示的亲和矩阵送入谱聚类，性能超过一众 SOTA。

## 推理链重建：自监督 IB 目标怎么来的

**第一步：互信息分解。** 关键的构造在 §3.1：对样本 $\mathbf{v}^i$，其与视图共同表示 $\mathbf{z}_c^i$ 的互信息被分解为

$$I(\mathbf{v}^{i};\mathbf{z}_{c}^{i})=\underbrace{I(\mathbf{v}^{i};\mathbf{z}_{c}^{i}|\mathbf{z}_{c}^{j})}_{\rm signal\text{-}irrelevant} + \underbrace{I(\mathbf{z}_{c}^{i};\mathbf{z}_{c}^{j})}_{\rm signal\text{-}relevant}.$$

条件互信息 $I(\mathbf{v}^i;\mathbf{z}_c^i|\mathbf{z}_c^j)$ 表示 $\mathbf{z}_c^i$ 从 $\mathbf{v}^i$ 捕获、但与 $\mathbf{z}_c^j$ 无关的信息，即"多余信息"；$I(\mathbf{z}_c^i;\mathbf{z}_c^j)$ 度量 $\mathbf{z}_c^j$ 中有多少信息可从 $\mathbf{z}_c^i$ 获得。这是把 IB 的"相关变量"从标签 $Y$ 替换成另一视图表示的桥接步骤——正是"自监督"的含义（原文明说：$\mathbf{z}_c^j$ 充当自监督信号）。由此得视图 $i$ 的损失

$$\mathcal{L}_{c}^{i} =- I(\mathbf{z}_{c}^{i};\mathbf{z}_{c}^{j}) + \lambda_{i} I(\mathbf{v}^{i};\mathbf{z}_{c}^{i}|\mathbf{z}_{c}^{j}),$$

$\lambda_i$ 是信息约束引入的 Lagrange 乘子——形式上正是标准 IB 拉格朗日式。

**第二步：条件互信息的化简。** 用条件互信息链式法则（原文 Eq.(3)）：

$$I(\mathbf{v}^{i};\mathbf{z}_{c}^{i}|\mathbf{z}_{c}^{j})=I(\mathbf{v}^{i};\mathbf{z}_{c}^{i},\mathbf{z}_{c}^{j})-I(\mathbf{v}^{i};\mathbf{z}_{c}^{j})=I(\mathbf{v}^{i};\mathbf{z}_{c}^{i})+I(\mathbf{z}_{c}^{j};\mathbf{v}^{i}|\mathbf{z}_{c}^{i})-I(\mathbf{v}^{i};\mathbf{z}_{c}^{j})=I(\mathbf{v}^{i};\mathbf{z}_{c}^{i})-I(\mathbf{v}^{i};\mathbf{z}_{c}^{j}).$$

最后一步用了 $I(\mathbf{z}_{c}^{j};\mathbf{v}^{i}|\mathbf{z}_{c}^{i})=0$，即假设 $\mathbf{z}_c^j$ 关于 $\mathbf{v}^i$ 的信息在给定 $\mathbf{z}_c^i$ 后为（分析重建：这一步在正文推导中未显式陈述条件，被注释掉的推导块表明作者改动过这里；该假设的成立依赖 $\mathbf{z}_c^i$ 从 $\mathbf{v}^i$ 提取且携带不少于自监督信号 $\mathbf{z}_c^j$ 的信息——这是一个近似而非严格等式，读者应把最终目标视为原文所称的"松弛/上界"）。于是

$$\mathcal{L}_{c}^{i} =- I(\mathbf{z}_{c}^{i};\mathbf{z}_{c}^{j}) + \lambda_{i}( I(\mathbf{v}^{i};\mathbf{z}_{c}^{i})-I(\mathbf{z}_{c}^{j};\mathbf{v}^{i})).$$

**第三步：两视图合并与松弛。** 合并 $\mathcal{L}_c^i + \mathcal{L}_c^j$，并利用 $\mathbf{v}^i$ 对子空间聚类"信息过载"这一论证，把 $I(\mathbf{z}_{c}^{j};\mathbf{v}^{i})$ 换成编码器分裂前的特征 $\mathbf{h}^i$（原文引用不等式 $I(\mathbf{z}_{c}^{j};\mathbf{v}^{i}) \geq I(\mathbf{z}_{c}^{j};\mathbf{h}^{i})$），得到上界形式的总损失，拆成三个可分别消融的项：

- $\mathcal{L}_{c}^{dis}=-2 I(\mathbf{z}_{c}^{i};\mathbf{z}_{c}^{j})$：跨视图共同信息最大化；
- $\mathcal{L}_{c}^{cmi}=-(\lambda_{i} I(\mathbf{z}_{c}^{j};\mathbf{h}^{i})+ \lambda_{j}I(\mathbf{z}_{c}^{i};\mathbf{h}^{j}))$：锚-特征互信息最大化；
- $\mathcal{L}_{c}^{mkl}=\lambda_{i} I(\mathbf{v}^{i};\mathbf{z}_{c}^{i}) + \lambda_{j} I(\mathbf{v}^{j};\mathbf{z}_{c}^{j})$：压缩项。

**第四步：三个互信息的可解化。** (i) 最大化类 KL 形式的 $I(\mathbf{z}_{c}^{j};\mathbf{h}^{i})$ 会发散，故改用 Jensen-Shannon 互信息估计（正对 = 同一样本两视图特征，负对 = 随机采样的 $\hat{\mathbf{h}}^i$，判别器 $\mathrm{D}$ 估计配对概率）；$I(\mathbf{z}_c^i;\mathbf{z}_c^j)$ 同法。(ii) 最小化 $I(\mathbf{v}^{i};\mathbf{z}_{c}^{i})$：由 KL 非负导出变分上界 $\mathbb{E}_{p(\mathbf{v}^{i})}[D_{KL}(p(\mathbf{z}_{c}^{i}|\mathbf{v}^{i})\|q(\mathbf{z}_{c}^{i})]$，把后验拉向预定义分布（如标准高斯）。

## 视图特有表示与自表达

**互补的两种约束（§3.2）。** 定义"互补"满足两个 desiderata：解耦（$\mathbf{z}_s^i$ 与 $\mathbf{z}_c^i$ 独立）与联合充分（合并后含视图 $i$ 的完整信息）。前者由 $\mathcal{L}_{s} = I(\mathbf{z}_{s}^{i};\mathbf{z}_{c}^{i}) + I(\mathbf{z}_{s}^{j};\mathbf{z}_{c}^{j})$ 实现，用 predictability minimization 思路优化：设预测器 $F$ 用 $\mathbf{z}_s^i$ 预测 $\mathbf{z}_c^i$，$\min\max$ 博弈使二者互相不可预测。后者由重建项承担。

**自表达层与重建（§3.3、§3.4）。** 在视图共同空间上加全连接自表达层 $\mathcal{L}_{se}^{i} = \|\mathbf{Z}_{c}^{i} - \mathbf{Z}_{c}^{i}\mathbf{C}^{i}\|_{F}^{2} + \lambda\|\mathbf{C}^{i}\|^{2}$，约束 $\text{diag}(\mathbf{C}^{i})=0$，$\mathbf{C}^i$ 即谱聚类所需的亲和矩阵。重建用 $I(\mathbf{v}^{i};\mathbf{z}_{s}^{i},\widetilde{\mathbf{z}}_{c}^{i})$ 的变分下界（$\widetilde{\mathbf{z}}_{c}^{i}$ 为自表达后的特征），$q(\mathbf{v}^i|\cdot)$ 取高斯时实现为 $\|\mathbf{v}^{i}-R(\mathbf{z}_{s}^{i},\widetilde{\mathbf{z}}_{c}^{i})\|^{2}$ 的解码损失。总损失

$$\min \mathcal{L} = \mathcal{L}_{c} + \alpha \mathcal{L}_{s} - \beta \mathcal{L}_{r} + \gamma \mathcal{L}_{se},$$

各视图自表达系数矩阵取平均后做谱聚类。注意：这篇文章里"IB"只出现在视图共同空间的学习中，视图特有空间与重建用的是普通互信息正则——两个空间的角色在论证中是分工而非同构（分析重建）。

## 证据：实验与消融

- **主表（Table 1）**：RGB-D、Fashion-MNIST、notMNIST、COIL20 四个数据集，ACC/NMI/ARI 三指标，SIB-MSC 全部最优。与 gLMSC 的差距支持"应删多余信息"的论点；与 MIB-DSC（作者把为多视图表示学习设计的 MIB 接到自己的视图共同模块上构造的基线）的比较支持"互为自监督信号"这一自监督设计的增量价值；与 SiMVC/CoMVC 的比较支持"子空间结构发现"本身重要。RGB-D 上 ACC 51.2 对最强基线 MIB-DSC 42.4，提升幅度最大。
- **数据规模（Table 2）**：Fashion-MNIST 上 1000/5000/10000 样本，SIB-MSC 稳定领先；gLMSC 在 10000 样本时因显存要求无法运行——线性方法/自表达类方法的可扩展性边界在此显式出现。
- **消融（Table 4）**：逐项去掉 $\mathcal{L}_s$、$\mathcal{L}_{c}^{mkl}$、$\mathcal{L}_{c}^{cmi}$、$\mathcal{L}_{c}^{dis}$。作者称每个组件都有贡献，但数字并不均匀：去掉压缩项 $\mathcal{L}_{c}^{cmi}$ 伤害最大（RGB-D ACC 从 51.2 掉到 29.2；COIL20 从 78.4 掉到 51.4），而去掉 $\mathcal{L}_c^{dis}$（两视图共同表示互信息最大化）在某些数据集上甚至接近完整模型（RGB-D 48.1）。这是对"自监督信号最大化跨视图一致性"这一核心叙事的一个重要限定（分析重建）：在部分数据集上，真正不可缺的是条件互信息压缩，而不是跨视图互信息最大化本身；原文没有讨论这个不均匀性。
- **可视化（Figs. 4/5）**：融合亲和矩阵的 t-SNE 比单视图结果更好；余弦相似度显示 $\mathbf{z}_c^i$ 与 $\mathbf{z}_c^j$ 高相关、$\mathbf{z}_c^i$ 与 $\mathbf{z}_s^i$ 低相关——为"共同/特有"两个空间的解耦提供直接但粗粒度（仅 4 个样本）的证据。

## 限定条件与疑点

- 理论层面多处为上界/下界松弛（Jensen-Shannon 估计、变分近似、$I(\mathbf{z}_{c}^{j};\mathbf{v}^{i}) \ge I(\mathbf{z}_{c}^{j};\mathbf{h}^{i})$ 的替换），优化的是这些代理目标而非原始互信息；$\lambda_i, \alpha, \beta, \gamma$ 的取值依赖搜索，未给出理论指导。
- 条件互信息链式化简中 $I(\mathbf{z}_{c}^{j};\mathbf{v}^{i}|\mathbf{z}_{c}^{i})=0$ 的成立条件在正文未充分论证（见上文推导重建），严格性存疑。
- 只展示了 $m=2$ 视图的公式；原文称" easily extended to the general case"，但 $M>2$ 的成对求和公式被注释掉了，扩展性与计算复杂度未验证。
- 源文件中引用编号丢失（\cite 内容为空），对比方法描述多处依赖读者自行查证；两处红色批注型注释（"#去掉as much as possible…"、"经验上……"）是作者内部草稿痕迹，不构成正文证据。
- 评价指标为聚类外指标，"子空间结构"本身没有被直接验证（无子空间角度/维数的评估）。

## 结论

本文的推理链是把 IB 的"相关变量"从标签换成另一视图的潜表示：$I(\mathbf{v}^i;\mathbf{z}_c^i|\mathbf{z}_c^j)$ 作压缩项、$I(\mathbf{z}_c^i;\mathbf{z}_c^j)$ 作充分性项，配合自表达层与重建项构成完整聚类框架。最非平凡的一步是互信息分解加链式化简，它让"自监督"落地为可优化的互信息三元组；而消融中压缩项 $\mathcal{L}_{c}^{cmi}$ 主导性能的现象提示：在该框架中，IB 式压缩对子空间结构的贡献大于跨视图一致性最大化——这一原文未明说的层级关系，是从数据中读出的重要限定。
