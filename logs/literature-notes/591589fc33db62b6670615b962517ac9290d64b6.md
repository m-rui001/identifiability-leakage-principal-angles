## 论证骨架（页码锚点版）

- **问题设定** [page 1–2]：数据驱动 UQ；经典 KL 降维 + 代理路线的维数灾难与"需要先验协方差"限制；DNN-SDE 已有路线（DNN 前向近似、arbitrary polynomial chaos 的指数增长、PI-GAN 的训练不稳与密度不可评）；NF 的"精确对数似然 + 高效采样"优势。
- **数据模型** [page 2–3]：$N_s$ 个快照、每快照 $N_k,N_f,N_u$ 个传感器（位置可随快照变化——与 PI-GAN 的关键区分，Remark 2 [page 3]）；前向/反向由 $k$ 与 $u$ 的传感器配比连续定义。
- **RealNVP 复习** [page 3–5]：换元公式、耦合块的三角 Jacobian 与直接逆映射（式 (7)–(11)）。
- **NFF 核心** [page 5–8]：参考高斯场 $z(x,\omega) = A(x)+ B(x)\xi(\omega)+\mathrm{diag}(C(x))\epsilon(x,\omega)$（式 (13)，KL 截断 $M$ 阶 + 防奇异噪声项）；快照级联合高斯 $\mathcal{N}(\boldsymbol{\mu^s},\boldsymbol{\Sigma^s})$（式 (15)）；负对数似然损失（式 (16)–(17)）；$N\gg M$ 时 Woodbury 恒等式 + \texttt{LowRankMultivariateNormal} 快速实现（Remark，[page 7]）；推断用 $\xi$ 的高斯后验（式 (19)–(20)，附录 B 给 $\mu_\xi,\Sigma_\xi$ 显式式）；标量场增广辅助白噪声的 RealNVP 处理（Remark + 附录 C/Algorithm 3）。
- **物理信息 NFF** [page 8–10]：三个流代理 $k,u,f$；总损失 $\mathcal{LOSS}=w_{data}\mathcal{L}_{data}+w_{equ}\mathcal{L}_{equ}+w_{bnd}\mathcal{L}_{bnd}$（式 (22)–(23)）；方程项取变分形式，测试函数 $h(x,c,r)=r^{-D_{x}}\mathbf{1}_{\{\|x-c\|_{\infty}\le r/2\}}$，1D/2D 的无偏估计（$e_i e_i'$ 配平方技巧）在附录给出（[page 17–21]）。
- **数值结果** [page 10–16]：非高斯场（$k=\exp(\tilde k)$，$l_c = 0.5, 0.2$，$N_k = 6/11$，12 传感器，$10^3$ 快照，$M = 30$）[page 10–12]；混合非高斯场的双模态条件统计复现 [page 12–13]；单测量推断 [page 13–14]；1D 随机椭圆方程前向（13 个 $k$ 传感器/21 个 $f$ 传感器，$N_k = 7$、$f$ 可用 11）与反向/混合（$N_k = 1, N_u = 7$ 与 $N_k = 3, N_u = 5$，$f\equiv 1$，$M = 40$）[page 14–15]；2D 前向（51 传感器、$N_k = 30$）[page 15–16]。
- **结论** [page 16]：全数据驱动统一框架、传感器位置可变、缓解维数灾难；未来做时间依赖与多尺度问题。

## 适用条件与边界（同期刊版，摘要）

KL 阶数 $M$ 手工选择（30/40）；参考场 $A,B,C$ 的最优构造开放；变分损失依赖测试函数族；标量场需增维处理；实验限于静态椭圆问题。
