## 论证骨架（页码锚点版）

- **问题与动机** [page 1–3]：高维非线性滤波；KF/EnKF 高斯拟设失效、PF 粒子退化、QKF 维数灾难、score-based 滤波与 RKN/VAE 类方法依赖显式 SSM 或可处理分布近似；已有 NF 滤波（NKF、CNF-DPF）的缺陷：NKF 状态仅为潜变量不能映射物理状态，CNF-DPF 沿粒子流程高维采样低效。设定：$f,h$ 未知，仅有轨迹数据。
- **NF 预备** [page 4–5]：双射 $\mathcal{T}$、换元公式 $p_{\bm{x}}(\bm{x}) = p_{\bm{z}}(\bm{z}) |\mathrm{det}(\partial\mathcal{T}(\bm{x})/\partial\bm{x})|$、条件密度引理 $p(\bm{x}|\bm{x}') = p(\bm{z}|\bm{z}')|\mathrm{det}(\partial\mathcal{T}(\bm{x})/\partial\bm{x})|$；采用 RealNVP。
- **FBF 模型结构** [page 5–8]：$\bm{\chi}_{k} = \mathcal{T}(\bm{x}_{k})$、$\bm{\gamma}_{k} = \mathcal{V}(\bm{y}_{k})$；潜 SSM 两方程（状态更新对观测 $\bm\gamma_k$ 条件仿射、观测方程对 $\bm\chi_{k-1}$ 线性）；高斯性论证与两个 Remark（$A,B,C,D$ 不得依赖 $\bm\chi_{k-1}$；传统线性 SSM 为特例）；原空间分布恢复 $p(\bm{x}_{k}\mid\bm{y}_{1:k})=p(\bm{\chi}_{k}\mid\bm{\gamma}_{1:k})|\mathrm{det}(\partial\mathcal{T}/\partial\bm{x}_{k})|$ [page 7]。
- **训练** [page 8–10]：极大似然目标 $\mathcal{L}(W) = \frac{\alpha}{K} \sum_{k} \log f_s + \frac{\beta}{K} \sum_{k} \log f_o$，SGD（Algorithm 1 [page 9]）；初始分布用 $\mathcal{T}(\bm x_0)$ 样本均值/协方差近似 [page 10]。
- **滤波两步** [page 10–12]：Step 1 共轭高斯更新给出 $\bm{\mu}_{k-1}^{'} = \bm{\mu}_{k-1} + \bm{\Sigma}_{k-1}D^{\top}Q_{\gamma}^{-1}(\bm{\gamma}_{k} - C - D\bm{\mu}_{k-1})$、$\bm{\Sigma}_{k-1}^{'} = \bm{\Sigma}_{k-1} - \bm{\Sigma}_{k-1}D^{\top}Q_{\gamma}^{-1}D\bm{\Sigma}_{k-1}$；Step 2 给出 $\bm{\mu}_{k} = A(\bm{\gamma}_{k}) + B(\bm{\gamma}_{k})\bm{\mu}_{k-1}^{'}$、$\bm{\Sigma}_{k} = B(\bm{\gamma}_{k})\bm{\Sigma}_{k-1}^{'}B(\bm{\gamma}_{k})^{\top} + Q_{\chi}(\bm{\gamma}_{k})$；采样经 $\bm{x}_k^{(j)} = \mathcal{T}^{-1}(\bm{\chi}_k^{(j)})$（Algorithm 2 [page 12]）。
- **数值证据** [page 13–24]：二维模型（$x_{k} = 0.9\,\mathrm{sin}(1.1x_{k-1} + 0.1\pi) + 0.01 + e_k$，$y_{k} = \mathrm{arctan}(x_{k,2}/x_{k,1}) + v_k$，$r^2\in\{0.025,0.05,0.075,0.1\}$）[page 13–16]，FBF 接近 PF、$r^2\ge 0.05$ 时优于 RKN/CNF-DPF，计时 offline 435.18 s 对 RKN 5965.41 s、CNF-DPF 12840.28 s [page 16 表]；Lorenz-96（$F=8$，量测 $y_t = x_t^3 + v_t$，$m=10,\dots,100$，$\Delta t = 0.01$）[page 17–22]，$m\ge 40$ 时 FBF 优于 RKN，$m=100$ 时 PF 在线 111081 s 对 FBF 968 s，CNF-DPF $m>30$ 显存不可行 [page 22 表]；随机平流–扩散（$\mathrm{d}u + (\kappa\partial_{s}u - D\partial_{ss}^{2}u + g(s))\mathrm{d}t = \sigma\,\mathrm{d}W(t)$，$g(s) = 5(s^2 - 1)$，$\sigma = 10$，$D = 0.01$，$\kappa = 0.5$，传感器 $n=25\to 10$）[page 23–26]，FBF 不确定性在测点附近收缩、PF 区间失效、RKN 无此自适应行为 [page 25 图]。
- **附录 A（FBF' 特例）** [page 26–30]：线性潜 SSM $\chi_k = E + F\chi_{k-1} + \zeta_k$、$\gamma_k = G + H\chi_k + \xi_k$ 的 Kalman 更新及其到 FBF 形式的等价改写（$A = E - K_{k}^{'}(G+HE) + K_k^{'}\bm\gamma_{k}$、$B = F - K_{k}^{'}HF$ 等，$K_{k}^{'} = P_{\chi}H^{\top}(HP_{\chi}H^{\top} + P_{\gamma})^{-1}$ [page 28]）；FBF' 计算量同阶（offline 469.97 s）但误差更高 [page 29–30]。

## 适用条件与边界（同主篇，摘要）

高斯闭包依赖 $A,B,Q_\chi$ 仅依赖 $\bm\gamma_k$、$C,D$ 为常数；协方差对角参数化（Softplus）为实验性选择；初始分布为事后近似；在线开销含 NF 逆变换；要求训练轨迹覆盖系统动力学。
