# 经由多视图信息瓶颈学习鲁棒表示

原题：Learning Robust Representations via Multi-View Information Bottleneck（Federici, Dutta, Forré, Kushman, Akata；ICLR 2020；arXiv:2002.07017）。源文本为 arXiv LaTeX 源（主文件 main.tex；定位用章节/公式号）。

## 论证起点：监督 IB 可以直接压"多余信息"，无监督不能

论文的出发点是一个精确刻画的不对称：监督设定下可直接对 IB 原理落地——最小化 $I(x;z)$ 同时最大化 $I(z;y)$。作者用链式法则把 $I(x;z)$ 分解为两项：

$$I(x;z) = \underbrace{I(x;z|y)}_{\text{superfluous information}} + \underbrace{I(y;z)}_{\text{predictive information}},$$

只要 $z$ 对 $y$ 充分（sufficient，即 $I(x;y|z)=0$，等价于 $I(x;y)=I(y;z)$），$I(y;z)$ 就与表示无关，于是"最小充分表示"归结为最小化 $I(x;z|y)$。问题在于：**无监督时没有标签，模型无法识别哪部分信息与任务相关**。流行的 InfoMax 目标反其道而行——最大化 $I(x;z)$ 以保住全部预测信息，但对丢弃无关信息毫无作为。作者由此提出核心思想：在多视图设定下，利用多视图文献的基本假设——每个视图提供同样的任务相关信息——把"视图间不共享的信息"识别为必然多余的，从而在不知道 $y$ 的情况下安全地压缩。

## 理论：冗余定义 + 推论 1 给出"无标签的充分性保证"

形式化分两步。先定义**冗余**：$v_1$ 对 $v_2$ 关于 $y$ 冗余当且仅当 $I(y;v_1|v_2)=0$；两视图**互为冗余**（mutually redundant）时得到关键结论（推论 1）：若 $z_1$ 是 $v_1$ 的表示且对 $v_2$ 充分（$I(v_1;v_2|z_1)=0$），则 $z_1$ 对 $y$ 的预测力与联合观测相同：$I(v_1v_2;y)=I(y;z_1)$。直觉（作者明说）：包含两视图全部共享信息的表示，必然包含必要的标签信息。

再把 $I(v_1;z_1)$ 做同样的链式分解：

$$I(v_1; z_1) = \underbrace{I(v_1;z_1|v_2)}_{\text{superfluous}} + \underbrace{I(v_2;z_1)}_{\text{predictive for } v_2},$$

要让表示对 $v_2$ 充分则 $I(v_2;z_1)$ 必须最大，因此可以安全削减的只剩 $I(v_1;z_1|v_2)$——$z_1$ 中 $v_1$ 独有、不能从 $v_2$ 预测的部分；在互冗余假设下它对预测任务必然无关。作者还刻画了该假设的两个极端对齐：两视图只共享标签信息时，方法退化为**不需要标签的监督 IB**（附录 Proposition 给出证明：$I(v_1;z_1|v_2)=I(v_1;z_1|y)$，最小化前者即最小化后者）；两视图相同时退化为 InfoMax（此时 $I(v_1;z_1|v_2)=0$ 对任何表示成立，无可丢弃）。这两个端点把 MIB 精确地插在监督 IB 与 InfoMax 之间——这是论文方法定位的推理骨架。

## 损失函数：两级上界把不可算的条件互信息变成对称 KL

取两个松弛 Lagrangian 目标 $\mathcal{L}_1(\theta;\lambda_1)=I_\theta(z_1;v_1|v_2)-\lambda_1 I_\theta(v_2;z_1)$、$\mathcal{L}_2(\psi;\lambda_2)=I_\psi(z_2;v_2|v_1)-\lambda_2 I_\psi(v_1;z_2)$，把 $z_1,z_2$ 定义在同一域 $\mathcal{Z}$ 上后求平均，经两级放缩（附录 app:loss 给出全部推导）得上界：

$$\mathcal{L}_{MIB}(\theta,\psi;\beta) = - I_{\theta\psi}(z_1;z_2) + \beta\ D_{SKL}(p_\theta(z_1|v_1)\,\|\,p_\psi(z_2|v_2)),$$

其中 $D_{SKL}$ 是两个方向 KL 的平均。推导中值得展开的两处：其一，$I_\theta(v_1;z_1|v_2)$ 被写成期望后插项 $\frac{p_\psi(z_2|v_2)}{p_\theta(z_1|v_2)}$，拆成 $\KL(p_\theta(z_1|v_1)\|p_\psi(z_2|v_2)) - \KL(p_\theta(z_2|v_1)\|p_\psi(z_2|v_2))$，第二项非负故得上界，且**当两视图编码一致时界是紧的**——这把"KL 项同时在做对齐"显式化了（作者在结果讨论中把检索任务的高分归因于此对齐效应）。其二，$I_\theta(z_1;v_2)=I_{\theta\psi}(z_1;z_2v_2)-I_{\theta\psi}(z_1;z_2|v_2) \geq I_{\theta\psi}(z_1;z_2)$（因 $z_2$ 是 $v_2$ 的表示，等号步由 $z_2$ 充分时取紧），故最大化 $I(z_1;z_2)$ 即可。实践中 $I(z_1;z_2)$ 用任意可微样本级互信息下界估计，作者试了 Jensen–Shannon 与 InfoNCE 两种（配辅助判别模型 $C_\xi(z_1,z_2)$），正文结果统一用 $I_{JS}$（附录 Table tab:MNIST_full 称其表现更好）。

**自监督扩展**是理论到单视图的桥：取不影响标签信息的增广函数类 $\mathcal{T}$（$I(v_1;y)=I(v_2;y)=I(x;y)$），令 $v_1=t_1(x)$、$v_2=t_2(x)$，则两视图对 $y$ 互为冗余；当 $I(t_1;t_2|x)=0$ 时两视图引入不相关变化，MIB 目标的最优解必须丢弃它们——不变性从数据中学得而非内建进架构。两个编码器由同一 $\mathcal{T}$ 均匀采样、边缘同分布，故可共享参数只留一个编码器。

## 相关工作定位：信息平面上的目标几何

论文用 Information Plane（横轴 $I(x;z)$、纵轴 $I(y;z)$）统一比较：InfoMax 目标指向右上（保留全部观测信息）；$\beta$-VAE 从右 $(\beta\to 0$ 无损$)$ 移向左（$\beta\to\infty$ 时 $I(z;x)\to 0$），但**途中无保证保留标签信息**；监督 IB 指向左上角。MIB 的目标区是"在 MV-InfoMax 最优表示中多余信息最少者"。这里嵌着全文最重要的理论屏障——附录定理（No Free Generalization）：若 $I(x;z)>I(x;z')$，则总能构造一个标签 $y$ 使 $z'$ 对 $y$ 无预测力而 $z$ 有（证明用构造法：取 $y$ 满足 $I(y;z')=0$ 且 $x=f(z',y)$，再逐条链式放缩得 $I(y;z)\geq I(x;z)-I(x;z')>0$）。推论直接点题：**任何丢弃观测信息的表示，总存在某个标签使它失效**——这就是"不引入额外假设（如互冗余）就不能无监督压缩"的形式化依据，也是 MIB 全部理论价值的立足点。

## 实验：三个任务分别对应理论的三个预测

**Sketch-based image retrieval（真多视图）**：Sketchy 数据集（12,500 图 + 75,471 素描，125 类，加 60,502 张同类 ImageNet 图，共 73,002 自然图；6,250 素描留作测试）。VGG（TU-Berlin 预训练）4096 维特征 → 64 维表示。结果（Table tab:sketchy，5 折均值±标准差）：MIB（$\beta=1$）mAP@all **0.856±0.005**、Prec@200 0.848±0.005，超过此前最好的 GDH*（0.810）、DSH*（0.711，64-bits 二值表示）等。训练配对取同类图像与素描以保证互冗余。作者把高分主要归因于 $D_{SKL}$ 的对齐效应（上节提到的界取紧条件）。对照组中 MV-InfoMax 的 0.008 数值被脚注明确限定：因其对两视图不产生一致表示、无法直接用于排序，仅为完整性列出——这是一个标注过的不可比数字。

**MIR-Flickr（近似多视图）**：1M 图 + 800K 标签；$v_1$ 为 3,857 维手工图像特征，$v_2$ 为 2000 维多热标签编码；无标签对训练，10K 有标签样本训多标签逻辑回归评估。结果：MIB（$\beta=10^{-3}$，验证集选定）mAP **0.749±0.02**，MV-InfoMax 0.751±0.02，$\beta=1$ 时 0.688±0.02；大幅超过 VCCA-private（0.615）、bi-VCCA-private（0.626）等。关键发现是标签稀缺区间：$\beta$ 越大在少标签时收益越大（图右），而全标签时略降。作者给出机理解释：**MIR-Flickr 的图像-标签对只是近似满足互冗余**（补充材料 fig:flickr_example 示意违约情形），此时过强压缩会丢真信息，需要较小 $\beta$ 补偿——这是把"假设近似成立"与"超参选择"连起来的推理。作者另推测 MIB 对 MVAE/VCCA 的优势可能部分来自不依赖重建项（重建引入偏置），以"possible reason / may be"语气表述。

**MNIST 自监督单视图（理论与估计的对账）**：小仿射变换 + 独立像素损坏生成两视图；2 层 1024 隐单元编码器、64 维表示；固定编码器后用少量标签训逻辑回归。互信息用专门训练的估计网络经验测量，把各方法画到 Information Plane（nats）。结果（fig:sample_complexity）与理论预测一致：丢弃更多观测信息而保持最大预测信息的方法在少标签区间更好；$\beta=1$ 的 MIB 几乎只保留标签信息，"每类仅 1 个标签"时性能几乎不降。附录消融补齐边界条件：损坏率趋于 100% 时互冗余被明显违反、MIB 性能劣化；极低损坏率区间 MIB 先丢一些标签信息随后恢复，作者归因于 Monte–Carlo 估计 $D_{SKL}$ 在罕见损坏样本下的偏差（标注为 hypothesize）；$\beta$ 消融显示 MIB 在 Pareto 前沿各点均优于 $\beta$-VAE 的权衡；且 $\beta>1$ 会优先压 $I(x;z|v_2)$ 而可能违反充分性约束。

## 边界与未决

- 全部保证以**互冗余**为前提；作者自己给出该条件不可平凡推广到三视图以上的形式化反例（附录 app:non-trans）：取 $v_1,v_2,v_3$ 为独立公平二元变量、$y := v_1 \text{ XOR } v_3$，可验 $v_1$ 与 $v_2$、$v_2$ 与 $v_3$ 均互冗余（$I(v_1;y|v_2)=I(v_2;y|v_1)=0$ 等），但 $I(v_1;y|v_3)=H(v_1)=1$——高阶交互使冗余关系**不可传递**。两视图扩展为开放问题。
- $D_{SKL}$ 上界的紧性依赖两视图编码一致、$I(z_1;z_2)$ 下界的紧性依赖 $z_2$ 对 $z_1$ 充分，两者在训练中无独立保证（推断重建，原文只说明何时取紧）。
- 实验规模受限：MNIST 上的互信息测量"极其昂贵"，作者自述只做小规模实验以揭示方法间差异。
- Sketchy 上与 MV-InfoMax 的对比行（0.008）不可比（脚注限定）。
